1. ทำให้เรียบด้วยค่าเฉลี่ย: SMA

1.1 Moving average คืออะไร

มองภูเขาจากระยะไกล รายละเอียดของหินแต่ละก้อนหายไป เหลือรูปทรงของภูเขา moving average ทำแบบเดียวกันกับข้อมูล

เทคนิคพยากรณ์มีสองตระกูล: โมเดลเชิงเส้น (regression, exponential smoothing, ARIMA, decomposition) ที่อธิบายง่ายและเป็นเนื้อหาเกือบทั้งวิชา โดย regression ที่นี่ไม่ได้ศึกษาเหตุเป็นผล แค่หา intercept กับ slope ของ trend7 กับโมเดลไม่เชิงเส้น (neural network, SVM) ที่ "อาจ" แม่นกว่า แต่ข้อมูลสั้นที่มีรูปแบบชัดมักใช้โมเดลเชิงเส้นได้ดีพอ

ค่าเฉลี่ยเคลื่อนที่ (moving averages) ออกแบบมาเพื่อทำให้ข้อมูลเรียบ8 มันไม่ได้ทำนายทิศทาง แต่ทำให้เห็น trend ง่ายขึ้น ความยาวหน้าต่างควรเท่ากับรอบของ seasonal (รายเดือน 12 รายไตรมาส 4) เพราะเฉลี่ยครบหนึ่งรอบแล้วผลของฤดูหักล้างกัน เหลือแต่ trend ซึ่งคือที่มาของ centered moving average ในตอน 5 SMA มีไว้ให้เข้าใจแนวคิด ส่วน EMA แตกเป็นได้หลายชนิด9

\[F_t=\frac{X_t+X_{t-1}+\dots+X_{t-k+1}}{k}\]

ค่าเฉลี่ยของ k ค่าล่าสุด เช่น k = 3 ได้ \(F_4=(X_4+X_3+X_2)/3\)10

สูตรบนสไลด์เขียนตัวสุดท้ายเป็น \(X_{t-k}\) ซึ่งผิด ต้องเป็น \(X_{t-k+1}\)11 เพราะนับจาก \(X_t\) ถึง \(X_{t-k}\) มี k + 1 ตัว ตรวจด้วย k = 3, t = 4 ได้ \(X_2\) ตรงกับตัวอย่าง

1.2 ตัวอย่าง CPALL

อัตราผลตอบแทนรายวัน 80 วันของ CPALL แกว่งรอบ 0 ไม่มี trend และไม่มี seasonal เพราะราคาหุ้นโดยธรรมชาติไม่มี seasonal13 สไลด์เรียกว่าอนุกรมแนวราบ (horizontal) โมเดลที่เข้ากันคือ \(X_t=\mu+\varepsilon_t\) สิ่งเดียวที่ต้องประมาณคือระดับ μ แบ่ง train 65 วันแรก test 15 วันท้าย อัตราผลตอบแทนเขียนได้ \((P_t-P_{t-1})/P_{t-1}\) หรือ \(\log(P_t/P_{t-1})\) ซึ่งไม่เท่ากัน ต้องเลือกแบบเดียว14 (แบบ log คือ difference ของ log ใน Lesson 7 ตอน 2.4)

คอลัมน์ k = 3 เริ่มมีค่าที่วันที่ 3: \((1.08-1.6-0.54)/3=-0.3533\) ค่าต่อไปคิดเร็วได้ด้วยค่าเดิมบวก (ค่าใหม่ลบค่าที่หลุด)/k15 ค่าแรก ๆ หายเพราะต้องมีครบ k ค่า (k = 3 หาย 2 ค่า)16 ยิ่ง k มากยิ่งเรียบแต่ตามช้าลง ช่วงท้ายของกราฟเป็นเส้นราบ เพราะทำเหมือนไม่รู้ test set ค่า \(F_{65}\) ค่าเดียวจึงพยากรณ์วันที่ 66–80 ทั้งหมด SMA จึงเหมาะกับพยากรณ์ระยะสั้นแค่ 1 จุด17

k ตั้งแต่ 2 ถึง 5 ใช้ได้กับกรณีส่วนใหญ่ ข้อมูลแกว่งมากใช้ k สูง แต่ k มากเกินจะลบทุกอย่างทิ้ง ทั้ง seasonal และ trend18 โดยรวม SMA ง่ายเกินไปและเหมาะกับการสอนมากกว่า19 บน test ได้ RMSE 1.663 และ MAE 1.586 การวัดบน train เรียก self-validation บน test เรียก cross-validation วิชานี้เน้นแบบหลัง เพราะจุดประสงค์คือพยากรณ์ไปข้างหน้า20 (Lesson 2)

ลองใน R: SMA ของ CPALL 
library(zoo); library(forecast)
data <- ts(read.table("CPALL.txt", h = T))
train.ts <- window(data, start = 1, end = 65); test.ts <- window(data, start = 66, end = 80)
ma.trailing <- rollmean(train.ts, k = 3, align = "right")    # 63 ค่า; "center" ได้แบบ centered
accuracy(ma.trailing, train.ts)                               # self-validation
forecast <- rep(ma.trailing[63], 15)                          # ค่าสุดท้าย 1.5533 ซ้ำ 15 ครั้ง
accuracy(forecast, test.ts)                                   # cross-validation: RMSE 1.663, MAE 1.586

2. ให้น้ำหนักค่าใหม่มากกว่า: EMA

2.1 น้ำหนักที่ลดลงแบบ exponential

ความจำของคน: เรื่องเมื่อวานจำชัด เรื่องเมื่อปีก่อนจำได้รางเลือน แต่ไม่ได้ลืมสนิท SMA จำ 3 วันชัดเท่ากันแล้วลืมทันที EMA จำแบบคน

แท่งเทาคือ SMA ที่ให้ ⅓ เท่ากันแล้วหายเป็นศูนย์ทันที แท่งส้มคือ EMA ที่ให้ค่าล่าสุดมากที่สุดแล้วลดลง 20% ทุกช่วง21 เขียนเต็มได้ \(F_{10}=\alpha X_9+\alpha(1-\alpha)X_8+\alpha(1-\alpha)^2X_7+\dots\)22 ดึง \((1-\alpha)\) ออกจากพจน์ที่สองเป็นต้นไป ที่เหลือคือ \(F_9\) จึงได้รูปสั้น

\[F_{t+1}=\prm{\alpha}X_t+(1-\prm{\alpha})F_t,\qquad 0<\alpha<1\]

ค่าพยากรณ์ใหม่ = ค่าเฉลี่ยถ่วงน้ำหนักระหว่างค่าจริงล่าสุดกับค่าพยากรณ์เดิม α ใหญ่ตามข้อมูลใหม่เร็ว α เล็กเรียบ ค่าที่นิยมคือ 0.1–0.2 น้ำหนักรวม \(\alpha\sum(1-\alpha)^j=1\) จึงเป็นค่าเฉลี่ยที่ถูกต้อง สมการนี้คือ ARIMA(0,1,1) ที่ α = 1 + θ ใน Lesson 7 ตอน 1.3

สูตรอ้างถึงตัวเอง จึงต้องมีค่าเริ่มต้น \(F_1\) ใช้ \(X_1\) หรือค่าเฉลี่ย 3–5 ค่าแรกก็ได้ ถ้าข้อมูลยาวพอจะลู่เข้าค่าเดียวกัน และ R เลือกค่าเริ่มต้นกับ α เอง23 ไฟล์ Excel ใช้ค่าเฉลี่ยสามค่าแรก \(F_1=-0.3533\)24 (หัวเรื่องของสไลด์หน้า 13 พิมพ์ "(SMA)" ที่ถูกคือ EMA)

accuracy(fc, test.ts)

3.2 Holt: level กับ trend

ติดตามรถที่กำลังวิ่ง ต้องรู้ทั้งตำแหน่ง (level) และความเร็ว (trend) ทุกครั้งที่เห็นรถใหม่ก็ปรับทั้งสองค่า

EMA พยากรณ์เป็นเส้นราบ ถ้าข้อมูลมี trend ขาขึ้น ค่าพยากรณ์จะต่ำกว่าจริงตลอด ยอดขาย 16 เดือนชุดนี้แสดงปัญหานั้นชัด37: ขึ้นจากราว 14,000 เป็น 274,515 ไม่มี seasonal โมเดลจึงเป็น \(X_t=a+bt+\varepsilon_t\)38 ระดับคงที่ μ ของ CPALL ถูกแทนด้วยเส้นตรง จึงต้องมีส่วนที่ติดตามความชันเพิ่ม

\[F_{t+k}=L_t+k\,T_t\]

3.3 Damped trend: ข้อมูลที่มีเพดาน

อัตราการมีส่วนร่วมในกำลังแรงงานของสิงคโปร์เพิ่มเกือบเป็นเส้นตรง แต่เกิน 100 ไม่ได้ ถ้าใช้เส้นตรงต่อไปเรื่อย ๆ ค่าพยากรณ์อาจทะลุร้อย47 วิธีแก้คือ damped trend R เลือก ETS(M,Ad,N) ซึ่ง Ad มาจาก additive damped48

4. เพิ่มฤดูกาล: Holt-Winters

4.1 สมการที่สามสำหรับ seasonal

สไลด์เล่าว่า Charles C. Holt เป็นที่รู้จักจากงานของตัวเองและของลูกศิษย์ของเขา Peter Winters สรุปสั้น ๆ ว่า Winters เอาแนวคิดของ Holt มาเพิ่มองค์ประกอบ seasonal แค่นั้นเอง วิธีนี้ไม่สอนคำนวณมือเพราะมีสามสมการ50 สิ่งที่ต้องได้คือเข้าใจสมการ รู้ว่าพารามิเตอร์ตัวไหนคู่กับอะไร และอ่านผลของ R ได้

\[\text{บวก: }F_{t+k}=L_t+kT_t+S_{t+k-m}\qquad\text{คูณ: }F_{t+k}=(L_t+kT_t)\times S_{t+k-m}\]

m คือความยาวรอบ (รายเดือน 12 รายไตรมาส 4)51 \(S_{t+k-m}\) คือค่า seasonal ของฤดูเดียวกันในรอบที่แล้ว เช่น พยากรณ์ธันวาคมปีหน้าใช้ seasonal ของธันวาคมล่าสุด

α คู่กับ level\(L_t=\alpha(Y_t-S_{t-m})+(1-\alpha)(L_{t-1}+T_{t-1})\) ใช้ค่าจริงที่ถอดผลของฤดูออกแล้ว
β คู่กับ trendเหมือน Holt
γ คู่กับ seasonal\(S_t=\gamma(Y_t-L_t)+(1-\gamma)S_{t-m}\) ผสมส่วนที่เกิน level ตอนนี้กับค่าฤดูเดียวกันรอบก่อน
φพารามิเตอร์หน่วงอีกตัวถ้ามี damped52

L = 200, T = 5, k = 2: แบบบวกที่ seasonal = −15 ได้ \(200+10-15=195\) แบบคูณที่ seasonal = 0.9 ได้ \(210\times0.9=189\) แบบคูณใช้หลักเดิม "ลบเป็นหาร บวกเป็นคูณ" ตรงส่วน seasonal ค่า seasonal แบบบวกจึงเฉลี่ยเป็น 0 แบบคูณเฉลี่ยเป็น 1 พารามิเตอร์ทุกตัวอยู่ระหว่าง 0 ถึง 1 ใกล้ 1 ปรับตามข้อมูลล่าสุดเร็ว ใกล้ 0 แทบไม่เปลี่ยน

5. แยกองค์ประกอบตรง ๆ: Decomposition

5.1 สี่ขั้นของ decomposition

decomposition ใน R ไม่ได้ออกแบบมาเพื่อพยากรณ์ แต่ถ้าทำใน Excel ด้วย regression จะพยากรณ์ได้ และอาจดีพอ ๆ กับ ETS58 แบบ regression ดีกว่าและเป็นแบบที่ใช้สอน MBA59 วัตถุประสงค์ข้อหนึ่งคือ ประมาณผลของฤดูกาล เพื่อทำค่าที่ปรับฤดูกาลแล้ว เช่น ยอดธันวาคมสูงกว่าพฤศจิกายนทุกปี ค่าดิบบอกไม่ได้ว่าธุรกิจดีขึ้นจริงหรือเป็นแค่ผลของฤดู

ขั้นแบบบวกแบบคูณ
1. trendmoving average (ไม่มีสมการ) หรือ regression (มีสมการ) ทั้งสองแบบต้องหาเส้นนี้ก่อน60

3. seasonalเฉลี่ยฤดูเดียวกัน ปรับให้เฉลี่ยเป็น 0เฉลี่ยฤดูเดียวกัน ปรับให้เฉลี่ยเป็น 1
4. randomข้อมูล − trend − seasonalข้อมูล ÷ (trend × seasonal)
ใช้เมื่อtrend นิ่ง แกว่งไม่มากเปลี่ยนเร็ว แกว่งกว้าง61

สไลด์ระบุว่า ผลของฤดูกาลมักถูกปรับให้เฉลี่ยเป็น 0 สำหรับแบบบวก หรือเป็น 1 สำหรับแบบคูณ เพราะ seasonal ต้องบอกเฉพาะส่วนที่เบี่ยงจากระดับปกติ ส่วนเกินควรอยู่ใน trend ข้อจำกัดคือสมมติว่ามี seasonal index ประจำแต่ละไตรมาส ซึ่งโมเดลอื่นอาจไม่มี62 ขั้น 2 คือ detrending ใน Lesson 3 ตอน 4

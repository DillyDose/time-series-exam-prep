1. ข้อมูลตามเวลาต่างจากข้อมูลทั่วไปอย่างไร

อาจารย์เปิดวิชาด้วยการเทียบข้อมูลสองแบบ ข้อมูลที่เคยใช้ในวิชาสถิติทั่วไปเรียกว่า cross-sectional คือเก็บครั้งเดียวจบ เขียนเป็น \(X_i\) โดย i คือลำดับของหน่วยที่เก็บ เช่น คนที่ 1, 2, …, n ส่วนข้อมูลอนุกรมเวลาเขียนเป็น \(X_t\) โดย t คือจุดเวลาที่ 1, 2, …, n ตัวห้อยต่างกันแค่ตัวอักษร แต่ความหมายต่างกันมาก (Class 1, 0:00:00–0:01:16)

อาจารย์ใช้การทดลองง่าย ๆ แยกสองแบบนี้: ลองสลับลำดับข้อมูลดู ในข้อมูลแบบ cross-sectional ถ้าสลับ \(X_1\) กับ \(X_3\) ผลการวิเคราะห์ไม่เปลี่ยน เพราะ \(X_1\) อาจเป็นอาจารย์คนหนึ่ง \(X_3\) เป็นอีกคน ทั้งสองไม่เกี่ยวกัน แต่ในอนุกรมเวลา ถ้าสลับยอดขายเดือนมกราคมกับเดือนมีนาคม เรื่องราวของข้อมูลเปลี่ยนไปทันที (Class 1, 0:01:40) ภาษาสถิติเรียกข้อมูลแบบแรกว่าเป็นอิสระต่อกัน (independent) ส่วนแบบหลังมีลำดับและมีความเกี่ยวกันตามเวลา

นิยามบนสไลด์สรุปความต่างนี้ไว้สั้น ๆ อนุกรมเวลาคือชุดของค่าที่ ordered และสังเกต ณ จุดเวลาที่ต่อเนื่องกัน ส่วน cross-sectional คือค่าที่สังเกต ณ จุดเวลาเดียว และ (time is no significance) คือเวลาไม่มีบทบาท เปรียบได้กับวิดีโอกับภาพถ่ายหมู่ วิดีโอคือภาพของสิ่งเดียวที่ถ่ายต่อเนื่อง ถ้าสลับเฟรมเรื่องจะเพี้ยน ส่วนภาพถ่ายหมู่บันทึกทุกคนในขณะเดียวกัน จะเรียงใครยืนซ้ายขวาอย่างไรก็ได้ข้อมูลเท่าเดิม

หน้านี้เพิ่มรายละเอียดสองเรื่อง เรื่องแรก cross-sectional มักมีหลายตัวแปร เช่น รายได้ อายุ และการศึกษาของ 500 คน ส่วนอนุกรมเวลามักมีตัวแปรน้อยมาก หลายครั้งมีตัวเดียว แต่มีจุดเวลามาก สไลด์เขียนว่า (usually at least 50) อาจารย์อธิบายตัวเลขนี้ว่า "มาตรฐานทั่ว ๆ ไปเขาขอ N อย่างน้อย 50 ถือว่าดี" แต่ไม่ใช่ทฤษฎีบังคับ "จริง ๆ 30 ก็พอได้อยู่" (Class 1, 0:02:49–0:03:15) เหตุผลที่ต้องมีจุดเวลามากจะชัดใน Lesson 3: เส้นขอบที่ใช้ตัดสินว่า autocorrelation ต่างจากศูนย์หรือไม่คือ \(2/\sqrt{n}\) ถ้า n = 50 ได้ 0.28 แต่ถ้า n = 20 ได้ 0.45 ข้อมูลน้อยทำให้แยกความสัมพันธ์จริงออกจากความบังเอิญได้ยาก เรื่องที่สองคืออนุกรมเวลาเป็นข้อมูล dynamic คือเปลี่ยนไปตามเวลา

หน้านี้ให้ลักษณะของอนุกรมเวลาที่มีตัวแปรเดียว (univariate) สามข้อ ข้อแรก วัด ณ เวลาที่กำหนด โดยปกติห่างเท่ากัน เช่น ทุกเดือน ข้อสอง เป็นการวัดตัวแปรเดียวกันซ้ำตามเวลา เช่น ยอดขายของร้านเดิม ข้อสาม ข้อมูลมีการเรียงลำดับ และลำดับนี้ refers generally to time คือหมายถึงเวลา ข้อที่ต้องห่างเท่ากันสำคัญในทางปฏิบัติ อาจารย์เตือนใน Class 3 ว่าถ้าข้อมูลเป็นรายวันทำการ ซึ่งข้ามวันเสาร์อาทิตย์ "ต้องระวังนิดนึง ให้มันห่างเท่า ๆ กัน" (Class 3, 1:18:16)

สไลด์กำหนดขอบเขตของวิชาว่าจะศึกษาเฉพาะอนุกรมที่วัดจาก a single continuous random variable และห่างเท่ากันใน discrete time คือวัดที่ regular time periods. คำสำคัญคือ continuous กับ discrete ความหมายเป็นดังนี้ single คือตัวแปรเดียว continuous คือค่าที่วัดเป็นทศนิยมได้ เช่น ยอดขาย 78.7 ส่วน discrete time คือเวลานับเป็นจุด ๆ เช่น ปี 1995, 1996 อาจารย์บอกว่าข้อมูลที่นับเป็นจำนวนเต็มก็ถือเป็น continuous ในวิชานี้เพื่อความง่าย (Class 1, 0:07:37)

อาจารย์ถามในห้องว่าตารางนี้มีตัวแปรกี่ตัว คำตอบคือหนึ่งตัว ได้แก่ Sales ส่วน Year ไม่ใช่ตัวแปร เป็นแค่ตัวบอกเวลา (time indicator) ค่า 78.7 คือ \(X_1\), 63.5 คือ \(X_2\), 89.7 คือ \(X_3\) ต่อไปเรื่อย ๆ (Class 1, 0:17:47–0:18:11) ตำราของวิชาเริ่มนับที่ \(X_1\) บางแหล่งเริ่มที่ \(X_0\) อาจารย์ใช้แบบ \(X_1\) ข้อนี้สำคัญเมื่อทำ regression ใน Lesson 3: ตัวแปรต้นคือ t = 1, 2, 3 ซึ่งเป็นแค่ลำดับเวลา ไม่ได้มีความหมายเชิงเหตุและผล

ตัวอย่างที่แสดงว่าลำดับคือข้อมูล: ยอดขายปี 1995 ถึง 2001 คือ 78.7, 63.5, 89.7, 93.2, 92.1, 90.1, 90.2 อ่านได้ว่าตกหนักในปี 1996 แล้วฟื้นตัวจนทรงตัวราว 90 ถ้าย้าย 63.5 ไปไว้ปี 2001 ตัวเลขชุดเดิมจะเล่าเรื่องใหม่ว่ายอดขายทรงตัวหลายปีแล้วร่วงในปีสุดท้าย ค่าเฉลี่ยและความแปรปรวนของทั้งสองแบบเท่ากันทุกประการ แต่การพยากรณ์ปี 2002 ต่างกันมาก

2. ประเภทของข้อมูลอนุกรมเวลา และเป้าหมายของการวิเคราะห์

ตารางข้อมูลทั่วไปมีคอลัมน์ตัวแปรตาม \(Y\) และตัวแปรต้น \(X_1,\dots,X_p\) แต่ละแถวเป็นอิสระต่อกัน สไลด์เพิ่มคอลัมน์ TIME และเขียนกำกับว่า TIME (DEPENDENCE) หมายความว่าแต่ละแถวขึ้นกับแถวก่อนหน้า วิธีสถิติที่เคยเรียนสมมติว่าแถวเป็นอิสระต่อกัน จึงใช้ตรง ๆ ไม่ได้ ต้องมีเครื่องมือใหม่ที่วัดว่าค่าของตัวเองในเวลาหนึ่งเกี่ยวกับค่าของตัวเองในอีกเวลาหนึ่งมากเพียงใด เครื่องมือนั้นคือ autocovariance และ ACF ในหัวข้อ 8

อาจารย์ใช้ตารางนี้อธิบายประเภทของอนุกรมเวลาที่จะเจอในวิชา (Class 1, 0:36:30–0:50:25) จัดเป็นสี่แบบ

ประเภทหน้าตาข้อมูลเป้าหมายเรียนเมื่อใด
1. Univariateคอลัมน์เดียว \(X_1,\dots,X_n\)อธิบายและพยากรณ์ตัวมันเองครึ่งแรก Lesson 1–9
2. Multivariate ที่ทุกตัวสำคัญเท่ากันหลายคอลัมน์ ทุกคอลัมน์เป็นตัวแปรตามดูว่าหลายอนุกรมส่งผลถึงกันอย่างไรVAR ในบทท้าย
3. มี Y เป็นหลัก และ X เป็นตัวเสริมY และ \(X_1,X_2,X_3\) ทุกตัวเป็นอนุกรมเวลาพยากรณ์ Y โดยใช้ X ช่วยให้แม่นขึ้น X ไม่ค่อยถูกพยากรณ์ARIMAX ในบทท้าย
4. Panel dataหลายบริษัท แต่ละบริษัทเก็บ X, Y หลายปีเทียบหลายหน่วยตามเวลาอาจไม่ได้สอน "หัวข้อใหญ่มาก"

อาจารย์ย้ำจุดที่คนสับสนบ่อย: ในข้อมูลแบบ univariate ต่อให้ใช้สัญลักษณ์ X คอลัมน์เดียวนั้นก็คือตัวแปรตาม เพราะมีตัวเดียว ไม่มีตัวแปรต้นให้เทียบ (Class 1, 0:42:16) และในแบบ panel ตัวอย่าง AIS, True และบริษัทที่สาม เก็บปี 2000 ถึง 2026 อาจารย์ถามว่ามีกี่ observation คำตอบคือ 3 observation แต่ละ observation เก็บมา 26 ปี ไม่ใช่ 78 (Class 1, 0:46:36–0:50:08)

กราฟดัชนี S&P 500 เป็นตัวอย่างของอนุกรมเวลาตัวแปรเดียว อาจารย์เรียกกราฟเส้นที่มีจุดถี่แบบนี้ว่า time series plot และบอกว่าใช้ "เห็น overall ก่อน คุณคงไม่ได้โมเดลจากกราฟนี้หรอก" (Class 1, 0:51:44–0:54:05) อ่านจากกราฟได้สามเรื่อง ช่วงปี 1965 ถึง 1980 ค่าแกว่งอยู่ระหว่างประมาณ 60 ถึง 120 ไม่ได้ขึ้นชัดเจน หลังปี 1982 ค่าเพิ่มเร็วจนถึงราว 350 ในปี 1990 คือมีแนวโน้มขาขึ้น และการแกว่งช่วงท้ายกว้างกว่าช่วงแรกมาก เช่นการร่วงในปี 1987 ทั้งสามเรื่องจะมีชื่อเรียกในหัวข้อ 3 และ 4

อ่านกราฟอนุกรมเวลาสี่ขั้น (ใช้ได้กับทุกกราฟในวิชา)
  1. ดูระดับกลางของเส้น: เลื่อนขึ้นหรือลงตามเวลาไหม ถ้าใช่คือมี trend
  2. ดูรูปแบบที่ซ้ำเป็นจังหวะ: ซ้ำทุกปีตามปฏิทินคือ seasonal ซ้ำเป็นรอบยาวไม่แน่นอนคือ cycle
  3. ดูความกว้างของการแกว่ง: กว้างขึ้นหรือแคบลงตามเวลาไหม ถ้าใช่คือความแปรปรวนไม่คงที่
  4. ดูจุดผิดปกติ: ค่าที่กระโดดออกไปครั้งเดียว (outlier) หรือระดับที่เปลี่ยนทันที (step change)

การวิเคราะห์อนุกรมเวลามีเป้าหมายสี่ข้อ ข้อแรก describe คือบรรยายลักษณะสำคัญของรูปแบบ ข้อสอง explain คืออธิบายว่าอดีตส่งผลต่ออนาคตอย่างไร หรืออนุกรมสองชุด “interact” กันอย่างไร ซึ่งตรงกับประเภทที่ 2 และ 3 ในตารางข้างบน ข้อสาม forecast คือพยากรณ์ค่าในอนาคต ข้อสี่ใช้เป็นมาตรฐานควบคุมคุณภาพในการผลิต เช่น ถ้าน้ำหนักบรรจุภัณฑ์ที่วัดได้หลุดจากช่วงที่โมเดลคาดไว้ แสดงว่าเครื่องผลิตเริ่มผิดปกติ

เรื่องการพยากรณ์ อาจารย์แยกคำว่า forecast ออกจาก predict: forecast มักหมายถึงการพยากรณ์ไปในอนาคต ส่วน predict ใช้กว้างกว่า และแบ่งการพยากรณ์เป็นสองแบบ แบบระยะสั้น (short term) คือพยากรณ์ล่วงหน้า 1 ถึง 2 จุดเวลา แบบระยะยาว (long term) เช่น 10 เดือนข้างหน้า อาจารย์ถามว่าธุรกิจใช้แบบไหน คำตอบคือส่วนใหญ่ใช้ระยะสั้น "พยากรณ์ล่วงหน้าวีกข้างหน้าพอ คุณจะได้เตรียมสินค้าได้ทัน" ส่วนภาครัฐที่ต้องการภาพในอนาคตอาจใช้ระยะยาว (Class 1, 0:54:17–0:58:50) เหตุผลเชิงทฤษฎีจะเห็นในหัวข้อ 11: ยิ่งพยากรณ์ไกล ความไม่แน่นอนยิ่งโต

3. องค์ประกอบสี่อย่าง: trend, seasonal, cycle, irregular

เมื่อดูกราฟอนุกรมเวลาสักเส้น สิ่งที่เห็นมักเป็นหลายอย่างซ้อนกันอยู่ อาจารย์ให้มองว่าอนุกรมเวลาแยกได้เป็นองค์ประกอบหลักสามถึงสี่อย่าง และจัดเป็นสองกลุ่ม กลุ่มแรกคือ signal ส่วนที่มีแบบแผนและอธิบายด้วยโมเดลได้ ได้แก่ trend, seasonal และ cycle กลุ่มที่สองคือ noise ส่วนที่สุ่มและอธิบายไม่ได้ (Class 1, 0:59:24–1:03:16) งานของทั้งวิชาคือแยกสองกลุ่มนี้ออกจากกัน เหมือนการฟังวิทยุที่สัญญาณไม่ชัด เพลงคือ signal ที่ทำนายท่อนต่อไปได้ เสียงซ่าคือ noise ที่ทำนายไม่ได้ ทำได้แค่บอกว่าดังประมาณไหน

สไลด์แสดงองค์ประกอบสี่อย่าง ตัวอย่างที่เห็นภาพ: ยอดขายของร้านหนึ่งโตขึ้นทุกปี (trend) สูงทุกเดือนธันวาคม (seasonal) ซบเซาเป็นช่วงหลายปีตามภาวะเศรษฐกิจ (cycle) และขึ้นลงรายวันโดยไม่มีเหตุผลชัดเจน (irregular) หัวข้อย่อยต่อไปอธิบายทีละอย่าง

3.1 Trend: ภาพรวมขึ้นหรือลง

Trend คือการที่ค่าโดยเฉลี่ยมีแนวโน้มเพิ่มขึ้นหรือลดลงตามเวลา อาจารย์ให้ดูภาพรวม (overall) ไม่ใช่ดูทีละจุด และเริ่มจาก linear trend คือเส้นตรงก่อน ข้อมูลที่ยาวมาก ๆ อาจมีหลาย trend ผสมกัน (Class 1, 1:02:09–1:02:53) กราฟบนเป็น trend ขาขึ้น: น้ำหนักที่วัด 25 ครั้งเริ่มที่ประมาณ 10.2 และจบที่ประมาณ 10.9 ระหว่างทางมีช่วงลดลง เช่น จาก 10.7 ที่ครั้งที่ 6 เหลือ 10.4 ที่ครั้งที่ 7 แต่ระดับเฉลี่ยยังสูงขึ้น กราฟล่างเป็น trend ขาลง: จำนวนผู้เสียชีวิตต่อการขับรถ 100 ล้านไมล์ลดจากประมาณ 5.5 ในปี 1966 เหลือประมาณ 1.7 ในปี 1994 การลดลงชั่วคราวระหว่างทางไม่ได้ลบล้าง trend เหมือนเดินขึ้นเขาที่มีทางลงสั้น ๆ เป็นช่วง ปลายทางก็ยังสูงกว่าต้นทาง

3.2 Seasonal: รูปแบบที่ซ้ำตามปฏิทิน

Seasonality คือรูปแบบสูงต่ำที่ซ้ำอย่างสม่ำเสมอ และ related to calendar time คือผูกกับปฏิทิน เช่น ฤดู ไตรมาส เดือน หรือวันในสัปดาห์ ในกราฟ จุดสูงสุดของทุกรอบตรงกับฤดูร้อนของทุกปี จึงทำนายตำแหน่งของยอดได้ล่วงหน้า และยอดของแต่ละรอบสูงกว่ารอบก่อนหน้า แปลว่ามี trend ขาขึ้นซ้อนอยู่ด้วย องค์ประกอบหลายอย่างอยู่ในเส้นเดียวกันได้

สไลด์ให้ตัวอย่างสองข้อ ยอดขายเสื้อกันหนาวในฤดูหนาวมากกว่าฤดูร้อนเสมอ และยอดขายเครื่องดื่มเย็นในฤดูร้อนมากกว่าฤดูหนาว ทั้งสองมีรอบยาวหนึ่งปีและยอดเกิดในช่วงเดิมของปฏิทิน อาจารย์ยกตัวอย่างข้อมูลการใช้ไฟฟ้าใน Class 7-1: "หน้าร้อนคนเปิดแอร์เยอะ มันก็จะเป็นรอบของมัน" (Class 7-1, 0:27:56) ตัวอย่างนี้กลับมาอีกครั้งใน Lesson 7

3.3 Cycle: รอบยาวที่ไม่ผูกกับปฏิทิน

Cycle คือการขึ้นลงที่เกิดซ้ำ แต่ the period of cycle is greater than a year คือรอบยาวกว่าหนึ่งปี กราฟยอดขายแบตเตอรี่ (พันก้อน) ปี 1991 ถึง 2011 เพิ่มจากประมาณ 44 เป็น 72 เส้นตรงที่พาดขึ้นคือ trend ระยะยาว ข้อมูลจริงวนรอบเส้นนี้เป็นสี่ระยะ คือรุ่งเรือง (Prosperity) เมื่ออยู่เหนือเส้นและถึงจุดสูงสุด ถดถอย (Recession) เมื่อเริ่มลดลง ตกต่ำ (Depression) เมื่ออยู่ใต้เส้นและถึงจุดต่ำสุด และฟื้นตัว (Recovery) เมื่อกลับขึ้น หนึ่งรอบใช้เวลาหลายปี และไม่ได้เกิดในเดือนเดิมของทุกปี

ตัวอย่างในสไลด์คือแฟชั่นที่วนกลับมาทุก 3 ปี และของเสียที่เกิดซ้ำทุก 3 ชั่วโมง ตัวอย่างหลังมีรอบสั้นกว่าหนึ่งปี แต่ยังนับเป็น cycle เพราะรอบเกิดตามจังหวะของเครื่องจักร ไม่ได้ผูกกับปฏิทิน อาจารย์อธิบายความต่างว่า seasonal มองเป็นจุดที่ซ้ำ ส่วน cycle "มองเป็นลอน มองเป็นช่วง มองไกลกว่า seasonal" (Class 1, 1:01:04) และบอกว่า cycle เป็นองค์ประกอบที่ยากที่สุด เพราะเปลี่ยนง่ายและต้องใช้ฟังก์ชันตรีโกณมิติอย่าง sin และ cos ส่วนใหญ่จึงไม่ค่อย model โดยตรง วิชานี้เน้นการวิเคราะห์ในมิติเวลา (time domain) มากกว่ามิติความถี่ (frequency domain) (Class 1, 1:04:44–1:06:21)

3.4 Irregular: ส่วนที่เหลือซึ่งอธิบายไม่ได้

Irregular คือความผันผวนระยะสั้นที่ไม่มีแบบแผน เกิดจากเหตุการณ์ที่ไม่คาดคิด สไลด์ยกตัวอย่าง flood, war, earthquake, pandemic, famines คือน้ำท่วม สงคราม แผ่นดินไหว โรคระบาด และทุพภิกขภัย สไลด์นิยามว่าเป็นส่วนที่ left over เมื่อนำ trend, seasonal และ cycle ออกแล้ว และบางครั้งเรียกว่า “noise” อาจารย์อธิบายที่มาว่าเกิดจากปัจจัยที่ควบคุมไม่ได้หรือไม่ได้เก็บไว้ในข้อมูล เช่น ช่วง Covid-19 "คุณทำโมเดลยังไงก็ตาม มันก็ต้องมีอย่างนี้โผล่มา" (Class 1, 1:08:38–1:09:10) และตั้งชื่อเฉพาะให้ error ของอนุกรมเวลาว่า white noise ซึ่งเป็นหัวข้อที่ 9 (Class 1, 1:10:04)

จำนวนผู้ยกเลิกนัดกะทันหันใน 30 วันแกว่งระหว่าง 9 ในวันที่ 13 ถึง 20 ในวันที่ 14 สองวันติดกันต่างกันถึง 11 ลองหาแบบแผนตามสี่ขั้นในหัวข้อ 2: ระดับกลางไม่ขึ้นไม่ลง เพราะค่าแรกคือ 18 และค่าสุดท้ายคือ 19 ไม่มียอดที่ซ้ำทุก 7 วัน ไม่มีคลื่นยาว และความกว้างของการแกว่งพอ ๆ กันตลอด เมื่อหา trend, seasonal และ cycle ไม่เจอ สิ่งที่เห็นคือ irregular ล้วน ๆ

4. ความแปรปรวนคงที่และไม่คงที่

นอกจากสี่องค์ประกอบ อาจารย์ให้จดอีกเรื่องหนึ่งก่อนจบคาบแรก: "ช่วยจดคำว่า constant, non-constant variance อันนี้สำคัญมาก" (Class 1, 1:15:33) เหตุผลที่อาจารย์ให้คือ "ไม่ว่าคุณจะวิเคราะห์แบบไหนก็ตาม คุณต้องให้มันแกว่งเท่ากันก่อนถึงจะเข้าโมเดลได้ ... การแยก trend แล้วแต่เทคนิค แต่การปรับให้การแกว่งคงที่เป็น requirement เกือบทุกโมเดล" (Class 1, 1:16:43–1:17:07)

คำถามของหน้านี้คือความกว้างของการแกว่งคงที่ตามเวลาหรือไม่ กราฟแรกเป็นจำนวนผู้โดยสารสายการบินปี 1949 ถึง 1961 ระดับเฉลี่ยเพิ่มจากประมาณ 120 เป็น 450 และระยะจากยอดถึงท้องในแต่ละปีกว้างขึ้นจากประมาณ 40 เป็น 200 จึงเข้าทั้งป้าย Non-constant mean และ Non-constant variance กราฟที่สองมี 100 จุดที่แกว่งรอบ 0 ตลอด ช่วงแรกแกว่งแคบประมาณ ±0.1 ช่วงท้ายแกว่งระหว่าง −2 ถึง 1 จึงมี mean คงที่แต่ variance ไม่คงที่ สองเรื่องนี้แยกจากกัน mean คือระดับกลางของเส้น variance คือความกว้างของการแกว่งรอบระดับกลาง กราฟหนึ่งอาจมีปัญหาเรื่องเดียวหรือทั้งสองเรื่อง

ทำไมการแกว่งไม่เท่ากันจึงเป็นปัญหา อาจารย์อธิบายเพิ่มใน Class 7-1 โดยเทียบกับ regression: ความแปรปรวนคงที่คือ homoscedasticity ส่วนความแปรปรวนไม่คงที่คือ heteroscedasticity ถ้าช่วงหลัง residual แกว่งมากกว่าช่วงแรก แปลว่าโมเดลอธิบายช่วงหลังได้แย่กว่า ซึ่งเป็นสัญญาณของ lack of fit (Class 7-1, 0:13:30–0:14:41) วิธีแก้ที่อาจารย์ใช้บ่อยที่สุดคือ take log เพื่อ "บีบ" ข้อมูล ซึ่งสอนเต็มใน Lesson 7 ใน Lesson 2 อาจารย์ยังเรียกความแปรปรวนของอนุกรมเวลาอีกชื่อว่า volatility (Class 2, 1:51:58)

ตัวอย่างตัวเลข: ทำไม log ทำให้การแกว่งเท่ากัน
  1. ข้อมูล

    ปีแรกยอดอยู่ระหว่าง 90 ถึง 110 ปีที่สิบยอดอยู่ระหว่าง 360 ถึง 440 ทั้งสองปีแกว่ง ±10% รอบระดับของตัวเอง

  2. ความกว้างบนข้อมูลเดิม

    ปีแรก \(110-90=20\) ปีที่สิบ \(440-360=80\) ต่างกัน 4 เท่า variance จึงไม่คงที่

  3. ความกว้างหลัง log

    ปีแรก \(\ln110-\ln90=4.7005-4.4998=0.2007\) ปีที่สิบ \(\ln440-\ln360=6.0868-5.8861=0.2007\) เท่ากันพอดี

เมื่อการแกว่งโตเป็นสัดส่วนกับระดับ การ take log ทำให้ความกว้างเท่ากัน รายละเอียดอยู่ใน Lesson 7

5. Signal กับ noise และ decomposition แบบบวกกับแบบคูณ

แนวคิดของ decomposition คืออนุกรมเวลาประกอบด้วย signal และ noise ส่วน signal (trend, seasonal, cycle) ใช้พยากรณ์ โดยยืดส่วนที่มีแบบแผนต่อไปในอนาคต สไลด์เขียนว่า Forecast extrapolate signal portion of model ส่วน noise (error, remainder, irregular) พยากรณ์ไม่ได้ แต่ขนาดของมันบอกว่าค่าจริงจะคลาดจากค่าพยากรณ์ได้ประมาณเท่าใด จึงใช้สร้างช่วงความเชื่อมั่น สไลด์เขียนว่า Confidence interval account for uncertainty อาจารย์เสริมว่า "ทุกคนคงบอกแล้วว่าโมเดลที่สร้าง ไม่มีโมเดลไหน" ถูกต้องสมบูรณ์ ส่วน noise จึงมีอยู่เสมอ (Class 1, 1:03:16)

เขียน decomposition เป็นสมการได้สองแบบ โดย \(T_t\) คือ trend, \(S_t\) คือ seasonal และ \(E_t\) คือ error แบบบวก (additive) คือ \(Y_t=T_t+S_t+E_t\) และแบบคูณ (multiplicative) คือ \(Y_t=T_t\times S_t\times E_t\) อาจารย์ถามในห้องว่าสองแบบนี้แบบไหน "เปลี่ยนแปลงได้เร็วกว่า" และสรุปว่าถ้าอนุกรมไม่ค่อยแกว่งมากขึ้นตามเวลา แบบบวกเหมาะกว่า (Class 1, 1:19:09–1:20:05) ตัวอย่างตัวเลขทำให้เห็นความต่างชัด

6. ทบทวนตัวแปรสุ่ม: E, Var, Cov และ correlation

ครึ่งหลังของสไลด์ชุดนี้เปลี่ยนจากการดูกราฟเป็นการเขียนด้วยคณิตศาสตร์ อาจารย์ใช้เวลาราว 40 นาทีแรกของ Class 2 ทบทวนเรื่องนี้ด้วยการเขียนมือ และบอกว่า "3–4 วีกแรกจะเป็นการปูพื้น ต้องใช้ความรู้ด้านสถิตินิดนึง" (Class 2, 0:00:03) เหตุผลที่ต้องทบทวนคือประโยคที่อาจารย์ย้ำ: "ความยากของอนุกรมเวลาคือแต่ละจุดเป็นตัวแปรสุ่ม ฉะนั้นมันจะมีความสัมพันธ์ระหว่างจุด" (Class 2, 0:00:13–0:01:20) เครื่องมือที่วัดความสัมพันธ์นั้นคือ covariance หัวข้อนี้จึงทบทวน covariance ให้คล่องก่อน

ตัวแปรสุ่มคือตัวแปรที่รับค่าเป็นตัวเลขตามผลของการทดลองสุ่ม ค่าของมัน can not be predicted with certainty แต่แปรผันตาม probability distribution. ตัวอย่างคือแต้มลูกเต๋า ไม่รู้ว่าครั้งหน้าจะได้แต้มอะไร แต่รู้ว่าแต่ละแต้มมีโอกาส 1 ใน 6 อาจารย์บอกว่าในวิชานี้ "การทดลองสุ่ม" ก็คือการเก็บข้อมูลนั่นเอง (Class 1, 0:23:38) และอธิบาย distribution ว่า "คือนิสัยของตัวแปรสุ่มตัวนั้น ว่ามันเคลื่อนที่ยังไง" ดูได้จาก histogram (Class 1, 0:26:02–0:28:06)

หน้านี้คือ Expectation and Variance ค่าเฉลี่ยของตัวแปรสุ่มต่อเนื่องคือ \(\mu=E(X)=\int x f_X(x)\,dx\) และความแปรปรวนคือ \(\mathrm{Var}(X)=E(X-\mu)^2\) หรือใช้สูตรลัด \(\mathrm{Var}(X)=E(X^2)-[E(X)]^2\) อาจารย์ชี้ว่าการคำนวณด้วยอินทิกรัลต้องรู้ \(f(x)\) ซึ่งในชีวิตจริงไม่รู้ จึงต้องประมาณจากข้อมูลด้วยค่าเฉลี่ยตัวอย่าง \(\bar x=\sum x_i/n\) และความแปรปรวนตัวอย่าง \(s^2=\sum(x_i-\bar x)^2/(n-1)\) และวางหลักสัญลักษณ์ว่า "ตัวกรีกแทน parameter ตัวอังกฤษแทน statistic" (Class 2, 0:01:49–0:07:44) หลักนี้ใช้ตลอดวิชา: \(\rho(h)\) คือค่าจริงที่ไม่รู้ \(\hat\rho(h)\) คือค่าที่ประมาณจากข้อมูล

ตัวอย่างตัวเลข: ลูกเต๋าหนึ่งลูก

    \(E(X)=(1+2+3+4+5+6)/6=21/6=3.5\)

  2. \(E(X^2)\)

    \((1+4+9+16+25+36)/6=91/6=15.167\)

  3. ความแปรปรวนด้วยสูตรลัด

    \(\mathrm{Var}(X)=15.167-3.5^2=15.167-12.25=2.917\)

หน้านี้คือ Covariance and Correlation covariance หรือความแปรปรวนร่วม ต้องมีตัวแปรสองตัว นิยามคือ \(\mathrm{cov}(X,Y)=E[(X-\mu_X)(Y-\mu_Y)]=E(XY)-E(X)E(Y)\) อาจารย์อธิบายความหมายว่าค่าบวกคือสองตัวไปทางเดียวกัน X มาก Y ก็มากเป็นส่วนใหญ่ ค่าลบคือสวนทาง แต่ covariance บอกได้แค่ทิศทาง ไม่ได้บอกว่าแรงแค่ไหน เพราะขนาดขึ้นกับหน่วย (Class 2, 0:13:13–0:15:13) อาจารย์ถามในห้องว่า covariance มีค่ามากสุดน้อยสุดเท่าไร นักศึกษาตอบ −1 ถึง 1 ซึ่งผิด เพราะนั่นคือช่วงของ correlation covariance อยู่ได้ตั้งแต่ลบอนันต์ถึงบวกอนันต์ (Class 2, 0:15:17–0:19:19)

เพื่อให้วัดความแรงได้ ต้องหารด้วยส่วนเบี่ยงเบนมาตรฐานของทั้งสองตัว ได้ correlation \(\rho=\mathrm{cov}(X,Y)/(\sigma_X\sigma_Y)\) ซึ่งอาจารย์เรียกว่า "standardized version ของ covariance" อยู่ระหว่าง −1 ถึง 1 และไม่มีหน่วย อาจารย์เตือนว่าการแปลงเป็นทางเดียว: covariance แปลงเป็น correlation ได้ แต่ถ้ารู้แค่ correlation จะแปลงกลับเป็น covariance ไม่ได้ เพราะไม่รู้ส่วนเบี่ยงเบนมาตรฐาน (Class 2, 0:16:07–0:20:49)

อาจารย์พูดในคลิป: "เคยออกข้อสอบ"

ถ้า X กับ Y เป็นอิสระต่อกัน แล้ว \(\mathrm{cov}(X,Y)=0\) (Class 2, 1:17:08–1:18:03) เหตุผล: เมื่ออิสระต่อกัน \(E(XY)=E(X)E(Y)\) แทนในสูตร \(\mathrm{cov}=E(XY)-E(X)E(Y)=0\)

แต่ส่วนกลับไม่จริงเสมอ สไลด์เขียนว่า (converse is not necessary true ) ตัวอย่างค้าน: ให้ X มีค่า −1, 0, 1 ด้วยโอกาสเท่ากัน และ \(Y=X^2\) จะได้ \(E(X)=0\) และ \(E(XY)=E(X^3)=(-1+0+1)/3=0\) covariance จึงเป็น 0 ทั้งที่ Y ถูกกำหนดจาก X ทั้งหมด เพราะ covariance วัดเฉพาะความสัมพันธ์เชิงเส้น ความสัมพันธ์แบบโค้งตัวยูจึงหลุดไป

7. อนุกรมเวลาคือ stochastic process

หน้านี้ตอบว่าทำไมต้องรู้เรื่องตัวแปรสุ่ม ลำดับของตัวแปรสุ่ม \(\{X_t:t=1,2,\dots,n\}\) เรียกว่า stochastic process คือกลุ่มของตัวแปรสุ่มที่มีเวลาเป็นดัชนี \(X_1\) คือค่าที่เวลา 1, \(X_2\) คือค่าที่เวลา 2 อาจารย์อธิบายจุดที่ต่างจากสถิติทั่วไป: ในสถิติทั่วไป \(x_1,\dots,x_n\) มาจากตัวแปรสุ่มตัวเดียวกัน แต่ในอนุกรมเวลา \(X_t\) แต่ละจุดเป็นตัวแปรสุ่มคนละตัว "มีตัวแปรสุ่ม n ตัว" (Class 2, 0:00:13–0:01:20)

เปรียบได้กับการทอยลูกเต๋า n ลูกเรียงกัน ลูกละหนึ่งเวลา แต่ละลูกอาจถ่วงน้ำหนักไม่เหมือนกัน ข้อมูลที่เห็นคือแต้มที่ออกหนึ่งชุด ถ้าย้อนเวลาไปทอยใหม่จะได้อีกชุดหนึ่ง แต่ในความจริงเวลาย้อนกลับไม่ได้ ข้อมูลจึงมีชุดเดียว ความยากของวิชาคือต้องเรียนรู้ลักษณะของลูกเต๋าทั้ง n ลูกจากการทอยเพียงครั้งเดียว

ข้อมูลอนุกรมเวลาสัมพันธ์กันเองเกือบทุกครั้ง เรียกว่า autocorrelated. ในกราฟ S&P 500 ค่าของปี 1983 ใกล้กับค่าของปี 1982 มากกว่าค่าของปี 1965 สไลด์ให้ทางเลือกสองทาง คือใช้ประโยชน์จากความสัมพันธ์นั้น (exploit) เพื่อพยากรณ์ หรืออย่างน้อยต้องรับมือกับมัน (cope) เพราะวิธีสถิติที่สมมติว่าข้อมูลอิสระต่อกันจะให้ผลผิดถ้ามองข้าม

ภาพนี้แสดงว่าตัวแปรสุ่มที่เรียงตามเวลามีหน้าตาอย่างไร จุดเริ่มต้น \(V_0\) เป็นค่าที่รู้แน่นอน แต่ละเวลาถัดไป ค่าที่เป็นไปได้กระจายเป็นการแจกแจงหนึ่งก้อน ศูนย์กลางของก้อนเลื่อนขึ้นตาม trend และภาพระบุว่า variance grows linearly with the forecasted horizon ยิ่งมองไปข้างหน้าไกล ก้อนยิ่งกว้าง ความไม่แน่นอนยิ่งมาก นี่คือเหตุผลเชิงทฤษฎีที่ธุรกิจชอบพยากรณ์ระยะสั้น และเป็นสิ่งเดียวกับที่จะพิสูจน์ในหัวข้อ 11: random walk มีความแปรปรวน \(t\sigma_w^2\) ซึ่งโตเป็นเส้นตรงตามเวลา

ถ้าจะอธิบายอนุกรมเวลาให้ครบสมบูรณ์ ต้องรู้การแจกแจงร่วมของ \((X_1,\dots,X_n)\) ทุกชุด คือรู้ \(P(X_1\le x_1,\dots,X_n\le x_n)\) ทุกค่า x และทุก n หมายถึงต้องรู้โอกาสของทุกเส้นทางที่ข้อมูลเป็นไปได้ ซึ่งมากเกินกว่าจะหาได้จากข้อมูลชุดเดียว

ทางออกคือระบุเฉพาะส่วนที่สำคัญ สไลด์บอกว่าวิชานี้กำหนด only the first and second-ordered moments คือค่าคาดหมายในรูป \(E(X_t)\) และ \(E(X_tX_{t-k})\) เหตุผลคือข้อมูลสำคัญส่วนใหญ่ของอนุกรมเวลาอยู่ใน first and second moments ซึ่งก็คือค่าเฉลี่ย ความแปรปรวน และ covariance moment อันดับหนึ่งให้ค่าเฉลี่ย moment อันดับสองให้ความแปรปรวนเมื่อ k = 0 และ covariance เมื่อ k ≥ 1 เปรียบเหมือนการบรรยายลักษณะคนด้วยส่วนสูงกับน้ำหนัก ไม่ครบทุกรายละเอียด แต่พอจะแยกคนส่วนใหญ่ออกจากกันได้

8. Mean function, autocovariance และ ACF

สามนิยามในหัวข้อนี้คือ moment อันดับหนึ่งและสองที่เขียนเป็นฟังก์ชันของเวลา อาจารย์อธิบายคำว่า auto ว่า "ทางซ้าย [covariance ระหว่าง X กับ Y] ใช้กับ cross-sectional คือความสัมพันธ์ระหว่างตัวแปร แต่ time series เราเล่นทางขวา คือความสัมพันธ์ระหว่างจุดเวลา เพราะคุณมีแค่ตัวแปรเดียว" autocovariance จึงแปลว่า "ความแปรปรวนร่วมในตัวมันเอง" (Class 2, 0:28:59–0:31:31)

Mean function คือ \(\mu_t=E(X_t)\) ค่าเฉลี่ยทางทฤษฎีที่เวลา t ตัวห้อย t มีไว้เพราะแต่ละเวลาอาจมีค่าเฉลี่ยไม่เท่ากัน ข้อมูลที่มี trend ขาขึ้นมี \(\mu_t\) เพิ่มตามเวลา ส่วนข้อมูลที่แกว่งรอบระดับเดิมมี \(\mu_t\) คงที่ ความต่างนี้คือเกณฑ์ข้อแรกของ stationarity ใน Lesson 2

Autocovariance function คือ \(\gamma(s,t)=\mathrm{cov}(X_s,X_t)=E[(X_s-\mu_s)(X_t-\mu_t)]=E(X_sX_t)-\mu_s\mu_t\) อาจารย์เขียนเป็น \(\gamma(s,t)\) หรือ \(\gamma_{s,t}\) และยกตัวอย่างว่า \(\gamma(1,5)\) คือความสัมพันธ์ระหว่างเดือนมกราคมกับเดือนพฤษภาคม (Class 2, 0:26:04–0:28:20) ถ้า s = t จะได้ \(\gamma(t,t)=\mathrm{Var}(X_t)\) ตามกฎข้อ 6 ค่าบวกหมายความว่า ถ้าเวลา s สูงกว่าค่าเฉลี่ย เวลา t ก็มักสูงกว่าค่าเฉลี่ยด้วย

อาจารย์เปลี่ยนวิธีเขียนให้ง่ายขึ้นด้วยแนวคิด lag แทนที่จะสนใจจุดเวลา t กับ s ทีละจุด "เราสนใจว่า t กับ s ห่างกันแค่ไหน" จึงเขียนคู่ \(X_t\) กับ \(X_{t+h}\) โดย h คือระยะห่าง เรียกว่า lag h ต่ำสุดคือ 0 ซึ่งหมายถึงจุดเดียวกัน และ \(\gamma(0)=\mathrm{Var}(X_t)\) (Class 2, 0:32:09–0:36:06) การเขียนแบบนี้ใช้ได้เต็มที่เมื่อ covariance ขึ้นกับระยะห่างอย่างเดียว ซึ่งเป็นนิยามของ stationarity ใน Lesson 2

Autocorrelation function คือ \(\rho(s,t)=\dfrac{\gamma(s,t)}{\sqrt{\gamma(s,s)\,\gamma(t,t)}}\) ซึ่งเป็น autocovariance ที่หารด้วยส่วนเบี่ยงเบนมาตรฐานของทั้งสองเวลา จึงอยู่ระหว่าง −1 ถึง 1 สไลด์ให้การตีความสามระดับ ค่าใกล้ ±1 คือ strong linear dependence ค่าใกล้ 0 คือความสัมพันธ์เชิงเส้นอ่อน และค่าเท่ากับ 0 คือ uncorrelated

อาจารย์พูดในคลิป: "สูตรแรกในหนังสือ ช่วยจด"

เมื่อเขียนด้วย lag และความแปรปรวนเท่ากันทุกเวลา ตัวหารคือ \(\sqrt{\gamma(0)\gamma(0)}=\gamma(0)\) สูตรจึงย่อเป็น

\(\rho(h)=\dfrac{\gamma(h)}{\gamma(0)}\)

อาจารย์บอกว่า "ใช้ได้ทุกอนุกรมเวลา ช่วยจด" (Class 2, 0:36:14–0:39:26) ผลที่ตามมาทันทีคือ \(\rho(0)=\gamma(0)/\gamma(0)=1\) เสมอ "เพราะมันคือตัวแปรเดียวกัน" (Class 2, 2:16:59) ข้อสอบที่ให้หา ACF จึงเริ่มจากหา \(\gamma(h)\) ทุก lag แล้วหารด้วย \(\gamma(0)\)

ตัวอย่างอุ่นเครื่อง: \(X_t=5+w_t\) โดย \(w_t\) อิสระต่อกัน ค่าเฉลี่ย 0 ความแปรปรวน 4
  1. Mean function

    \(\mu_t=E(5)+E(w_t)=5+0=5\) เท่ากันทุกเวลา

  2. \(\gamma(0)\)

    \(\mathrm{Var}(5+w_t)=\mathrm{Var}(w_t)=4\) การบวกค่าคงที่ไม่เปลี่ยนการแกว่ง

  3. \(\gamma(h)\) เมื่อ \(h\ne0\)

    \(\mathrm{cov}(5+w_t,\,5+w_{t+h})=\mathrm{cov}(w_t,w_{t+h})=0\) เพราะอิสระต่อกัน

  4. ACF

    \(\rho(0)=4/4=1\) และ \(\rho(h)=0/4=0\) เมื่อ \(h\ne0\)

9. White noise

อาจารย์เรียก white noise ว่า "อนุกรมเวลาตัวแรกที่ต้องรู้" ลักษณะคือ "ไม่มี pattern อะไรเลย" (Class 2, 1:18:42) ฟังดูไม่น่าสนใจ แต่ทุกโมเดลในวิชาสร้างจากมัน MA สร้างจากผลรวมของ white noise, AR คือค่าในอดีตบวก white noise และเมื่อสร้างโมเดลเสร็จ สิ่งที่เหลือควรเป็น white noise อาจารย์เชื่อมชื่อนี้กับหนังสยองขวัญเรื่อง White Noise ที่เสียงซ่าจากวิทยุแกว่งแบบสุ่ม เพื่อให้จำว่า white noise คือ "การแกว่งแบบ random" (Class 1, 1:10:13–1:13:18)

นิยามแรกบนสไลด์: white noise คือกลุ่มของตัวแปรสุ่มที่ uncorrelated เขียนว่า \(w_t\) มีค่าเฉลี่ย 0 และความแปรปรวน \(\sigma_w^2\) เขียนย่อว่า \(w_t\sim wn(0,\sigma_w^2)\) กราฟแกว่งขึ้นลงถี่รอบศูนย์ ความกว้างเท่าเดิมตั้งแต่ต้นจนจบ และไม่มีช่วงที่ค่าเกาะกลุ่มสูงหรือต่ำติดกันนาน ค่าก่อนหน้าไม่ได้บอกอะไรเกี่ยวกับค่าถัดไป นี่คือความหมายของ uncorrelated เมื่อมองจากกราฟ

นิยามที่เข้มขึ้น: white noise คือลำดับของตัวแปรสุ่มที่ independent and identically distributed (iid) มี \(E(w_t)=0\), \(\mathrm{Var}(w_t)=\sigma_w^2\) และ \(\sigma_w^2\) เป็นค่าคงที่ ( free of 𝑡 ) อาจารย์อธิบายว่าอนุกรมทั่วไป \(X_1\) กับ \(X_5\) อาจมีการแจกแจงต่างกัน แต่ white noise มีการแจกแจงเหมือนกันทุกเวลา (identically distributed) และไม่ขึ้นกับกันเลย (independent) (Class 2, 1:18:42–1:21:29) คำว่า independent เข้มกว่า uncorrelated: uncorrelated ห้ามแค่ความสัมพันธ์เชิงเส้น ส่วน independent ห้ามความสัมพันธ์ทุกรูปแบบ

ถ้าการแจกแจงเป็นแบบปกติ เขียนว่า \(w_t\sim iid\ N(0,\sigma_w^2)\) เรียกว่า Gaussian white noise อาจารย์บอกว่าตำราใช้แบบปกติ "เพราะความง่าย" (Class 2, 1:22:02) ถ้าเป็นการแจกแจง t ที่องศาอิสระ 3 เขียนว่า \(w_t\sim iid\ t_{df=3}\) การแจกแจง t มีหางหนากว่า จึงมีค่าโดดบ่อยกว่า แต่ยังเป็น white noise เพราะค่าเฉลี่ย 0 ความแปรปรวนคงที่ และอิสระต่อกัน

กราฟบนมี \(\sigma_w^2=1\) กราฟล่างมี \(\sigma_w^2=36\) รูปแบบเหมือนกัน ต่างกันที่สเกล อาจารย์ใช้กฎของการแจกแจงปกติอ่านกราฟ: ภายใน ±1 ส่วนเบี่ยงเบนมาตรฐานมีข้อมูลราว 68% ภายใน ±2 มีราว 95% และภายใน ±3 มีราว 99.7% (ในคลิปอาจารย์พูด 64% และ 99.6% ค่ามาตรฐานคือ 68% และ 99.7%) (Class 2, 1:26:51–1:27:53) กราฟบนมีส่วนเบี่ยงเบนมาตรฐาน 1 ค่าส่วนใหญ่จึงอยู่ระหว่าง −2 ถึง 2 กราฟล่างมีส่วนเบี่ยงเบนมาตรฐาน 6 ค่าส่วนใหญ่อยู่ระหว่าง −12 ถึง 12 ความแปรปรวนเปลี่ยนแค่ความกว้าง ไม่ได้สร้างแบบแผนใหม่

หา autocovariance ของ white noise โดยแยกสองกรณี เมื่อเป็นเวลาเดียวกัน \(\mathrm{cov}(w_t,w_t)=\mathrm{Var}(w_t)=\sigma_w^2\) ตามกฎข้อ 6 เมื่อเป็นคนละเวลา ทั้งสองอิสระต่อกัน จึงได้ \(\mathrm{cov}(w_t,w_s)=0\) สรุปได้ว่า \(\gamma(h)=\sigma_w^2\) เมื่อ h = 0 และ \(\gamma(h)=0\) เมื่อ h ≠ 0

แทนในสูตร \(\rho(h)=\gamma(h)/\gamma(0)\) ได้ \(\rho(0)=\sigma_w^2/\sigma_w^2=1\) และ \(\rho(h)=0/\sigma_w^2=0\) เมื่อ h ≠ 0 white noise สัมพันธ์กับตัวเองเต็มที่ที่เวลาเดียวกัน และไม่สัมพันธ์กับเวลาอื่นเลย ผลนี้ไม่ขึ้นกับ t จึงเป็นตัวอย่างแรกของอนุกรมที่ stationary ใน Lesson 2

กฎสั้นที่ใช้ในทุกการพิสูจน์ของวิชา

\(\mathrm{cov}(w_i,w_j)=\sigma_w^2\) ถ้า \(i=j\) และ \(=0\) ถ้า \(i\ne j\) อาจารย์ย้ำในหลายคลาสว่าคู่ที่ต่างเวลากัน covariance เป็นศูนย์ "ต่อให้มันเป็นฟังก์ชันไม่เหมือนกัน แต่คนละจุดเวลาก็ถือว่า covariance เป็นศูนย์" (Class 2, 2:34:41–2:39:11) อาจารย์บอกด้วยว่าตัว white noise เอง "จะไม่ออกข้อสอบ เพราะมันง่ายที่สุดแล้ว" (Class 2, 2:01:55) แต่ทุกข้อสอบใช้กฎนี้

สไลด์บอกว่า white noise โดยตัวเอง uninteresting สำหรับการสร้างโมเดลให้ข้อมูลจริง แต่มีบทบาทสำคัญ อนุกรมเวลามีการแปรผันสองชนิด ชนิดแรกเป็นระบบ (systematic) เช่น trend และ seasonal ซึ่งต้องการจับใส่โมเดล ชนิดที่สองเป็นการแปรผันสุ่มที่อยู่เบื้องหลังเสมอ เป้าหมายคือดึงส่วนที่เป็นระบบออกให้หมด ถ้าทำได้ดี ส่วนที่เหลือควรเป็น white noise อาจารย์สรุปว่า "สุดท้าย หลังจากที่คุณสร้างโมเดลแล้ว สิ่งที่เหลืออยู่ก็จะเป็น white noise" (Class 1, 1:10:32) ข้อนี้คือเกณฑ์ตรวจโมเดลใน Lesson 8: ถ้า residual ยังมีแบบแผน แปลว่าโมเดลยังดึงไม่หมด เหมือนกรองกาแฟ ถ้ายังมีผงกาแฟหลุดลงแก้ว แปลว่าที่กรองยังไม่ละเอียดพอ

11. Homework: random walk with drift (เฉลยของอาจารย์ใน Class 3)

โจทย์ให้หา mean function, autocovariance และ autocorrelation ของ \(X_t=\delta+X_{t-1}+w_t\) โดย \(X_0=0\) โมเดลนี้เรียกว่า random walk with drift ค่าวันนี้เท่ากับค่าเมื่อวาน บวกค่าคงที่ \(\delta\) (drift) บวกแรงกระแทกสุ่ม เปรียบได้กับคนเมาที่เดินไปข้างหน้าก้าวละ \(\delta\) แต่เซซ้ายขวาแบบสุ่มทุกก้าว ตำแหน่งปัจจุบันคือผลรวมของทุกก้าว การเซแต่ละครั้งจึงสะสมไปตลอด อาจารย์เฉลยข้อนี้ตอนต้นของ Class 3 และเรียกว่าเป็น Shumway problem 1.8 หน้า 41 "เป็นข้อที่ต้องมีทริกนิดนึง" (Class 3, 0:00:31)

ทริกสองข้อของอาจารย์ (ใช้ได้กับทุกโจทย์ที่อ้างถึงตัวเอง)
  1. ถ้าคิดอะไรไม่ออก ลองเขียนแบบไล่ ๆ ดูก่อน คือแทน t = 1, 2, 3 จนเห็นรูปแบบ แล้วค่อยเขียนรูปทั่วไป (Class 3, 0:01:27–0:02:36)
  2. ถ้าคิด covariance ไม่ออก ลองแทนตัวเลข เช่น s = 2, t = 3 แล้วค่อยสรุปเป็นสูตร (Class 3, 0:13:11–0:14:23)
เฉลยตามวิธีของอาจารย์
  1. ไล่เขียนทีละเวลา (ทริกข้อ 1)

    \(X_1=\delta+X_0+w_1=\delta+w_1\)

    \(X_2=\delta+X_1+w_2=2\delta+w_1+w_2\)

    \(X_3=\delta+X_2+w_3=3\delta+w_1+w_2+w_3\)

  2. รูปทั่วไป

    \(X_t=t\delta+\sum_{k=1}^{t}w_k\) อาจารย์บอกว่า "มันต้องแตกมาเป็นตัวนี้ก่อนถึงจะทำได้" (Class 3, 0:05:05)

  3. Mean function

    \(E(X_t)=t\delta+\sum E(w_k)=t\delta\) ขึ้นกับ t "ส่วนใหญ่แล้ว random walk เกือบทุกตัวจะมี t มา" จึงไม่ stationary (Class 3, 0:06:02–0:07:05)

  4. ตัดค่าคงที่ออกจาก covariance

    \(\gamma(s,t)=\mathrm{cov}\big(s\delta+\sum_{k=1}^{s}w_k,\ t\delta+\sum_{k=1}^{t}w_k\big)=\mathrm{cov}\big(\sum_{k=1}^{s}w_k,\ \sum_{k=1}^{t}w_k\big)\) เพราะ \(s\delta\) และ \(t\delta\) "ไม่ใช่ตัวแปรสุ่ม เป็นแค่ time indicator" (Class 3, 0:11:32–0:12:39)

  5. แทนตัวเลข (ทริกข้อ 2)

    s = 2, t = 3: \(\mathrm{cov}(w_1+w_2,\ w_1+w_2+w_3)\) ตัวที่ตรงกันคือ \(w_1,w_2\) ได้ \(2\sigma_w^2\)

    s = 3, t = 3: ตรงกันสามตัว ได้ \(3\sigma_w^2\)   s = 2, t = 1: ตรงกันตัวเดียว ได้ \(\sigma_w^2\)

  6. สรุปเป็นสูตร

    จำนวนตัวที่ตรงกันคือเวลาที่น้อยกว่า: \(\gamma(s,t)=\min\{s,t\}\,\sigma_w^2\) อาจารย์ถามว่า "ปีกกาที่เป็นอย่างนี้ สามารถเขียนเป็นฟังก์ชันอันเดียวได้" คือใช้ min (Class 3, 0:16:03–0:16:45)

  7. ACF

    \(\rho(s,t)=\dfrac{\min\{s,t\}\sigma_w^2}{\sqrt{s\sigma_w^2}\sqrt{t\sigma_w^2}}=\dfrac{\min\{s,t\}\sigma_w^2}{\sigma_w^2\sqrt{st}}=\dfrac{\min\{s,t\}}{\sqrt{st}}\)

\(\mu_t=t\delta\), \(\gamma(s,t)=\min\{s,t\}\sigma_w^2\), \(\mathrm{Var}(X_t)=t\sigma_w^2\), \(\rho(s,t)=\min\{s,t\}/\sqrt{st}\) ทุกค่าขึ้นกับเวลา จึงไม่ stationary
จุดที่ต้องระวัง: บนกระดาน σ² ยังไม่ถูกตัด

บนกระดาษในคลิป อาจารย์เขียนผลสุดท้ายเป็น \(\min\{s,t\}\sigma^2/\sqrt{ts}\) ซึ่งยังเหลือ \(\sigma^2\) อยู่ และพูดว่า "น่าจะถูกมั้ง" (Class 3, 0:19:45) ตัวหารที่ถูกคือ \(\sqrt{t\sigma^2}\sqrt{s\sigma^2}=\sigma^2\sqrt{ts}\) σ² จึงตัดกันหมด คำตอบที่ถูกคือ \(\min\{s,t\}/\sqrt{st}\) ซึ่งไม่มีหน่วย และอยู่ระหว่าง 0 ถึง 1 ตามที่ correlation ควรเป็น อาจารย์ยังเตือนว่า "อย่าสับสน ถ้าโจทย์ถาม autocorrelation function ให้แปลงด้วย" (Class 3, 0:16:45)

ตัวอย่างตัวเลข: ที่ s = 4, t = 5 ได้ \(\rho=4/\sqrt{20}=0.894\) แต่ที่ s = 100, t = 101 ได้ \(100/\sqrt{10100}=0.995\) ยิ่งเวลาผ่านไปนาน ค่าที่อยู่ติดกันยิ่งสัมพันธ์กันสูง เพราะทั้งสองค่ามีแรงกระแทกสะสมชุดเดียวกันเกือบทั้งหมด ความแปรปรวน \(t\sigma_w^2\) ที่โตเป็นเส้นตรงคือสิ่งที่สไลด์หน้า 32 วาดเป็นก้อนการแจกแจงที่กว้างขึ้นเรื่อย ๆ

อาจารย์ให้เหตุผลว่าทำไมต้องหาสูตรเหล่านี้: "ส่วนใหญ่เราไม่รู้ว่าเป็นรูปอะไร ถ้าเราเจอ data set แล้วมันมี autocorrelation คล้าย ๆ กับที่เราทำ เราจะได้ดูว่ามันเป็นโมเดลนี้หรือเปล่า" (Class 3, 0:20:42–0:21:10)

ข้อ 15รันโค้ด

รันโค้ดนี้ใน R แล้วตอบว่า ACF ที่ lag 1 จากข้อมูลใกล้ค่าทางทฤษฎีของ \(X_t=w_t+0.5w_{t-1}\) หรือไม่ และ lag ใดเกินเส้นขอบ

set.seed(10)
w <- rnorm(200)
x <- w + 0.5 * c(0, head(w, -1))   # x_t = w_t + 0.5 w_(t-1)
x <- x[-1]                          # ตัดจุดแรกที่ยังไม่มี w ก่อนหน้า
acf(x, lag.max = 3, plot = FALSE)
var(x)
ACF lag 1–3: 0.479  0.105  0.050      var(x) = 1.212

ทฤษฎีจากข้อ 6: \(\rho(1)=0.4\), \(\rho(2)=\rho(3)=0\), \(\gamma(0)=1.25\) ค่า 0.479 สูงกว่าทฤษฎีเล็กน้อยเพราะมีข้อมูลแค่ 199 จุด เส้นขอบคือ \(2/\sqrt{199}=0.142\) มีเพียง lag 1 ที่เกินเส้น ตรงกับโมเดลที่ใช้ w ร่วมกันแค่ระยะห่างหนึ่ง

ข้อ 16รันโค้ด

รันโค้ดนี้ วาดกราฟของ random walk with drift แล้วตอบว่า (ก) ค่าที่ t = 200 ใกล้ \(t\delta\) หรือไม่ (ข) ACF ลดลงเร็วหรือช้า และสรุปว่า stationary หรือไม่

set.seed(3)
rw <- cumsum(0.2 + rnorm(200))      # delta = 0.2
plot(ts(rw)); abline(a = 0, b = 0.2, lty = 2)
rw[200]
acf(rw, lag.max = 10, plot = FALSE)
rw[200] = 43.0          (tδ = 200 × 0.2 = 40)
ACF lag 1, 5, 10: 0.985  0.921  0.840

(ก) 43.0 ใกล้ 40 ส่วนต่าง 3 มาจากผลรวมของแรงกระแทก ซึ่งมีส่วนเบี่ยงเบนมาตรฐาน \(\sqrt{200}=14.1\) จึงคลาดได้มากกว่านี้ด้วยซ้ำ เส้นประคือ mean function \(t\delta\)

(ข) ACF ลดลงช้ามาก ยังเป็น 0.840 ที่ lag 10 เกินเส้นขอบ 0.141 มาก เป็นลักษณะของอนุกรมที่ไม่ stationary ตรงกับ \(\mu_t=t\delta\) ที่ขึ้นกับเวลา

สิ่งที่ควรทำได้หลังจบบทนี้
  • บอกความต่างระหว่าง \(X_i\) กับ \(X_t\) และเหตุผลที่ลำดับคือข้อมูล
  • แยกประเภทของอนุกรมเวลาสี่แบบ และเป้าหมายสี่ข้อของการวิเคราะห์
  • ชี้ trend, seasonal, cycle, irregular และความแปรปรวนที่ไม่คงที่จากกราฟ และเลือก decomposition แบบบวกหรือคูณ
  • ใช้กฎหกข้อของ E, Var, Cov คล่อง และรู้ว่า cov = 0 ไม่ได้แปลว่าอิสระต่อกัน
  • เขียนนิยาม \(\mu_t\), \(\gamma(s,t)\), \(\rho(h)=\gamma(h)/\gamma(0)\) และสมบัติของ white noise
  • หา mean, autocovariance, ACF ของโมเดลที่เขียนด้วย w ด้วยการนับ w ที่ตรงกัน และใช้ทริก "ไล่เขียน" กับ "แทนตัวเลข" กับโมเดลที่อ้างถึงตัวเอง

2.1 สี่องค์ประกอบ: signal กับ noise

ฟังวิทยุที่สัญญาณไม่ชัด เพลงคือ signal ที่ทายท่อนต่อไปได้ เสียงซ่าคือ noise ที่ทายไม่ได้ บอกได้แค่ว่าดังประมาณไหน งานของทั้งวิชาคือแยกสองอย่างนี้ออกจากกัน15

trend คือระดับเฉลี่ยที่เพิ่มหรือลดตามเวลา ดูภาพรวม ไม่ใช่ทีละจุด กราฟบนมีช่วงลดลงสั้น ๆ แต่ปลายทางยังสูงกว่าต้นทาง กราฟล่างคือผู้เสียชีวิตต่อการขับรถ 100 ล้านไมล์ที่ลดลงต่อเนื่อง เหมือนเดินขึ้นเขาที่มีทางลงสั้น ๆ เป็นช่วง

ยอดของทุกรอบตรงกับฤดูร้อน จึงทายตำแหน่งยอดล่วงหน้าได้ และยอดแต่ละรอบสูงกว่ารอบก่อน แปลว่ามี trend ซ้อนอยู่ด้วย องค์ประกอบหลายอย่างอยู่ในเส้นเดียวกันได้ การใช้ไฟฟ้าก็เป็นรอบแบบนี้ หน้าร้อนคนเปิดแอร์มาก17 ข้อมูลนี้กลับมาใน Lesson 7

ยอดขายแบตเตอรี่วนรอบเส้น trend เป็นสี่ระยะ คือรุ่งเรือง ถดถอย ตกต่ำ และฟื้นตัว หนึ่งรอบใช้หลายปีและไม่ได้เกิดเดือนเดิมทุกปี seasonal มองเป็นจุดที่ซ้ำ ส่วน cycle มองเป็นลอนที่ไกลกว่า18 cycle ยากที่สุด เพราะเปลี่ยนง่ายและต้องใช้ sin/cos ส่วนใหญ่จึงไม่ model โดยตรง วิชานี้เน้น time domain มากกว่า frequency domain19

ทั้งสี่ซ้อนกันอยู่ และแยกได้ด้วยความยาวของรอบ: trend ยาวตลอดช่วง cycle เป็นลอนยาว seasonal เป็นรอบสั้นซ้ำถี่ ส่วน irregular คือรอยหยักไม่มีแบบแผน เกิดจากเหตุไม่คาดคิด เช่น น้ำท่วม สงคราม แผ่นดินไหว โรคระบาด ทุพภิกขภัย ช่วง Covid-19 ทำโมเดลอย่างไรก็ยังมีส่วนนี้โผล่มา20 error ของอนุกรมเวลามีชื่อเฉพาะว่า white noise ซึ่งเป็นพระเอกของตอน 421

จำนวนผู้ยกเลิกนัดใน 30 วันแกว่งแรง (สองวันติดกันต่างกันถึง 11) แต่ระดับกลางไม่ขึ้นไม่ลง ไม่มียอดซ้ำทุก 7 วัน ไม่มีลอนยาว และความกว้างพอ ๆ กันตลอด เมื่อหา trend, seasonal และ cycle ไม่เจอ สิ่งที่เห็นจึงเป็น irregular ล้วน ๆ

4. Autocovariance, ACF และ white noise

4.1 Autocovariance: covariance กับตัวเองที่เวลาอื่น

\[\mu_t=E(X_t)\qquad \gamma(s,t)=\mathrm{cov}(X_s,X_t)=E(X_sX_t)-\mu_s\mu_t\]

auto แปลว่าตัวเอง cross-sectional ใช้ covariance เทียบสองตัวแปร แต่อนุกรมเวลามีตัวแปรเดียว จึงเทียบตัวเองที่เวลาต่างกัน41 \(\mu_t\) มีตัวห้อย t เพราะแต่ละเวลาอาจมีค่าเฉลี่ยต่างกัน (มี trend ก็ต่างกัน) ซึ่งคือเกณฑ์แรกของ stationarity ใน Lesson 2

\(\gamma(1,5)\) คือความสัมพันธ์ระหว่างมกราคมกับพฤษภาคม42 และ \(\gamma(t,t)=\mathrm{Var}(X_t)\) วิธีเขียนที่ง่ายกว่าคือสนใจแค่ระยะห่าง43 เขียนคู่ \(X_t\) กับ \(X_{t+h}\) และเรียก h ว่า lag โดย \(\gamma(0)=\mathrm{Var}(X_t)\) lag h หมายถึงทุกคู่ที่ห่างกัน h ไม่ใช่ระยะจากวันแรก

4.2 ACF: สูตรแรกที่ต้องจด

\[\rho(h)=\frac{\gamma(h)}{\gamma(0)}\]

สูตรแรกในหนังสือที่ต้องจด ใช้ได้ทุกอนุกรมเวลา44 มาจาก \(\rho(s,t)=\gamma(s,t)/\sqrt{\gamma(s,s)\gamma(t,t)}\) เมื่อความแปรปรวนเท่ากันทุกเวลา ค่าใกล้ ±1 บอกความสัมพันธ์เชิงเส้นที่แรง และ \(\rho(0)=1\) เสมอเพราะเป็นตัวแปรเดียวกัน45

\(X_t=5+w_t\) เมื่อ \(w_t\) อิสระ ค่าเฉลี่ย 0 ความแปรปรวน 4: mean = 5 ทุกเวลา \(\gamma(0)=4\) (บวกค่าคงที่ไม่เปลี่ยนการแกว่ง) และ \(\gamma(h)=0\) เมื่อ h ≠ 0 ACF จึงเป็น 1 ที่ lag 0 และ 0 ที่ lag อื่น

4.3 White noise: ตัวต่อพื้นฐานของทุกโมเดล

white noise คือลูกเต๋าลูกใหม่ที่ทอยทุกวัน ไม่รู้เรื่องเมื่อวานเลย เหมือนเสียงซ่าจากวิทยุในหนัง White Noise ที่แกว่งแบบสุ่ม46 มันคืออนุกรมเวลาตัวแรกที่ต้องรู้ เพราะไม่มีแบบแผนอะไรเลย47

    หารด้วย \(\gamma(0)\): \(\rho(1)=\tfrac23\), \(\rho(2)=\tfrac13\), \(\rho(h)=0\) เมื่อ \(|h|\ge3\)

\(\mu_t=0\); \(\gamma(h)=\tfrac{3-|h|}{9}\sigma_w^2\) เมื่อ \(|h|\le2\) และ 0 เมื่อ \(|h|\ge3\); \(\rho(h)=\tfrac{3-|h|}{3}\) ผลไม่มี t จึง stationary และ ACF ที่ตัดเป็นศูนย์หลัง lag 2 คือลายเซ็นของ MA ใน Lesson 5
ลองใน R: จำลอง Example 1.9

5.2 Random walk with drift (การบ้าน)

โจทย์การบ้านท้ายสไลด์ให้หา mean, autocovariance และ ACF ของ random walk with drift ซึ่งต่างจาก Example 1.9 ตรงที่ X อ้างถึงตัวเอง

\[X_t=\prm{\delta}+X_{t-1}+\shk{w_t},\qquad X_0=0\]

ค่าวันนี้ = ค่าเมื่อวาน + drift δ + แรงกระแทกสุ่ม เหมือนคนเมาที่เดินหน้าก้าวละ δ แต่เซซ้ายขวาทุกก้าว ตำแหน่งคือผลรวมของทุกก้าว การเซจึงสะสมไปตลอด ข้อนี้คือ Shumway problem 1.8 ที่ต้องใช้ทริก58: X อ้างถึงตัวเอง จึงนับลูกบอลตรง ๆ ไม่ได้ ถ้าคิดไม่ออกให้ไล่เขียนทีละเวลา59 และถ้าคิด covariance ไม่ออกให้แทนตัวเลข60

เฉลย random walk with drift ทีละขั้น
  1. ไล่เขียนทีละเวลา

    \(X_1=\delta+w_1\), \(X_2=2\delta+w_1+w_2\), \(X_3=3\delta+w_1+w_2+w_3\)

  2. รูปทั่วไป

    \(X_t=t\delta+\sum_{k=1}^{t}w_k\) ต้องแตกเป็นรูปนี้ก่อนจึงทำต่อได้61

  3. Mean function

    \(E(X_t)=t\delta\) ขึ้นกับ t ซึ่งเป็นลักษณะของ random walk เกือบทุกตัว62

  4. ตัดค่าคงที่ออก

    \(\gamma(s,t)=\mathrm{cov}\big(\sum_{k=1}^{s}w_k,\ \sum_{k=1}^{t}w_k\big)\) เพราะ \(s\delta\), \(t\delta\) ไม่ใช่ตัวแปรสุ่ม เป็นแค่ time indicator63

  5. แทนตัวเลข

    s = 2, t = 3: ถุง \(\{w_1,w_2\}\) กับ \(\{w_1,w_2,w_3\}\) ตรงกันสองลูก ได้ \(2\sigma_w^2\) · s = 3, t = 3 ได้ \(3\sigma_w^2\) · s = 2, t = 1 ได้ \(\sigma_w^2\)

  6. สรุปเป็นสูตร

    จำนวนลูกที่ตรงกันคือเวลาที่น้อยกว่า: \(\gamma(s,t)=\min\{s,t\}\,\sigma_w^2\)64

  7. ACF

    \(\rho(s,t)=\dfrac{\min\{s,t\}\sigma_w^2}{\sqrt{s\sigma_w^2}\sqrt{t\sigma_w^2}}=\dfrac{\min\{s,t\}}{\sqrt{st}}\)

\(\mu_t=t\delta\), \(\gamma(s,t)=\min\{s,t\}\sigma_w^2\), \(\mathrm{Var}(X_t)=t\sigma_w^2\), \(\rho(s,t)=\min\{s,t\}/\sqrt{st}\) ทุกค่าขึ้นกับเวลา จึงไม่ stationary

เฉลยบนกระดานเขียนผลเป็น \(\min\{s,t\}\sigma^2/\sqrt{ts}\) ซึ่งยังเหลือ σ²65 แต่ตัวหารที่ถูกคือ \(\sigma^2\sqrt{ts}\) σ² จึงตัดกันหมด และถ้าโจทย์ถาม autocorrelation ต้องแปลงต่อจาก autocovariance เสมอ66

s = 4, t = 5 ได้ \(\rho=4/\sqrt{20}=0.894\) แต่ s = 100, t = 101 ได้ 0.995 ยิ่งเวลาผ่านไป ค่าติดกันยิ่งสัมพันธ์สูง เพราะมีแรงกระแทกสะสมชุดเดียวกันเกือบทั้งหมด จำลอง 5,000 รอบใน R ได้ค่าเฉลี่ยและความแปรปรวนตรงสูตร การจำลองแบบนี้คือเหตุผลที่วิชาสอน simulation67

ลองใน R: ยืนยันสูตร random walk ด้วยการจำลอง 5,000 รอบ 
set.seed(4)
R <- replicate(5000, cumsum(0.2 + rnorm(50)))   # drift 0.2, sigma = 1, 50 จุด ทำ 5000 รอบ
mean(R[50, ]); var(R[10, ]); var(R[50, ])
cor(R[10, ], R[20, ])                            # rho(10, 20)
mean t=50 = 9.95     ทฤษฎี tδ = 50(0.2) = 10
var  t=10 = 9.91     ทฤษฎี tσ² = 10
var  t=50 = 49.99    ทฤษฎี 50
cor(10,20) = 0.699   ทฤษฎี min(10,20)/sqrt(10·20) = 0.707

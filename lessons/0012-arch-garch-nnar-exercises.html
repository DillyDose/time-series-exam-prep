แบบฝึก Lesson 12: ARCH/GARCH และ NNAR

แบบฝึกแบ่งเป็นห้ากลุ่ม คือคำนวณ ทฤษฎี อ่านผลจาก R เลือกโมเดล และข้อสอบเก่า ข้อเลือกตอบกดแล้วเห็นผลทันที ส่วนข้อเขียนให้ลองเขียนก่อนแล้วจึงกดดูเฉลย ข้อ 12 คือข้อสอบจริง FINAL 2024 ข้อ 4 (12 คะแนน) ทำด้วย R ได้จากไฟล์ CPALL.txt ในโฟลเดอร์ข้อสอบเก่า

กลุ่ม A: คำนวณ

ข้อ 1ARCH(1)
ARCH(1) มี \(\alpha_0=0.1,\ \alpha_1=0.6\) และ \(u_{t-1}=-2\) ค่า \(\sigma_t^2\) เท่าไร
ข้อ 2GARCH(1,1) ด้วยมือ
ugarchfit ของ GARCH(1,1) ได้ omega = 0.1182, alpha1 = 0.4722, beta1 = 0.4529 (ก) เขียนสมการ σ²ₜ (ข) ถ้า \(u_{t-1}=1.5\) และ \(\sigma^2_{t-1}=1\) จง σₜ (ค) ความแปรปรวนระยะยาวเท่าไร และ volatility จะค้างนานหรือไม่

(ก) \(\sigma_t^2=0.1182+0.4722\,u_{t-1}^2+0.4529\,\sigma_{t-1}^2\) และ \(u_t=\varepsilon_t\sigma_t\)

(ข) σ²ₜ = 0.1182 + 0.4722(2.25) + 0.4529(1) = 1.634 จึงได้ σₜ = 1.278

(ค) ω/(1 − α₁ − β₁) = 0.1182/(1 − 0.9251) = 1.578 หรือ sd 1.256 α₁ + β₁ = 0.925 ใกล้ 1 ความผันผวนจึงค้างหลายวันก่อนกลับสู่ระดับระยะยาว

ข้อ 3นับ input และน้ำหนักของ NNAR
(ก) nnetar(watt) ได้ NNAR(16,1,9)[288] network ขนาดเท่าไร มีน้ำหนักกี่ตัว (ข) เพิ่ม xreg หนึ่งตัวแล้ว k เป็นเท่าไร

(ก) input = 16 lag + 1 seasonal lag (X_{t−288}) = 17 node, hidden 9, output 1 จึงเป็น 17-9-1 น้ำหนัก = (17 + 1) × 9 + (9 + 1) × 1 = 172 (บวก 1 คือ bias ของแต่ละ node)

(ข) input เพิ่มเป็น 18 k = (16 + 1 + 1 + 1)/2 = 9.5 ปัดเป็น 10 ตรงกับ NNAR(16,1,10)[288] ที่ R รายงาน

กลุ่ม B: ทฤษฎี

ข้อ 4ความหมายของ ARCH
ใน ARCH(1) ถ้า \(u_{t-1}\) ใหญ่กว่าปกติมาก ข้อใดถูก
ข้อ 5ทำไมต้องยกกำลังสอง
จากสมการ ARCH(1) \(u_t=\varepsilon_t\sqrt{\alpha_0+\alpha_1u_{t-1}^2}\) แสดงว่า \(u_t^2\) มีรูปแบบ AR(1) และอธิบายว่าทำไม ACF ของ u เป็นศูนย์ แต่ ACF ของ u² ไม่เป็น

ยกกำลังสอง: \(u_t^2=\varepsilon_t^2(\alpha_0+\alpha_1u_{t-1}^2)\) เขียนใหม่เป็น \(u_t^2=\alpha_0+\alpha_1u_{t-1}^2+w_t\) โดย \(w_t=(\varepsilon_t^2-1)(\alpha_0+\alpha_1u_{t-1}^2)\) มีค่าเฉลี่ยศูนย์เพราะ E(ε²) = 1 จึงเป็น AR(1) ที่ φ = α₁ ACF ของ u² ที่ lag h จึงประมาณ α₁ʰ

ส่วน \(E(u_tu_{t-1})=E(\varepsilon_t)E(\sigma_tu_{t-1})=0\) เพราะ ε_t ค่าเฉลี่ยศูนย์และไม่สัมพันธ์กับอดีต u จึงไม่สัมพันธ์กัน ขนาดส่งต่อกันได้แต่ทิศส่งต่อไม่ได้

ข้อ 6NNAR กับ ARIMA
NNAR(p,P,0)ₛ ที่ไม่มี hidden node เทียบเท่าโมเดลใด

ราคาปิดหุ้นเทคโนโลยีรายวัน ช่วงประกาศงบผันผวนสูงมาก ช่วงปกติผันผวนต่ำ return กระจุกเป็นช่วง ACF ไม่ชัดเจน แต่ ACF ของ squared return ลดแบบช้า ๆ ควรเลือกโมเดลใด

กลุ่ม E: ข้อสอบเก่า (ทำด้วย R)

ข้อ 12FINAL 2024 ข้อ 4 (12 คะแนน)
\(x_t\) คืออัตราผลตอบแทนรายวันของหุ้น CPALL ปี 2566 จำนวน 278 วัน (CPALL.txt) (ก) เขียนชื่อตัวแบบที่เลือก เหตุผล และขั้นตอนการวิเคราะห์ (5 คะแนน) (ข) นำผลจาก R ที่จำเป็นพร้อมคำอธิบาย เขียนสมการตัวแบบ และสรุปผล (7 คะแนน)

(ก) ตัวแบบ GARCH(1,1) เหตุผล: เป็นอัตราผลตอบแทนหุ้น ค่าเฉลี่ยใกล้ศูนย์ แต่มีช่วงผันผวนสูงสลับต่ำ (volatility clustering) เป้าหมายคือโมเดลความแปรปรวน ขั้นตอน: 1) ADF ตรวจความนิ่ง 2) plot ดู clustering 3) ArchTest ตรวจ ARCH effect 4) ลอง p, q = 1–2 เลือกจาก Ljung-Box ของ residual², ความ significant, Jarque-Bera 5) ugarchfit และ ugarchforecast

(ข) ผล R (รันซ้ำ): ADF p = 0.01 reject จึงนิ่ง · Ljung-Box ของ x² (lag 10) p = 2e-10 มีโครงสร้างในความแปรปรวน · ArchTest χ² = 34.33, df = 12, p = 0.0006 reject มี ARCH effect

GARCH(1,1) ผ่านทั้งสามเกณฑ์ดีที่สุด ugarchfit ได้ mu = 0.032 (ไม่ sig), omega = 0.118, alpha1 = 0.472, beta1 = 0.453 สมการ: \(x_t=0.032+u_t,\ u_t=\varepsilon_t\sigma_t,\ \sigma_t^2=0.118+0.472\,u_{t-1}^2+0.453\,\sigma_{t-1}^2\) ugarchforecast ให้ sigma 5 วันข้างหน้า 0.753, 0.801, 0.844, 0.882, 0.915 เพิ่มเข้าหาระดับระยะยาว √(0.118/0.075) ≈ 1.26 สรุป: return ของ CPALL มี volatility clustering ความผันผวนของวันนี้ขึ้นกับ shock เมื่อวาน (0.47) และความผันผวนเมื่อวาน (0.45) ใกล้เคียงกัน

x <- scan("CPALL.txt"); adf.test(x); plot.ts(x); ArchTest(x)
summary(garch(x, order = c(1,1)))    # ลอง c(0,1), c(0,2), c(1,2) เทียบ
sp <- ugarchspec(variance.model = list(model = "sGARCH", garchOrder = c(1,1)),
                 mean.model = list(armaOrder = c(0,0)))
f <- ugarchfit(sp, x); f; ugarchforecast(f, n.ahead = 5)
ข้อ 13ลำดับการตรวจ
ตอนเลือก p, q ของ GARCH อาจารย์ให้ดูเกณฑ์ตามลำดับใด (สำคัญที่สุดก่อน)
สิ่งที่ควรทำได้หลังจบบทนี้
  • บอกได้ว่าเมื่อไรใช้ variance model และอ่านสัญญาณจาก ACF ของ return กับ return²
  • คำนวณ σ²ₜ ของ ARCH(p) และ GARCH(1,1) ด้วยมือ และความแปรปรวนระยะยาว
  • ทำครบห้าขั้น: ADF, plot, ArchTest, เลือก p, q ด้วย Ljung-Box/significance/JB, ugarchfit และ forecast
  • จำกับดัก garch(order = c(q,p)) กับ ugarchspec(garchOrder = c(p,q))
  • อ่าน NNAR(p,P,k)[s] ตรวจ k = (p + P + 1)/2 และรู้ว่า xreg ต้องมีค่าในอนาคต

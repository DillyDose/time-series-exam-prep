แบบฝึก Lesson 9: SARIMA

แบบฝึกแบ่งเป็นห้ากลุ่ม คือคำนวณ ทฤษฎีและพิสูจน์ อธิบายความเข้าใจ อ่านผลจาก R และรันโค้ดเองแล้วเทียบผล ข้อเลือกตอบกดแล้วเห็นผลทันที ส่วนข้อเขียนให้ลองเขียนก่อนแล้วจึงกดดูเฉลย

กลุ่ม A: คำนวณ

ข้อ 1MA(1)₁₂
\(X_t=w_t+0.6w_{t-12}\) มี ACF ที่ lag 12 เท่าใด
ข้อ 2ตะเกียบ
MA(1)×MA(1)₁₂ ที่ θ = 0.5 และ Θ = 0.5 มี ρ₁₃ เท่าใด
ข้อ 3MA(2)₁₂
\(X_t=w_t+0.5w_{t-12}+0.4w_{t-24}\) จงหา ρ₁, ρ₁₂, ρ₂₄, ρ₃₆ และบอกว่า PACF มีลักษณะอย่างไร

ρ₁ = 0 (lag ที่ไม่ใช่พหุคูณของ 12 เป็นศูนย์)

\(\rho_{12}=\dfrac{0.5+0.5(0.4)}{1+0.25+0.16}=\dfrac{0.7}{1.41}=0.496\), \(\rho_{24}=\dfrac{0.4}{1.41}=0.284\), ρ₃₆ = 0

PACF tail off ที่ lag 12, 24, 36, 48, … (เหมือน PACF ของ MA(2) แต่ย้ายไปที่พหุคูณของ 12) ตรวจด้วย ARMAacf(ma = c(rep(0,11), 0.5, rep(0,11), 0.4), lag.max = 36)

กลุ่ม B: ทฤษฎีและพิสูจน์

ข้อ 4AR(P)ₛ
AR(2)₄ มี PACF ไม่เป็นศูนย์ที่ lag ใด
ข้อ 5สัญกรณ์
\((1-0.6B)(1-B^{12})X_t=(1+0.4B^{12})w_t\) เขียนเป็นสัญกรณ์ใด
ข้อ 6พิสูจน์ (การบ้านที่อาจออกสอบ)
จงหา γ₀ และ ACF ทุก lag ของ MA(1)×MA(1)₁₂ \(X_t=(1+\theta B)(1+\Theta B^{12})w_t\) แล้วอธิบายว่าทำไม ρ₁₁ = ρ₁₃

\(X_t=w_t+\theta w_{t-1}+\Theta w_{t-12}+\theta\Theta w_{t-13}\) γ₀ = σ²(1 + θ² + Θ² + θ²Θ²) = σ²(1 + θ²)(1 + Θ²)

γ₁ = σ²(θ + Θ·θΘ) = σ²θ(1 + Θ²), γ₁₁ = σ²θΘ, γ₁₂ = σ²(Θ + θ·θΘ) = σ²Θ(1 + θ²), γ₁₃ = σ²θΘ lag อื่นเป็น 0

ρ₁ = θ/(1 + θ²), ρ₁₂ = Θ/(1 + Θ²), ρ₁₁ = ρ₁₃ = θΘ/((1 + θ²)(1 + Θ²)) เท่ากันเพราะทั้งสองมาจากผลคูณสัมประสิทธิ์คู่เดียว θ กับ Θ (lag 11 คือ θ ที่ตำแหน่ง 1 กับ Θ ที่ 12, lag 13 คือ 1 ที่ตำแหน่ง 0 กับ θΘ ที่ 13)

ข้อ 7กระจายโมเดล
จงเขียน ARIMA(1,0,0)×(1,0,0)₁₂ ด้วย B แล้วกระจายให้อยู่ในรูป \(X_t=\dots\) และบอกว่า PACF ตามทฤษฎีไม่เป็นศูนย์ที่ lag ใด

\((1-\phi B)(1-\Phi B^{12})X_t=w_t\) กระจาย \((1-\phi B-\Phi B^{12}+\phi\Phi B^{13})X_t=w_t\)

\(X_t=\phi X_{t-1}+\Phi X_{t-12}-\phi\Phi X_{t-13}+w_t\) เป็น AR(13) ที่มีแค่ lag 1, 12, 13 PACF จึงไม่เป็นศูนย์ได้ถึง lag 13 แล้วเป็นศูนย์ (มีค่าเด่นที่ 1, 12, 13) ระวังเครื่องหมายของพจน์ φΦ

กลุ่ม C: อธิบายความเข้าใจ

ข้อ 8อ่านรูปแบบ ACF
ACF ของอนุกรมรายเดือนไม่เป็นศูนย์เฉพาะ lag 1, 11, 12, 13 (ค่าที่ 11 และ 13 เล็กและเท่ากัน) ส่วน PACF tail off โมเดลใดเหมาะที่สุด
ข้อ 9ควิซ 7
ข้อใดแยก MA(2)₄ ออกจาก MA(4)₂ ได้ถูกต้อง
ข้อ 10ควิซ 7 ฉบับเต็ม
อธิบายลักษณะสำคัญของ ACF และ PACF อย่างละเอียดสำหรับ (1) AR(2)₃ (2) AR(5)₂ (3) MA(2)₄ (4) MA(4)₂

(1) AR(2)₃: ACF ไม่เป็นศูนย์เฉพาะ lag 3, 6, 9, … และ tail off lag อื่นเป็นศูนย์ PACF ไม่เป็นศูนย์ที่ lag 3, 6 แล้วเป็นศูนย์

(2) AR(5)₂: ACF tail off ที่ lag 2, 4, 6, … PACF ไม่เป็นศูนย์ที่ lag 2, 4, 6, 8, 10 แล้วเป็นศูนย์ lag คี่เป็นศูนย์ทั้งหมด

(3) MA(2)₄: ACF ไม่เป็นศูนย์ที่ lag 4, 8 แล้วเป็นศูนย์ PACF tail off ที่ lag 4, 8, 12, …

(4) MA(4)₂: ACF ไม่เป็นศูนย์ที่ lag 2, 4, 6, 8 แล้วเป็นศูนย์ PACF tail off ที่ lag 2, 4, 6, 8, 10, …

ข้อ 15รันโค้ด milk

รันส่วน US milk ของ R_codes แล้วเทียบสองโมเดล

library(TSA); data(milk)
f1 <- arima(milk, order = c(0,1,0), seasonal = list(order = c(3,1,0), period = 12), method = "ML")
f2 <- arima(milk, order = c(0,1,0), seasonal = list(order = c(0,1,1), period = 12), method = "ML")
f1; f2; AIC(f1); AIC(f2)
Box.test(residuals(f2)[-(1:13)], lag = 12, type = "Ljung", fitdf = 1)
f1: sar1 -0.9133  sar2 -0.8146  sar3 -0.6002  sigma^2 121.4  AIC() 1032.05
f2: sma1 -0.9541                                sigma^2 152.0  AIC() 1058.13
Ljung-Box f2 (lag 12): p-value = 0.003

f1 ดีกว่าทั้ง AIC, σ² และ Ljung-Box ตรงกับสไลด์ aic ที่พิมพ์ในตัว output จะต่ำกว่า AIC() 2 หน่วยเพราะโหลด TSA (1030.05 บนสไลด์)

สิ่งที่ควรทำได้หลังจบบทนี้
  • เขียน MA(Q)ₛ, AR(P)ₛ, ARMA(P,Q)ₛ ด้วย Bˢ และบอกว่าเทียบเท่า ARMA อันดับใด
  • หา ACF ของ MA(1)₁₂, MA(2)₁₂ และ MA(1)×MA(1)₁₂ รวมถึงตะเกียบที่ lag 11, 13
  • ตอบควิซ 7: ACF/PACF ของ seasonal AR/MA ทุกอันดับและทุก s
  • เขียน full SARIMA \(\phi(B)\Phi_P(B^s)\nabla^d\nabla_s^DX_t=\theta(B)\Theta_Q(B^s)w_t\) และแปลงเป็นสัญกรณ์ ARIMA(p,d,q)×(P,D,Q)ₛ
  • เขียนโมเดลจาก output ที่มี sar/sma โดยระวังเครื่องหมายของ Φ
  • วิเคราะห์ boardings และ milk ได้ครบทุกขั้น

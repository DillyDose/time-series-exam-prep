ข้อ 3คำนวณและเขียนโมเดล
VAR(1) สองตัวแปร type = "none" ได้สัมประสิทธิ์: สมการ y1: y1.l1 = 0.5, y2.l1 = 0.2 สมการ y2: y1.l1 = −0.1, y2.l1 = 0.7 (ก) เขียนสมการทั้งสองและรูปเมทริกซ์ (ข) ถ้าค่าล่าสุด y1 = 10, y2 = 20 จงพยากรณ์หนึ่งก้าวและสองก้าว

(ก) \(y_{1,t}=0.5y_{1,t-1}+0.2y_{2,t-1}+w_{1t}\), \(y_{2,t}=-0.1y_{1,t-1}+0.7y_{2,t-1}+w_{2t}\) หรือ \(\mathbf y_t=\begin{pmatrix}0.5&0.2\\-0.1&0.7\end{pmatrix}\mathbf y_{t-1}+\mathbf w_t\)

(ข) หนึ่งก้าว: y1 = 0.5(10) + 0.2(20) = 9, y2 = −0.1(10) + 0.7(20) = 13 · สองก้าว: y1 = 0.5(9) + 0.2(13) = 7.1, y2 = −0.1(9) + 0.7(13) = 8.2 พยากรณ์ทั้งสองตัวพร้อมกันโดยใช้ค่าพยากรณ์ของกันและกัน

ข้อ 6ทฤษฎี
(ก) อธิบายว่า Granger test ด้วย F-test ทำอย่างไร (สองโมเดลที่เทียบคืออะไร) (ข) ทำไม df1 ของ causality(var.a, cause = "DAX") ใน VAR(9) สี่ตัวแปรจึงเท่ากับ 27 (ค) ทำไม season = 52 จึงสร้าง dummy 51 ตัว

(ก) Model 1 (unrestricted): Y บน lag ของ Y และ lag ของ X · Model 2 (restricted): Y บน lag ของ Y อย่างเดียว F-test ดูว่าการเพิ่ม lag ของ X ลด residual sum of squares อย่างมีนัยสำคัญหรือไม่ ใน output ของ grangertest คือ Model 1 กับ Model 2

(ข) H0 คือ DAX ไม่ Granger-cause SMI, CAC, FTSE ต้องตั้งสัมประสิทธิ์ของ DAX ทุก lag (9) ในทุกสมการของตัวแปรอื่น (3) เป็นศูนย์ จึงมีข้อจำกัด 9 × 3 = 27 ข้อ

(ค) ถ้าใช้ 52 ตัว ผลรวมของ dummy ทุกตัวเท่ากับ 1 ทุกแถว ซ้ำกับค่าคงที่ (linear dependence) ประมาณไม่ได้ จึงให้สัปดาห์สุดท้ายเป็นฐาน (dummy ทุกตัวเป็น 0) ค่าของ sd แต่ละตัวคือความต่างจากสัปดาห์ฐาน

ข้อ 9อธิบาย
(ก) ARIMAX ใน R (regression with ARIMA errors) ต่างจากรูปบนสไลด์ \(\Phi(B)(1-B)^dY_t=\theta(B)w_t+\sum\alpha_iX_{it}\) อย่างไรในการตีความ α (ข) ทำไมการพยากรณ์ด้วย ARIMAX จึงต้องรู้ X ของอนาคต และถ้าไม่รู้ควรทำอย่างไร

(ก) R: \(Y_t=\beta_0+\alpha X_t+\varepsilon_t\) และ ε เป็น ARIMA α คือผลของ X ต่อค่าเฉลี่ยของ Y ในเวลาเดียวกันโดยตรง รูปบนสไลด์ X อยู่ในสมการ AR ของ Y ผลของ X จะถูกส่งต่อไปยังเวลาถัดไปผ่าน Φ(B) ผลรวมระยะยาวจึงเป็น α/Φ(1) ไม่ใช่ α

(ข) สมการมี X_t ของเวลาที่พยากรณ์ ต้องใส่ค่าจริงหรือค่าตามแผน (forecast(fit, xreg = inc_test)) ถ้าไม่รู้ต้องพยากรณ์ X ก่อน (ความคลาดเคลื่อนสะสม) หรือใช้ VAR ซึ่งพยากรณ์ทุกตัวพร้อมกัน

กลุ่ม E: รันโค้ดแล้วเทียบผล

ข้อ 13รันโค้ด uschange

รันส่วน uschange ของ R_codes (Class 10) โดยใช้ข้อมูลจาก fpp2

library(fpp2); library(forecast); library(lmtest)
data <- as.data.frame(uschange); names(data) <- tolower(names(data))
consumption <- ts(data$consumption); income <- ts(data$income)
grangertest(consumption ~ income, data = data)
con_training <- window(consumption, end = length(consumption) - 41)
con_test <- window(consumption, start = length(consumption) - 40)
inc_training <- window(income, end = length(income) - 41)
inc_test <- window(income, start = length(income) - 40)
arimax <- auto.arima(con_training, stepwise = T, approximation = F, xreg = inc_training)
arimax
accuracy(forecast(arimax, xreg = inc_test)$mean, con_test)

สิ่งที่ควรทำได้หลังจบบทนี้
  • เลือกระหว่าง ARIMA/ETS, ARIMAX/GLS และ VAR ตามโครงสร้างข้อมูล
  • อธิบาย GLS และอ่านผลเทียบกับ OLS
  • ทำ Granger test ทั้งสองทิศ รู้ H0 และไม่เปลี่ยน α หลังเห็นผล
  • เขียนสมการ ARIMAX (regression with ARIMA errors) จาก output และพยากรณ์ด้วย xreg ของอนาคต
  • อ่าน CCF โดยรู้ทิศของ lag ใน ccf(x, y)
  • นับพารามิเตอร์ของ VAR(p) เลือก p ด้วย VARselect และเขียนสมการจาก output
  • ตรวจ VAR ด้วย serial.test และ causality ($Granger) และเทียบด้วย RMSE ใน test

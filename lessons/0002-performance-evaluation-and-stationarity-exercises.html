แบบฝึก Lesson 2: วัดความแม่นยำของการพยากรณ์ และ Stationarity

แบบฝึกแบ่งเป็นห้ากลุ่ม คือคำนวณ ทฤษฎีและพิสูจน์ อธิบายความเข้าใจ อ่านผลจาก R และรันโค้ดเองแล้วเทียบผล ข้อเลือกตอบกดแล้วเห็นผลทันที ส่วนข้อเขียนให้ลองเขียนก่อนแล้วจึงกดดูเฉลย

ข้อสอบเก่าที่ออกจากบทนี้ และแม่แบบคำตอบ

ข้อ "นิ่งหรือไม่" ออกในข้อสอบปลายภาคทุกชุดที่มี และในชุดล่าสุด (2025) เป็นข้อแรกของข้อสอบ อาจารย์บอกให้ยึดชุดล่าสุดเป็นหลัก ส่วนเรื่องวัดความแม่นยำ ปี 2025 ใช้ RMSE บน test set เป็นคะแนนก้อนใหญ่ที่สุดของภาค R (8 คะแนนในข้อ 5g) เวลาสอบประมาณ 4.5 นาทีต่อคะแนน

แม่แบบคำตอบ: "อนุกรมนี้นิ่งหรือไม่" (ให้เขียนครบทุกขั้นแม้คำตอบจะชัด)
  1. Mean: หา \(E(X_t)\) แล้วเขียนว่า "ขึ้นกับ t" หรือ "ไม่ขึ้นกับ t"
  2. Variance: หา \(\gamma(0)\) และระบุว่ามีค่าจำกัด
  3. Autocovariance: หา \(\gamma(h)\) ทุก h แยกกรณี (เทคนิคจาก Lesson 1 หัวข้อ 12) แล้วเขียนว่า "ขึ้นกับ h อย่างเดียว" หรือ "ขึ้นกับ t"
  4. สรุป: "จึงเป็น (ไม่เป็น) weakly stationary" ถ้าไม่นิ่ง ให้บอกว่าข้อไหนไม่ผ่าน ถ้าข้อ 1 ไม่ผ่าน ไม่ต้องทำต่อก็ได้ แต่ให้เขียนเหตุผลชัด
กับดักที่พบในข้อสอบเก่าวิธีหลบ
ผลคูณ \(w_tw_{t-1}\) ดูเหมือนไม่เชิงเส้นจนคิดว่าไม่นิ่งนิ่งได้ ให้คำนวณจริง เพราะ independence ทำให้แยก expectation ของผลคูณได้
uncorrelated ทุก lag แล้วสรุปว่าเป็น iidไม่จริง ต้องตรวจความสัมพันธ์ของ \(X_t^2\) ด้วย (ข้อ ก ส่วนท้าย)
mean ไม่เป็น 0 แล้วคิดว่าไม่นิ่งนิ่งได้ ขอแค่ mean ไม่ขึ้นกับ t เช่น \(E(\nabla X_t)=-2\)
หยุดไล่ γ(h) ที่ lag ที่เป็น 0 ตัวแรกต้องไล่จนถึงระยะห่างมากที่สุดในสมการ (กับดักของ \(w_t-w_{t-3}\) ในตอนที่ 4 ของบทเรียน)
ข้อ กFinal 2025 ข้อ 1 (5 คะแนน)
ให้ \(X_t=w_tw_{t-1}\) โดย \(w_t\) เป็น white noise \(N(0,\sigma^2)\) จงตรวจว่า \(\{X_t\}\) เป็น stationary หรือไม่ แสดงวิธีทำ

Mean: \(w_t\) กับ \(w_{t-1}\) อิสระกัน จึงได้ \(E(X_t)=E(w_t)E(w_{t-1})=0\) ไม่ขึ้นกับ t

Variance: \(\gamma(0)=E(w_t^2w_{t-1}^2)=E(w_t^2)E(w_{t-1}^2)=\sigma^4\) มีค่าจำกัด

γ(1): \(E(X_tX_{t+1})=E(w_tw_{t-1}\cdot w_{t+1}w_t)=E(w_t^2)E(w_{t-1})E(w_{t+1})=\sigma^2\cdot0\cdot0=0\)

γ(h), |h| ≥ 2: \(E(w_tw_{t-1}w_{t+h}w_{t+h-1})\) มี w สี่ตัวที่ต่างกันหมด จึงเป็น 0

สรุป: mean = 0 คงที่ \(\gamma(0)=\sigma^4\) และ \(\gamma(h)=0\) เมื่อ \(h\ne0\) จึงเป็น weakly stationary และเป็น white noise ด้วย (variance \(\sigma^4\))

ส่วนเพิ่มที่ทำให้คำตอบโดดเด่น: \(X_t\) ไม่ใช่ iid เพราะ \(\mathrm{cov}(X_t^2,X_{t+1}^2)=E(w_{t-1}^2w_t^4w_{t+1}^2)-\sigma^4\cdot\sigma^4=3\sigma^8-\sigma^8=2\sigma^8\ne0\) ค่าที่ห่างกัน 1 lag ไม่สัมพันธ์กัน แต่ขนาดของมันสัมพันธ์กัน ซึ่งเป็นแนวคิดเดียวกับ ARCH/GARCH ที่สอนใน Class 11 (ตรวจด้วยการจำลองแล้ว: \(\hat\rho(1)\approx0\) และ covariance ของกำลังสองตรงกับ \(2\sigma^8\))

ข้อ ขPractice Final 1 ข้อ 1 (20 คะแนน)
ให้ \(X_t=-2t+w_t+0.5w_{t-1}\), \(w_t\sim N(0,\sigma^2)\) (a) จงแสดงว่า \(X_t\) ไม่นิ่ง (b) พิจารณา \(\nabla X_t=X_t-X_{t-1}\) อนุกรมนี้นิ่งหรือไม่

(a) \(E(X_t)=-2t\) ขึ้นกับ t จึงไม่นิ่ง ข้อนี้ข้อเดียวพอ

(b) \(\nabla X_t=[-2t+w_t+0.5w_{t-1}]-[-2(t-1)+w_{t-1}+0.5w_{t-2}]=-2+w_t-0.5w_{t-1}-0.5w_{t-2}\)

Mean: \(E(\nabla X_t)=-2\) คงที่ (ไม่เป็น 0 ก็นิ่งได้)

สัมประสิทธิ์ของ \(w_t,w_{t-1},w_{t-2}\) คือ \(1,-0.5,-0.5\)
\(\gamma(0)=(1+0.25+0.25)\sigma^2=1.5\sigma^2\)
\(\gamma(1)=[1\cdot(-0.5)+(-0.5)(-0.5)]\sigma^2=-0.25\sigma^2\)
\(\gamma(2)=[1\cdot(-0.5)]\sigma^2=-0.5\sigma^2\)
\(\gamma(h)=0\) เมื่อ \(|h|\ge3\)

สรุป: mean คงที่และ γ ขึ้นกับ h อย่างเดียว \(\nabla X_t\) จึงนิ่ง ได้ \(\rho(1)=-1/6\) และ \(\rho(2)=-1/3\) (ตรวจด้วยการจำลองแล้ว) ข้อนี้คือเหตุผลที่ differencing กำจัด linear trend ได้ ดูต่อใน Lesson 3 หัวข้อ 9

ข้อ คPractice Final 1 ข้อ 6 (5 คะแนน)
ให้ \(\mathrm{cov}(X_t,X_{t+h})=\gamma_h\) ไม่ขึ้นกับ t แต่ \(E(X_t)=3t\) จงแสดงว่า \(Y_t=7-3t+X_t\) เป็น stationary

\(E(Y_t)=7-3t+3t=7\) คงที่

\(\mathrm{cov}(Y_t,Y_{t+h})=\mathrm{cov}(X_t,X_{t+h})=\gamma_h\) เพราะ \(7-3t\) เป็นค่าคงที่ (ไม่สุ่ม) และการบวกค่าคงที่ไม่เปลี่ยน covariance

สรุป: mean คงที่และ covariance ขึ้นกับ h อย่างเดียว จึงนิ่ง นี่คือ detrending (Lesson 3 หัวข้อ 7) ที่เอาเส้น trend ที่รู้รูปแบบออก

ข้อ งFinal 2025 ข้อ 5g (ส่วนของโมเดลที่ 1)
ข้อมูลฝนรายเดือน 47 เดือน (ม.ค. 2022 ถึง พ.ย. 2025) ไฟล์ rain.txt โจทย์ให้แบ่ง train = แถว 1–36 และ test = แถว 37–47 แล้ว fit auto.arima(stepwise = TRUE, approximation = FALSE) บน train และหา RMSE บน test เขียนโค้ดให้ถูกลำดับ และระบุว่าคำตอบที่ต้องกรอกคืออะไร
library(forecast)
rain <- read.table("rain.txt", header = TRUE)
tr <- ts(rain$rain[1:36],  start = c(2022, 1), frequency = 12)
te <- ts(rain$rain[37:47], start = c(2025, 1), frequency = 12)
fit <- auto.arima(tr, stepwise = TRUE, approximation = FALSE)
fit                              # ชื่อโมเดลที่ต้องกรอกในตาราง
fc <- forecast(fit, h = length(te))
accuracy(fc, te)                 # อ่านแถว "Test set" คอลัมน์ RMSE

ผลที่รันจริง: ได้ ARIMA(0,0,0)(0,1,0)[12] with drift และ RMSE บน test = 4.846 (ตรวจด้วยสูตร \(\sqrt{\text{mean}((te-\hat y)^2)}\) ได้ค่าเดียวกัน)

สิ่งที่ต้องระวังจากบทนี้:

  • ต้องตั้ง frequency = 12 ก่อน ถ้าลืม auto.arima จะไม่เห็น seasonality และได้โมเดลอื่น
  • ลำดับใน accuracy(พยากรณ์, ค่าจริง) ต้องเอาค่าพยากรณ์ขึ้นก่อน ถ้าสลับ RMSE และ MAE ยังเท่าเดิม (4.846) แต่ ME กลับเครื่องหมายจาก +1.071 เป็น −1.071 และ MAPE เปลี่ยนจาก 7.181 เป็น 7.025 (กับดักเดียวกับตอนที่ 2 ของบทเรียน)
  • อาจารย์ขอให้รายงานค่าของ test set เท่านั้น ห้ามเอาแถว Training set ไปกรอก
  • การแบ่งเป็นแบบ fixed partition ตามตอนที่ 1 ของบทเรียน ตัดตามเวลา ห้ามสุ่ม

กลุ่ม B: ทฤษฎีและพิสูจน์

ข้อ 5พิสูจน์ (แนวควิซ)
ให้ \(x_t=w_t+\theta w_{t-1}^2\), \(w_t\sim N(0,\sigma^2)\) จงหา mean function, \(\gamma(0)\), \(\gamma(1)\) และสรุปว่า stationary หรือไม่

\(E(x_t)=0+\theta E(w_{t-1}^2)=\theta\sigma^2\) คงที่

\(\gamma(0)=\mathrm{Var}(w_t)+\theta^2\mathrm{Var}(w_{t-1}^2)=\sigma^2+\theta^2(3\sigma^4-\sigma^4)=\sigma^2+2\theta^2\sigma^4\)

\(\gamma(1)=\mathrm{cov}(w_t+\theta w_{t-1}^2,\ w_{t+1}+\theta w_t^2)=\theta\,\mathrm{cov}(w_t,w_t^2)=\theta[E(w^3)-E(w)E(w^2)]=0\)

\(\gamma(h)=0\) เมื่อ h ≥ 2 เพราะไม่มีตัวร่วม สรุป stationary

ข้อ 6พิสูจน์
ให้ \(x_t=2w_t+w_{t-2}\), \(w_t\sim wn(0,\sigma^2)\) จงหา \(\gamma(h)\) ทุก h และ ACF แล้วสรุปว่า stationary หรือไม่

\(E(x_t)=0\)

\(\gamma(0)=(4+1)\sigma^2=5\sigma^2\)

\(\gamma(1)\): \(x_{t+1}=2w_{t+1}+w_{t-1}\) ไม่มีตัวร่วมกับ \(w_t,w_{t-2}\) จึงเป็น 0

\(\gamma(2)\): \(x_{t+2}=2w_{t+2}+w_t\) ตัวร่วมคือ \(w_t\) (2 กับ 1) ได้ \(2\sigma^2\)

\(\gamma(h)=0\) เมื่อ \(|h|\ge3\) ACF: \(\rho(1)=0\), \(\rho(2)=2/5\) สรุป stationary สังเกตว่า lag 1 เป็น 0 แต่ lag 2 ไม่เป็น 0 จึงต้องไล่ทุก lag จนถึงระยะห่างสูงสุดในสมการ

ข้อ 7ทฤษฎี
จงพิสูจน์ว่าถ้า \(\{X_t\}\) เป็น strictly stationary และมีความแปรปรวนจำกัด แล้ว \(E(X_t)\) คงที่ และ \(\mathrm{cov}(X_t,X_s)\) ขึ้นกับ \(|t-s|\) เท่านั้น

n = 1: การแจกแจงของ \(X_t\) เหมือนของ \(X_{t+h}\) ทุก h ทุกเวลาจึงมีการแจกแจงเดียวกัน \(E(X_t)\) และ \(\mathrm{Var}(X_t)\) จึงคงที่

n = 2: การแจกแจงร่วมของ \((X_t,X_s)\) เหมือนของ \((X_{t+h},X_{s+h})\) เลือก h = −s ได้การแจกแจงของ \((X_{t-s},X_0)\) ซึ่งขึ้นกับ t − s เท่านั้น covariance ที่คำนวณจากการแจกแจงนี้จึงขึ้นกับ \(|t-s|\) เท่านั้น

กลุ่ม C: อธิบายความเข้าใจ

ข้อ 8Partition
ทำไมห้ามสุ่มแบ่งอนุกรมเวลาเป็น train กับ test
ข้อ 9Strong กับ weak
ข้อใดถูกเกี่ยวกับ strictly และ weakly stationary
ข้อ 10Roll-forward
แผนภาพหนึ่ง train ทุกรอบเริ่มจุดเดิมและยาวขึ้นเรื่อย ๆ ส่วน test อยู่ถัดจาก train เสมอ เป็นการแบ่งแบบใด
ข้อ 11อธิบาย
จงอธิบายว่าทำไม stationarity สำคัญต่อการสร้างโมเดล และกลยุทธ์ของวิชากับข้อมูลจริงที่ส่วนใหญ่ไม่นิ่งคืออะไร

ข้อมูลจริงมีค่าเดียวต่อเวลา ถ้าค่าเฉลี่ยและ covariance เปลี่ยนทุกเวลา จะประมาณค่าเหล่านั้นไม่ได้ เมื่อนิ่ง กติกาไม่เปลี่ยนตามเวลา ทุกจุดช่วยกันประมาณค่าชุดเดียว ทำให้ model ง่ายและพยากรณ์ได้ (predictable) ทฤษฎีส่วนใหญ่จึงสร้างบนอนุกรมที่นิ่ง

กลยุทธ์: ดึงส่วนที่ไม่นิ่งออกก่อน (trend ด้วย detrending หรือ differencing, ความแปรปรวนด้วย log) นำส่วนที่นิ่งไปสร้างโมเดล แล้วปรับกลับทีหลัง

ข้อ 14รันโค้ด

แบ่ง temp.txt เป็น train และ test ตามสไลด์ แล้วลองพยากรณ์ test ด้วยสองวิธีง่าย ๆ (ก) ใช้ค่าเฉลี่ยของ train (ข) ใช้ค่าสุดท้ายของ train จากนั้นเทียบ RMSE, MAE และ ME ของสองวิธี วิธีไหนดีกว่า และ ME บอกอะไร

x  <- ts(read.table("temp.txt"), start = 1856)
tr <- window(x, end = 1961); te <- window(x, start = 1962)

fb <- rep(tail(tr, 1), 36)     # (ข) ค่าสุดท้ายของ train
accuracy(fa, te); accuracy(fb, te)
(ก) ค่าเฉลี่ย train = −0.235   RMSE 0.349  MAE 0.305  ME 0.305
(ข) ค่าสุดท้าย   =  0.030   RMSE 0.174  MAE 0.141  ME 0.039

วิธี (ข) ดีกว่าทุกตัววัด เพราะข้อมูลมี trend ขาขึ้น ค่าเฉลี่ยของ train ทั้ง 106 ปีจึงต่ำกว่าช่วง test มาก ME ของวิธี (ก) เป็นบวก 0.305 เกือบเท่า MAE แปลว่าพยากรณ์ต่ำกว่าจริงเกือบทุกปี ซึ่งเป็นอาการของโมเดลที่ไม่จับ trend ข้อมูลนี้ไม่นิ่ง จึงต้องดึง trend ออกก่อน (Lesson 3)

จำลองโมเดลของ Exercise 1 ข้อ 2 แล้วเทียบ ACF จากข้อมูลกับค่าทางทฤษฎีที่คำนวณในตอนที่ 4 ของบทเรียน

set.seed(11)
w <- rnorm(2002, 0, 0.5)                          # sigma^2 = 0.25
x <- w[3:2002] - 1.2*w[2:2001] - 1.6*w[1:2000]
acf(x, lag.max = 3, plot = FALSE); var(x)
ARMAacf(ma = c(-1.2, -1.6), lag.max = 3)          # ค่าทางทฤษฎี
ACF จากข้อมูล lag 0–3: 1.000  0.149  -0.312  0.005     var(x) = 1.233
ทฤษฎี (ARMAacf):       1.000  0.144  -0.320  0.000     γ(0)  = 1.25

ค่าจากข้อมูล 2,000 จุดใกล้ค่าทางทฤษฎีทุก lag lag 3 ควรอยู่ในเส้นขอบ \(2/\sqrt{2000}=0.045\) สรุปว่าการคำนวณมือถูก และโมเดลนิ่ง ACF ตัดหลัง lag 2

สิ่งที่ควรทำได้หลังจบบทนี้
  • อธิบาย overfitting และเหตุผลที่ต้องวัด error บน test set เท่านั้น
  • แยก fixed, roll-forward แบบสะสม และแบบหน้าต่างเลื่อน และเขียนโค้ด window()
  • คำนวณ ME, MSE, RMSE, MAE, MAPE, MPE จากตาราง ตีความเครื่องหมาย และรู้ข้อเสียของ MAPE
  • ใช้ accuracy(f, x) ให้ถูกลำดับ
  • เขียนนิยามของ strictly และ weakly stationary และวิธีตรวจสองข้อ
  • ตรวจ stationarity ของโมเดลใดก็ตาม ไล่ lag ให้ครบ และใช้ moment ของการแจกแจงปกติเมื่อมี w² หรือผลคูณ

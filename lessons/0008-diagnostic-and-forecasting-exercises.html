แบบฝึก Lesson 8: Diagnostic และการพยากรณ์

แบบฝึกแบ่งเป็นห้ากลุ่ม คือคำนวณ ทฤษฎีและพิสูจน์ อธิบายความเข้าใจ อ่านผลจาก R และรันโค้ดเองแล้วเทียบผล ข้อเลือกตอบกดแล้วเห็นผลทันที ส่วนข้อเขียนให้ลองเขียนก่อนแล้วจึงกดดูเฉลย

กลุ่ม A: คำนวณ

ข้อ 1Standardized residual
โมเดลมี σ̂² = 0.09 และ residual ของจุดหนึ่งคือ 1.5 standardized residual ของจุดนั้นคือเท่าใด และควรสรุปอย่างไร
ข้อ 2พยากรณ์ AR(1)
\(X_t-50=0.8(X_{t-1}-50)+w_t\) และค่าสุดท้าย \(X_n=60\) ค่าพยากรณ์สองก้าว \(X^n_{n+2}\) คือเท่าใด
ข้อ 3Ljung-Box ด้วยมือ
ฟิต ARMA(1,1) กับข้อมูล n = 120 residual มี ACF ที่ lag 1, 2, 3 เท่ากับ 0.15, 0.10, 0.05 จงคำนวณ Q ที่ H = 3 หา df และสรุปที่ระดับ 0.05 (χ²(1) วิกฤต = 3.84)

\(Q=120(122)\left(\dfrac{0.0225}{119}+\dfrac{0.01}{118}+\dfrac{0.0025}{117}\right)=14640(0.000189+0.0000847+0.0000214)=14640(0.000294)=4.31\)

df = H − p − q = 3 − 1 − 1 = 1 เนื่องจาก 4.31 > 3.84 จึง reject H0 โมเดลยังไม่เหมาะสม แม้ ACF แต่ละ lag (0.15, 0.10, 0.05) จะอยู่ในเส้น 2/√120 = 0.183 ทั้งหมด

ข้อ 4พยากรณ์ด้วยมือ
ARMA(1,1) ของ times มี φ̂ = −0.6169, θ̂ = −0.7233, μ̂ = 0.0235, σ̂² = 1.57 ค่าสุดท้าย X₁₅₀ = −2.9693 และ residual สุดท้าย ŵ₁₅₀ = −1.9058 จงหาค่าพยากรณ์ก้าวที่ 1, 2 และช่วงพยากรณ์ 95% ของก้าวที่ 1 และ 2

ก้าว 1: \(0.0235+(-0.6169)(-2.9928)+(-0.7233)(-1.9058)=3.248\) se = √1.57 = 1.253 ช่วง 3.248 ± 1.96(1.253) = [0.792, 5.704]

ก้าว 2: \(0.0235-0.6169(3.248-0.0235)=-1.966\) se = \(\sqrt{1.57[1+(-1.3402)^2]}=2.095\) ช่วง −1.966 ± 4.106 = [−6.072, 2.141]

กลุ่ม B: ทฤษฎีและพิสูจน์

ข้อ 5MSPE
AR(1) φ = 0.5, σ² = 4 MSPE ของการพยากรณ์สองก้าวคือเท่าใด
ข้อ 6พิสูจน์
(ก) สำหรับ ARMA(1,1) \(X_t=\phi X_{t-1}+\theta w_{t-1}+w_t\) จงแสดงว่าความคลาดเคลื่อนของการพยากรณ์สองก้าวคือ \(w_{n+2}+(\phi+\theta)w_{n+1}\) (ข) สำหรับ AR(1) ที่มี mean μ จงแสดงว่า \(X^n_{n+h}=\mu+\phi^h(X_n-\mu)\) และ MSPE \(\to\gamma_0\) เมื่อ h → ∞

(ก) \(X_{n+2}=\phi X_{n+1}+\theta w_{n+1}+w_{n+2}\) แทน \(X_{n+1}=X^n_{n+1}+w_{n+1}\) ได้ \(X_{n+2}=\phi X^n_{n+1}+(\phi+\theta)w_{n+1}+w_{n+2}\) ส่วนแรกรู้ค่าเป็นค่าพยากรณ์ ส่วนที่เหลือคือความคลาดเคลื่อน MSPE = σ²[1 + (φ + θ)²]

(ข) \(X_{n+h}-\mu=\phi(X_{n+h-1}-\mu)+w_{n+h}\) แทนซ้ำ h ครั้ง ได้ \(\phi^h(X_n-\mu)+\sum_{j=0}^{h-1}\phi^jw_{n+h-j}\) ส่วนแรกคือค่าพยากรณ์ MSPE \(=\sigma^2\sum_{j=0}^{h-1}\phi^{2j}=\sigma^2\dfrac{1-\phi^{2h}}{1-\phi^2}\to\dfrac{\sigma^2}{1-\phi^2}=\gamma_0\)

ข้อ 7Ljung-Box
tsdiag ให้ p-value ของ Ljung-Box ทุก lag 1–20 อยู่ระหว่าง 0.35 ถึง 0.90 ควรสรุปอย่างไร

ข้อ 9diff ก่อน

ข้อ 10อธิบาย
ข้อมูล aerosol: ARIMA(0,1,1) มีพารามิเตอร์น้อยกว่าและ σ² ใกล้กับ ARIMA(2,1,0) (0.1966 กับ 0.1956) ทำไมสไลด์จึงเลือก ARIMA(2,1,0) และหลัก parsimony ใช้เมื่อใด

parsimony ใช้เมื่อโมเดลผ่าน diagnostic พอกัน ในกรณีนี้ ARIMA(0,1,1) มี p-value ของ Ljung-Box ต่ำกว่า 0.05 หลายจุดตั้งแต่ราว lag 7 (0.043 ที่ H = 7, 0.007 ที่ H = 20) แปลว่า residual ยังมี autocorrelation ที่ MA(1) จับไม่ได้ ส่วน ARIMA(2,1,0) ต่ำกว่า 0.05 เฉพาะ lag 18–20 จึงดีกว่า

ทั้งสองไม่ผ่าน normality (Shapiro p ≈ 0 หางหนา) จึงใช้เกณฑ์นี้แยกไม่ได้ และ ARIMA(1,1,2) ที่สไลด์ให้ลองผ่าน Ljung-Box ทุก H ที่ทดสอบ

สิ่งที่ควรทำได้หลังจบบทนี้
  • ตรวจ residual สามด้าน: normal (Shapiro, QQ), outlier (±3), ไม่สัมพันธ์ (ACF, Ljung-Box) และรู้ H0 ของแต่ละการทดสอบ
  • คำนวณ Q ของ Ljung-Box และ df = H − p − q
  • ทำ full data analysis ของอุณหภูมิและ aerosol ได้ครบทุกขั้น และเขียนข้อสรุป diagnostic
  • เขียนโมเดลจาก output โดยลบ intercept จาก X หรือ ∇X ทุกตัว
  • รู้ว่าทำไมควรใส่ d ใน arima() และ undifference ด้วย diffinv() ถ้า diff เองก่อน
  • พยากรณ์ ARMA ด้วยมือหนึ่งและสองก้าว และคำนวณ MSPE กับช่วงพยากรณ์ 95%

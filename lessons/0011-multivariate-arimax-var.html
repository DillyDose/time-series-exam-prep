1. GLS: regression ที่ error เป็น AR

1.1 ทำไม OLS ใช้กับอนุกรมเวลาไม่ได้ตรง ๆ

OLS สมมติว่า error ของแต่ละวันอิสระกัน เหมือนโยนเหรียญใหม่ทุกวัน แต่ในอนุกรมเวลา ถ้าวันนี้ทายต่ำไป พรุ่งนี้ก็มักทายต่ำไปด้วย error จึงเกาะกลุ่ม

สมัยก่อนสอน Generalized Least Square (GLS) แต่เทอมนี้ไม่สอน6 สไลด์และโค้ดยังอยู่ และเป็นฐานของ ARIMAX เพราะแก้ปัญหาเดียวกัน

\[y_t=\alpha+\beta x_t+\varepsilon_t,\qquad \Phi(B)\varepsilon_t=\shk{w_t}\]

ส่วนแรกคือ regression ปกติ ส่วนที่สองบอกว่า error เป็น AR (Lesson 5) แค่ใช้กับ residual แทนข้อมูล ถ้าไม่สนใจโครงสร้างนี้ standard error จะผิด t-test และ p-value ก็ผิดตาม ขั้นตอนคือทำ OLS เก็บ residual ดู ACF/PACF ของ residual ถ้ามี AR ก็ประมาณใหม่ด้วย gls() ของ package nlme

2. ARIMAX และ Granger causality

2.1 ARIMAX = regression ที่ error เป็น ARIMA

\[y_t=\alpha_0+\sum_{i=1}^{r}\prm{\alpha_i}X_{it}+\varepsilon_t,\qquad \varepsilon_t\sim\text{ARIMA}(p,d,q)\]

ARIMA ที่มีตัวแปรภายนอก (ARIMAX) ขยายจาก GLS โดยให้ error เป็น ARIMA ได้ทั้งหมด ไม่ใช่แค่ AR r คือจำนวนตัวแปรภายนอก ไม่ใช่พารามิเตอร์7 รูปนี้คือรูปบนกระดานและเป็นสิ่งที่ auto.arima(..., xreg = ) ทำ เรียกว่า regression with ARIMA errors

สไลด์เขียนอีกรูปหนึ่ง (Tiao และ Box 1981) \(\Phi(B)(1-B)^dY_t=\theta(B)w_t+\sum\alpha_iX_{it}\) สองรูปไม่เหมือนกันทุกประการ ในรูปของ R ค่า α คือผลของ X ต่อค่าเฉลี่ยของ Y โดยตรง ส่วนรูปบนสไลด์ ผลของ X ส่งต่อไปตามโครงสร้าง AR ด้วย

ขั้นตอนบนสไลด์และฉบับภาษาไทย (Wanida Wongwattanabundit) รวมได้ดังนี้

2.2 Granger causality: อดีตของ X ช่วยพยากรณ์ Y ไหม

พยากรณ์ยอดขายด้วยยอดขายในอดีตอย่างเดียว แล้วลองเติมงบโฆษณาในอดีตเข้าไป ถ้าพยากรณ์ดีขึ้นจริง ก็บอกว่าโฆษณา "Granger-cause" ยอดขาย ซึ่งไม่ใช่เหตุเป็นผลในความหมายทางวิทยาศาสตร์

3. MIDAS และ cross-correlation

3.1 MIDAS (แนวคิดเท่านั้น)

แนวคิดของ Mixed Data Sampling (MIDAS) regression ไม่มีโค้ดและไม่ได้ลงรายละเอียดในคลิป ใช้เมื่อ Y กับ X เก็บด้วยความถี่ต่างกัน เช่น GDP รายไตรมาสกับยอดค้าปลีกรายเดือน แทนที่จะเฉลี่ย X สามเดือนให้เป็นรายไตรมาสแล้วเสียข้อมูล MIDAS ใส่ค่ารายเดือนทั้งสามค่าเป็นตัวอธิบาย แต่ละค่ามีน้ำหนักของตัวเอง

3.2 Cross-correlation: X กับ Y สัมพันธ์กันที่ lag ไหน

\[\hat\rho_{12}(k)=\frac{\sum_{t=1}^{n-k}(X_{t+k,1}-\bar X_1)(X_{t2}-\bar X_2)}{\sqrt{\sum(X_{t1}-\bar X_1)^2}\sqrt{\sum(X_{t2}-\bar X_2)^2}}\]

ACF วัดอนุกรมกับอดีตของตัวเอง CCF ขยายไปวัดสองอนุกรมที่ lag ต่าง ๆ เป็นแค่เครื่องมือสำรวจข้อมูล ไม่ใช่โมเดลหลัก25 ใช้ช่วยตัดสินว่าควรใส่ X ที่ lag ไหน

4. VAR: แนวคิด จำนวนพารามิเตอร์ และข้อมูล var1

4.1 VAR: ทุกตัวแปรเป็นทั้งตัวตามและตัวอธิบาย

\[\mathbf X_t=\mathbf\Phi\,\mathbf X_{t-1}+\shk{\mathbf W_t}\quad\Longleftrightarrow\quad\begin{cases}X_{t1}=\prm{\phi_{11}}X_{t-1,1}+\prm{\phi_{12}}X_{t-1,2}+\shk{w_{t1}}\\ X_{t2}=\prm{\phi_{21}}X_{t-1,1}+\prm{\phi_{22}}X_{t-1,2}+\shk{w_{t2}}\end{cases}\]

VAR คือ "simultaneous model"29 แต่ละสมการคือ AR ของตัวเองบวก lag ของตัวอื่น VAR ที่เรียนมีแค่ AR term ไม่มี MA30 error สองสมการมี covariance matrix ที่มี Var(w₁), Var(w₂) และ Cov(w₁, w₂)31

ลูกศรส้มแต่ละเส้นคือ φ หนึ่งตัว เช่น φ₁₂ = 0.5 แปลว่า x₂ สัปดาห์ก่อนเพิ่ม 1 หน่วย ทำให้ x₁ สัปดาห์นี้เพิ่ม 0.5 หน่วย ต่างจาก ARIMAX ที่ลูกศรวิ่งจาก X ไป Y ทางเดียว และ VAR ไม่ต้องรู้ X ของอนาคตเพราะพยากรณ์ทุกตัวพร้อมกัน

var1 เป็นข้อมูลจำลองที่ออกแบบให้เห็นโครงสร้างชัด โค้ดใช้ 20 แถวแรก ccf(data$x1, data$x2) สูงสุดที่ lag 5 (0.835) คือ x2 นำ x1 อยู่ 5 ช่วง จึงคาดว่าในสมการของ x1 สัมประสิทธิ์หน้า lag 5 ของ x2 จะมีนัยสำคัญ36

บนสไลด์ได้ AIC = HQ = SC = 5 และ FPE = 637 สอดคล้องกับ CCF จึงเลือก VAR(5) แถว lag 6 เป็น NaN เพราะข้อมูล 20 แถวไม่พอประมาณ 13 พารามิเตอร์ต่อสมการ

สมการ x1 มีตัวเดียวที่มีนัยสำคัญคือ x2.l5 = 2.0046 (t = 117.9)38 จึงสรุปได้ว่า \(x_{1,t}\approx2x_{2,t-5}\) ตรงกับที่ CCF ชี้

สมการ x2 ไม่มีตัวไหนมีนัยสำคัญ x2 จึงแทบเป็น noise predict(fit, n.ahead = 5) ให้ fcst, lower, upper แยกแต่ละตัวแปร39 x1 พยากรณ์ได้แม่นแม้ x2 จะเดาไม่ได้ เพราะ x1 ห้าก้าวถัดไปคือสองเท่าของ x2 ที่สังเกตแล้วเมื่อ 5 ช่วงก่อน

สไลด์ต้นฉบับของตอนนี้ (หน้า 49, 51–55)

5.2 ตัวอย่าง EuStockMarkets

ตัวอย่างนี้มีไว้ให้เห็นว่า ข้อมูลที่ไม่นิ่งต้อง difference ก่อนเข้า VAR และ serial.test ที่ไม่ผ่านบอกให้เปลี่ยน p

ราคาปิดรายวันของ DAX, SMI, CAC และ FTSE มี trend ขาขึ้นทั้งหมด ADF ไม่นิ่งทุกตัว จึงใช้ stnry = diff(EuStockMarkets) แล้ว ADF ทุกตัวได้ p = 0.0144 VARselect ได้ AIC = 9 แต่ SC = 1 สไลด์เลือก p = 9 เพราะ AIC "is the most popular one"

vars::VAR(stnry, lag.max = 10, ic = "AIC", type = "none") ได้ 36 สัมประสิทธิ์ต่อสมการ รวม 144 ตัว ใช้ type = "none" เพราะผลต่างของราคามี mean ใกล้ศูนย์

residual ของ DAX กับ SMI มี correlation 0.749 แปลว่า shock ในวันเดียวกันเกิดพร้อมกันทั้งยุโรป serial.test ได้ p = 2.4 × 10⁻⁵ จึงปฏิเสธ H0 residual ยังมี autocorrelation เหลือ อาจต้องเปลี่ยน p45 สไลด์ใช้ VAR(9) ต่อ และการบ้านคือลอง p = 146

ในคลิปช่วงหนึ่งพูดว่า "อยากให้ p-value ต่ำ ๆ" ซึ่งขัดกับ H0 แล้วสรุปถูกว่า p ต่ำคือไม่ผ่าน ทางเลือกเมื่อ residual ยังสัมพันธ์คือเปลี่ยน p, เปลี่ยน type หรือใช้ log ก่อน difference (ราคาหุ้นมักใช้ผลต่างของ log คือผลตอบแทน ตาม Lesson 7 ตอน 2.4)

Granger ของทั้งสี่ดัชนีมี p ต่ำกว่า 0.05 ทุกตัว (เช่น SMI p = 7.1 × 10⁻⁶) จึงไม่ตัดตัวไหน47 df1 = 27 คือ 9 lag × 3 ตัวแปรอื่น ส่วน $Instant ที่สูงมากสะท้อน correlation ของ residual วันเดียวกันที่เห็นข้างบน

predict(var.a, n.ahead = 25) ได้สี่ดัชนีพร้อมกัน แต่เป็นค่าของผลต่าง ต้อง undifference เอง48 กับดักเดียวกับ Lesson 8 ตอน 2.4 แต่ VAR ไม่มีทางเลือก "ใส่ d ในคำสั่ง" ทางเลี่ยงคือ type = "both" ในตอน 6

Multivariate time series: GLS, ARIMAX, Granger, CCF และ VAR

อ่านประมาณ 20 นาที · ข้อความไฮไลต์คือถ้อยคำบนสไลด์ ตัวเลขยก1คือนาทีในคลิปที่รวมไว้ท้ายบท

ทุกบทก่อนหน้าพยากรณ์ Y จากอดีตของ Y เองเท่านั้น (univariate) แต่ยอดขายขึ้นกับงบโฆษณา และการบริโภคขึ้นกับรายได้ บทนี้เพิ่มตัวแปรอื่นเข้ามา การเลือกโมเดลตามโครงสร้างข้อมูลมีสามแบบ (สไลด์หน้า 50)

  • Univariate ใช้ ARIMA หรือ exponential smoothing (Lesson 4–10)
  • Univariate ที่มีตัวแปรอธิบาย ใช้ GLS, ARIMAX หรือ neural network ที่มี regressor มี Y ตัวเดียว สมการเดียว
  • Multivariate ใช้ VAR ทุกตัวแปรเป็น Y และสำคัญเท่ากัน มี n ตัวแปรก็มี n สมการ1

เครื่องมือประกอบคือ Granger causality test (X ช่วยพยากรณ์ Y ไหม) และ cross-correlation (X กับ Y สัมพันธ์กันที่ lag ไหน)

เรื่องที่ระบุว่าเกี่ยวกับข้อสอบในบทนี้มีดังนี้

  • Granger มี H0 = X does not cause Y (No Granger effect) ถ้าจะใช้ X ใน ARIMAX ต้องการ p-value ต่ำ2 ใน VAR ใช้ causality() และดูเฉพาะผล Granger3
  • ห้ามปรับ α ให้ผลมีนัยสำคัญ income→consumption ได้ p = 0.07491 การเปลี่ยน α เป็น 0.1 คือ "การแก้แบบโง่ ๆ" ปัญหาจริงคือเลือก X, Y ผิด ต้องทำ literature review4
  • เขียนสมการ ARIMAX จาก output ให้เป็น5
  • นับจำนวนพารามิเตอร์ของ VAR(p)6
  • เขียนสมการ VAR จาก output ข้อสอบคงไม่ให้เขียนครบทุก dummy แต่ต้องรู้ว่า seasonal คือ dummy sd1–sd51 และ trend คือ slope × t7
  • Portmanteau มี H0 = residual random = โมเดลเหมาะสม p ต่ำคือไม่ผ่าน8
  • ARIMAX ต้องส่ง X ของช่วง test ตอนพยากรณ์ และถ้า Y difference แล้ว X ต้อง difference ด้วย9
  • Final 40 คะแนน สอบ onsite 26 พฤศจิกายน และจะได้ข้อสอบเก่า10

1. ภาพรวม และ GLS: regression ที่ error เป็น AR

Class 10 สอนจนจบ VAR ในคาบเดียว11 สมัยก่อนสอน GLS ด้วย แต่เทอมนี้ไม่สอน12 และตัวที่น่าจะมีประโยชน์ที่สุดคือ ARIMAX13 หัวข้อของส่วนนี้คือ time series ที่มีตัวแปรอธิบาย (GLS, ARIMAX และ neural network ซึ่งเลื่อนไปคาบหน้า), cross-correlation และ VAR ARIMAX คือ ARIMA with exogenous variable ตัวแปรภายนอกคือตัวแปรที่ใช้อธิบาย Y แต่ไม่ได้ถูกพยากรณ์ในโมเดล ตารางสามแถวในหน้า 50 คือแผนที่ของทั้งวิชา เช่น ยอดขายรายเดือนอย่างเดียวใช้ ARIMA หรือ ETS ยอดขายกับงบโฆษณาที่บริษัทกำหนดเองใช้ ARIMAX (งบโฆษณาไม่ต้องพยากรณ์เพราะรู้ล่วงหน้า) ส่วนราคาหุ้นสี่ตลาดที่ต่างส่งผลต่อกันและต้องพยากรณ์ทุกตัวใช้ VAR14

GLS ไม่ได้สอนในเทอมนี้ แต่สไลด์และโค้ดยังอยู่ และเป็นฐานของ ARIMAX เพราะทั้งสองแก้ปัญหาเดียวกัน คือ regression ที่ error ไม่อิสระกัน ใน regression ทั่วไป (OLS) สมมุติว่า error อิสระกัน แต่เมื่อตัวแปรเป็นอนุกรมเวลา residual มักสัมพันธ์ข้ามเวลา ถ้าไม่สนใจโครงสร้างนี้ ค่าสัมประสิทธิ์และ standard error จะผิด โดยเฉพาะ s.e. ที่ผิดทำให้ t-test และ p-value ผิดไปด้วย โมเดลคือ \(y_t=\alpha+\beta x_t+\varepsilon_t\) และ \(\varepsilon_t=\phi_1\varepsilon_{t-1}+\dots+\phi_p\varepsilon_{t-p}+w_t\) หรือ \(\Phi(B)\varepsilon_t=w_t\) ส่วนแรกคือ regression ปกติ ส่วนที่สองคือ AR ของ error เหมือนที่เรียนใน Lesson 5 แค่ใช้กับ residual แทนข้อมูล ขั้นตอนมีสามขั้น คือทำ OLS แล้วเก็บ residual, ดูว่า residual มีโครงสร้าง AR หรือไม่ด้วย ACF/PACF และถ้ามีให้ประมาณโมเดลที่มี AR error แล้วตรวจความเหมาะสม ในทางปฏิบัติใช้ฟังก์ชัน gls() ของ package nlme ทำครั้งเดียว ข้อมูลตัวอย่าง revenue.txt มี 76 จุดเวลา Y คือ revenue X คือ growth ปัญหาคือ error สัมพันธ์กัน

ACF ของ residual ทะลุเส้นที่ lag 1 (ราว 0.6) และ lag 2 แล้วลดลง ส่วน PACF ทะลุแค่ lag 1 จึงเป็น AR(1) ของ error durbinWatsonTest(model) ยืนยัน: autocorrelation lag 1 = 0.636, D-W statistic = 0.695 (ค่าที่ไม่มี autocorrelation คือราว 2) p-value ≈ 0

output ของ gls() ให้ทั้งสัมประสิทธิ์ regression และ φ ของ AR(1) ใน error เทียบกับ OLS ได้ดังกล่องข้างล่าง

เทียบ OLS กับ GLS (รันจาก R_codes ของ Class 10)

    revenue = 36001.83 + 1.610 growth, s.e. ของ growth = 0.202, t = 7.96

  2. GLS ที่ error เป็น AR(1)

    gls(revenue ~ growth, correlation = corAR1(form = ~time)): revenue = 35986.21 + 1.652 growth, s.e. = 0.117, t = 14.15 และ φ = 0.668

  3. เขียนโมเดล

    \(\mathrm{Revenue}_t=35986.21+1.65\,\mathrm{growth}_t+\varepsilon_t\), \(\varepsilon_t=0.6681\varepsilon_{t-1}+w_t\)

ค่าสัมประสิทธิ์เปลี่ยนเล็กน้อย แต่ s.e. ต่างกันเกือบสองเท่า OLS ที่ไม่สนใจ autocorrelation ให้ s.e. ที่ไม่ถูกต้อง ช่วงความเชื่อมั่นและ p-value จึงผิดตาม

2. ARIMAX, Granger causality และข้อมูล uschange

ARIMAX ขยายจาก GLS โดยให้ error เป็น ARIMA ได้ทั้งหมด ไม่ใช่แค่ AR เสนอโดย Tiao และ Box (1981) คือ ARIMA ที่เติมตัวแปรอิสระ r ตัวทางขวามือ \(\Phi(B)(1-B)^dY_t=\theta(B)w_t+\sum_{i=1}^r\alpha_iX_{it}\) บนกระดานเขียนอีกรูปหนึ่งว่า \(y_t=\alpha_0+\sum\alpha_iX_{it}+w_t\) โดย \(w_t\) เป็น ARIMA(p,d,q) และ r คือจำนวนตัวแปรภายนอก ไม่ใช่พารามิเตอร์15 สองรูปนี้ไม่เหมือนกันทุกประการ R (auto.arima(..., xreg = )) ใช้รูปของกระดาน เรียกว่า regression with ARIMA errors ซึ่ง α คือผลของ X ต่อค่าเฉลี่ยของ Y โดยตรง ส่วนรูปบนสไลด์ ผลของ X ส่งต่อไปตามโครงสร้าง AR ด้วย

ขั้นตอนบนสไลด์คือ ตรวจความนิ่งของ Y (difference ถ้าจำเป็น), หา p, q จาก ACF/PACF, ประมาณสัมประสิทธิ์และตรวจ residual, ทำขั้นเดียวกันกับตัวแปร X และใช้ cross-correlation ระหว่าง Y กับ X กำหนดโครงสร้าง lag ปัจจุบัน auto.arima ทำขั้น p, q ให้ ขั้นตอนฉบับภาษาไทย (Wanida Wongwattanabundit) เพิ่มรายละเอียดที่ใช้ได้จริง

  • ตรวจ stationary ด้วย ADF และตัวแปรภายนอกต้อง difference ระดับเดียวกับตัวแปรตาม
  • ใช้ Granger test คัดตัวแปรภายนอกที่ส่งผลต่อตัวแปรตาม แต่ตัวแปรตามต้องไม่ส่งผลย้อนกลับ ที่ระดับนัยสำคัญ 0.05 แล้วสร้าง regression ด้วย forward/backward stepwise
  • ตรวจความนิ่งของ residual จาก regression และตัดตัวแปรที่ไม่มีนัยสำคัญ
  • ถ้ามีตัวแปรภายนอกหลายตัว ตรวจ multicollinearity และตัดตัวที่ VIF เกิน 10
  • ตรวจว่า residual ไม่มี autocorrelation เหลือ

ข้อที่ว่าตัวแปรตามต้องไม่ส่งผลย้อนกลับสำคัญ เพราะถ้า Y ส่งผลต่อ X ด้วย X ก็ไม่ใช่ตัวแปรภายนอกจริง ควรใช้ VAR แทน

Granger test ถามว่า "อดีตของ X ช่วยพยากรณ์ Y ได้ดีขึ้นกว่าใช้อดีตของ Y อย่างเดียวหรือไม่" ซึ่งไม่ใช่เหตุเป็นผลในความหมายทางวิทยาศาสตร์ H0: X does not cause Y (No Granger effect) H1: X causes Y16 วิธีทดสอบคือเทียบสอง regression ด้วย F-test Model 1 มี lag ของทั้ง Y และ X ส่วน Model 2 มีแค่ lag ของ Y ถ้า Model 1 ดีขึ้นอย่างมีนัยสำคัญ (p ต่ำ) แปลว่า X มี Granger effect ขั้นที่ 3 บนสไลด์คือทดสอบย้อนทิศ ซึ่งเป็นทางเลือก ข้อความภาษาไทยบนสไลด์ย้ำเงื่อนไขเดิม คือตัวแปรภายนอกต้องไม่ได้รับผลย้อนกลับจากตัวแปรตาม ถ้าเป็นเหตุเป็นผลกันสองทาง ต้องตัดตัวแปรนั้นออกจากตัวเลือกของ ARIMAX การทดสอบนี้จะใช้ใน VAR ด้วย17

ข้อมูลตัวอย่าง uschange คือการเปลี่ยนแปลงเป็นร้อยละรายไตรมาสของการบริโภค รายได้ การผลิต การออม และอัตราว่างงานของสหรัฐฯ 1960–2016 รวม 187 ไตรมาส Y คือ consumption และใช้ income เป็น X ตัวเดียวก่อน18 ไฟล์ uschange.txt ไม่ได้อัปโหลดในโฟลเดอร์ ใช้ fpp2::uschange แทนได้ (ชื่อคอลัมน์ขึ้นต้นด้วยตัวใหญ่)

ทั้งสองอนุกรมแกว่งรอบค่าคงที่ ไม่มี trend เพราะเป็นร้อยละการเปลี่ยนแปลงอยู่แล้ว adf.test(consumption) ได้ Dickey-Fuller = −4.53, p = 0.01 จึงนิ่ง ไม่ต้อง difference19 ช่วงประมาณปีที่ 40 (ราวปี 1980) consumption ลดลงแรงถึงราว −2.3 และ income มีค่าสุดโต่งช่วงท้าย

แบ่ง test = 41 ไตรมาสสุดท้าย20 auto.arima กับ training ได้ ARIMA(3,0,0) with non-zero mean: φ = 0.1769, 0.1240, 0.1870, mean = 0.8362, σ² = 0.4007, AICc = 287.39 test RMSE = 0.63221 ค่านี้ใช้เป็นเกณฑ์เทียบกับ ARIMAX

grangertest(consumption ~ income, data = data) ได้ F = 3.21, p = 0.07491 (ใช้ lag 1) ไม่มีนัยสำคัญที่ 0.05 ส่วนทิศกลับ grangertest(income ~ consumption) ได้ F = 23.05, p = 3.3 × 10⁻⁶ แปลว่า consumption ช่วยพยากรณ์ income แต่ income ไม่ช่วยพยากรณ์ consumption ตามเงื่อนไขข้างบน income จึงไม่ควรเป็นตัวแปรภายนอกของ consumption และสไลด์ก็เขียนว่าอาจพิจารณาให้ income เป็นตัวแปรตามในอนาคต22 สไลด์เขียนต่อว่า "but does cause at 10%, so lets continue our analysis" แนวทางนี้ผิด การเปลี่ยน α หลังเห็นผลคือ "การแก้แบบโง่ ๆ" ปัญหาจริงคือเลือก X กับ Y ผิด ต้องเริ่มจาก literature review23 วิทยาศาสตร์ใช้ Design of Experiment ควบคุมปัจจัยได้ แต่ data science และสังคมศาสตร์ต้องพึ่งทฤษฎีจากงานก่อน24 ตัวอย่างนี้จึงทำต่อเพื่อสาธิตโค้ดเท่านั้น

3. MIDAS และ cross-correlation กับข้อมูล Bsales

MIDAS (Mixed Data Sampling) มีเฉพาะแนวคิด ไม่มีโค้ดและไม่ได้ลงรายละเอียดในคลิป ใช้เมื่อ Y กับ X เก็บด้วยความถี่ต่างกัน เช่น GDP รายไตรมาส (ความถี่ต่ำ) กับดัชนีราคาหุ้นรายวันหรือยอดค้าปลีกรายเดือน (ความถี่สูง) แทนที่จะเฉลี่ย X รายเดือนสามเดือนให้เป็นรายไตรมาสแล้วเสียข้อมูล MIDAS ใช้ค่าปัจจุบันและค่าล่าช้าของ X ความถี่สูงทั้งหมดเป็นตัวอธิบาย จึงเป็น autoregressive distributed lag แบบทั่วไป เช่น ไตรมาสหนึ่งมีสามเดือน X ในไตรมาสนั้นจึงมีสามค่าที่แต่ละค่ามีน้ำหนักของตัวเอง

autocorrelation วัดความสัมพันธ์ของอนุกรมกับอดีตของตัวเอง cross-correlation ขยายไปวัดความสัมพันธ์ของสองอนุกรมที่ lag ต่าง ๆ มันเป็นแค่เครื่องมือสำรวจข้อมูล ไม่ใช่โมเดลหลัก29 ใช้ช่วยตัดสินว่าควรใส่ X ที่ lag ไหน cross-correlation ระหว่าง \(X_{t1}\) และ \(X_{t2}\) ที่ lag k คือ correlation ของ \(X_{t+k,1}\) กับ \(X_{t2}\)

\(\hat\rho_{12}(k)=\dfrac{\sum_{t=1}^{n-k}(X_{t+k,1}-\bar X_1)(X_{t2}-\bar X_2)}{\sqrt{\sum(X_{t1}-\bar X_1)^2}\sqrt{\sum(X_{t2}-\bar X_2)^2}}\)

จุดต่างสำคัญจาก ACF คือ ACF ที่ lag k กับ −k เท่ากัน แต่ CCF ไม่เท่า เพราะลำดับของอนุกรมมีผล30 k = 0 คือ Pearson correlation ของคู่เวลาเดียวกัน k = 2 จับคู่ \((X_{31},X_{12}),(X_{41},X_{22}),\dots\) คือตัวแปร 1 ในอนาคตสองช่วงกับตัวแปร 2 ปัจจุบัน k = −2 จับคู่ \((X_{11},X_{32}),\dots\) คือตัวแปร 1 ปัจจุบันกับตัวแปร 2 ในอนาคตสองช่วง หรือมองกลับว่าตัวแปร 1 นำตัวแปร 2 อยู่สองช่วง cross correlogram วาดเหมือน ACF แต่แกนนอนมีทั้ง lag ลบและบวก ความสูงของแท่งบอกความแรงของ cross-correlation ใน R ใช้ ccf(x, y) ซึ่งค่าที่ lag k คือ cor(x[t+k], y[t]) ดังนั้น lag ลบหมายถึง x ในอดีตเทียบกับ y ปัจจุบัน ข้อมูลตัวอย่าง Bsales มี 100 สัปดาห์ สี่ตัวแปร คือ sales (พันดอลลาร์, ตัวแปรตอบสนอง), ad_tv, ad_online (พันดอลลาร์) และ discount (ร้อยละ)

ccf(data$ad_tv, data$sales) มีค่าสูงสุดที่ lag −1 = 0.848 รองลงมาคือ lag 0 = 0.695 และ lag −2 = 0.641 ad_online มีรูปแบบเดียวกัน สูงสุดที่ lag −1 = 0.788 ส่วน discount ค่าสัมบูรณ์สูงสุดเพียง 0.333 และไม่มีแท่งเด่นที่ lag ใด31

lag −1 ของ ccf(ad_tv, sales) หมายถึง ad_tv ที่เวลา t − 1 กับ sales ที่เวลา t ข้อสรุปคือยอดขายสัมพันธ์กับโฆษณาของสัปดาห์ก่อนมากที่สุด (ρ ≈ 0.8) ซึ่งสมเหตุสมผลเพราะลูกค้าต้องใช้เวลาตัดสินใจหลังเห็นโฆษณา ถ้าจะทำ ARIMAX จึงควรใส่ ad_tv ที่ lag 1 เป็นตัวอธิบาย ส่วนส่วนลดไม่มีความสัมพันธ์แบบล่าช้าที่ชัดเจน32

4. VAR: แนวคิด จำนวนพารามิเตอร์ และข้อมูล var1

VAR คือ "simultaneous model"33 ทุกตัวแปรถูกพยากรณ์พร้อมกัน และทุกตัวใช้ lag ของตัวเองและของตัวอื่นเป็นตัวอธิบาย ใช้เมื่อตัวแปรตั้งแต่สองตัวสัมพันธ์กัน และรวมกันอธิบายได้มากกว่าตัวเดียว เป้าหมายคือศึกษาความสัมพันธ์ระหว่างทุกตัวแปรเพื่อพยากรณ์ให้ดีขึ้น และเพราะ VAR ไม่แยกตัวแปรตามกับตัวแปรอิสระ จึงพยากรณ์ทุกตัวพร้อมกัน ต่างจาก ARIMAX ที่ต้องรู้ X ของอนาคต VAR(1) สองตัวแปรเขียนได้ว่า

\(X_{t1}=\phi_{11}X_{t-1,1}+\phi_{12}X_{t-1,2}+w_{t1}\)
\(X_{t2}=\phi_{21}X_{t-1,1}+\phi_{22}X_{t-1,2}+w_{t2}\)

แต่ละสมการคือ AR(1) ของตัวเองบวก lag 1 ของอีกตัว VAR ที่เรียนมีแค่ AR term ไม่มี MA34 เช่น ถ้า φ₁₂ = 0.5 การโฆษณาสัปดาห์ก่อนเพิ่ม 1 หน่วยทำให้ยอดขายสัปดาห์นี้เพิ่ม 0.5 หน่วย เขียนเป็นเมทริกซ์ได้ \(\mathbf X_t=\mathbf\Phi\mathbf X_{t-1}+\mathbf W_t\) โดย Φ เป็นเมทริกซ์ 2 × 2 และ error มี covariance matrix ที่มี Var(w₁), Var(w₂) และ Cov(w₁, w₂)35 เมื่อ p หรือจำนวนตัวแปรเพิ่ม การเขียนแบบเต็มจะยาวมาก

เมื่อตัด seasonal dummy ได้ VAR(2) = 5.92, VAR(9) = 6.08, VAR(7) = 5.44 ดีกว่าทุกโมเดลแบบมี seasonal และ VAR(7) ดีที่สุด แปลว่า lag 7 ของมลพิษช่วยพยากรณ์จริง และ dummy 51 ตัวต่อสมการอาจทำให้ overfit

VAR(7) with trend ได้ AIC 11.15, BIC 11.73, RMSE 5.44 ส่วน VAR(2) with trend + seasonal ได้ AIC 11.00, BIC 12.49, RMSE 6.38 VAR(7) ดีกว่าทั้ง BIC และ RMSE แต่ VAR(2) มี AIC ต่ำกว่าเล็กน้อย สไลด์สรุปว่า these criteria do not tell the analyst which model is “right” or even “better”. AIC ใช้เทียบ VAR ด้วยกันได้ "ระดับหนึ่ง" แต่ห้ามเทียบข้ามตระกูล56 RMSE ของ VAR(2) ในตารางนี้คือ 6.38 ต่างจาก 6.35 ในหน้า 75 เล็กน้อย น่าจะมาจากการรันคนละครั้ง

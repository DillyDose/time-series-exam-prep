แบบฝึก Lesson 10: auto.arima, ETS และ tsCV

แบบฝึกแบ่งเป็นห้ากลุ่ม คือคำนวณ ทฤษฎีและพิสูจน์ อธิบายความเข้าใจ อ่านผลจาก R และรันโค้ดเองแล้วเทียบผล ข้อเลือกตอบกดแล้วเห็นผลทันที ส่วนข้อเขียนให้ลองเขียนก่อนแล้วจึงกดดูเฉลย

กลุ่ม A: คำนวณ

ข้อ 1ETS → ARIMA
ETS(A,N,N) ได้ α = 0.3 ARIMA(0,1,1) ที่เทียบเท่าในรูป \(\nabla X_t=w_t+\theta_1w_{t-1}\) มี θ₁ เท่าใด
ข้อ 2Holt → ARIMA(0,2,2)
ETS(A,A,N) ได้ α = 0.6, β = 0.2 ARIMA(0,2,2) ที่เทียบเท่ามี (θ₁, θ₂) เท่าใด
ข้อ 3AICc และ MSE
(ก) โมเดลหนึ่งมี AIC = 100.0, k = 4 พารามิเตอร์ (รวม σ²) และ n = 30 จงหา AICc และเทียบกับกรณี n = 300 (ข) tsCV ได้ error หนึ่งก้าว 0.2, −0.1, 0.3, −0.4 จงหา MSE และ RMSE

(ก) n = 30: \(2(4)(5)/(30-5)=40/25=1.6\) AICc = 101.6 · n = 300: \(40/295=0.136\) AICc = 100.14 ข้อมูลน้อย penalty เพิ่มมาก ข้อมูลมาก AICc ≈ AIC

(ข) MSE = (0.04 + 0.01 + 0.09 + 0.16)/4 = 0.30/4 = 0.075 และ RMSE = √0.075 = 0.274

กลุ่ม B: ทฤษฎีและพิสูจน์

ข้อ 4เทียบข้ามตระกูล
ETS ได้ AIC = 214.7 และ ARIMA ได้ AIC = −2.8 กับข้อมูลชุดเดียวกัน ข้อสรุปใดถูก
ข้อ 5พิสูจน์ความเทียบเท่า
จงแสดงว่า simple exponential smoothing \(F_{t+1}=\alpha X_t+(1-\alpha)F_t\) กับ ARIMA(0,1,1) \(\nabla X_t=w_t+\theta w_{t-1}\) ให้ค่าพยากรณ์เดียวกัน เมื่อ θ = α − 1 และอธิบายว่าทำไม ETS ทุกตัวไม่นิ่ง

จาก ARIMA: \(X_{t+1}=X_t+w_{t+1}+\theta w_t\) ค่าพยากรณ์คือ \(\hat X_{t+1}=X_t+\theta w_t\) และ \(w_t=X_t-\hat X_t\) จึงได้ \(\hat X_{t+1}=(1+\theta)X_t-\theta\hat X_t\) แทน θ = α − 1 ได้ \(\hat X_{t+1}=\alpha X_t+(1-\alpha)\hat X_t\) ซึ่งคือ SES

ETS เทียบเท่า ARIMA ที่มี d ≥ 1 หรือ D ≥ 1 เสมอ (ตาราง Hyndman) คือมีตัวประกอบ (1 − B) ซึ่งมีรากบนวงกลมหนึ่งหน่วย จึงไม่นิ่ง ส่วน ARIMA ที่ d = D = 0 นิ่งได้และไม่มีคู่ใน ETS

ข้อ 7อธิบาย
(ก) tsCV ต่างจาก leave-one-out cross validation ของข้อมูล cross-sectional อย่างไร และทำไมต้องเป็นแบบนั้น (ข) ทำไม MSE จาก tsCV ของ german (0.077) จึงใหญ่กว่า σ̂² ของโมเดลที่ฟิตกับข้อมูลทั้งหมด (0.049)

(ก) LOOCV ตัดจุดใดก็ได้ออกแล้วใช้จุดที่เหลือทั้งหมด รวมถึงอนาคตของจุดนั้น ส่วน tsCV ใช้เฉพาะข้อมูลก่อนจุดทดสอบ (rolling forecast origin) เพราะอนุกรมเวลามีลำดับ การใช้อนาคตพยากรณ์อดีตทำให้ความแม่นยำสูงเกินจริงและไม่ตรงกับการใช้งาน

(ข) σ̂² วัด error ในตัวอย่างที่โมเดลเห็นข้อมูลทุกจุดตอนประมาณ ส่วน tsCV วัด error นอกตัวอย่าง โมเดลแต่ละรอบไม่เห็นจุดที่ทดสอบ และรอบแรก ๆ ใช้ข้อมูลน้อย ค่าประมาณจึงคลาดมากกว่า

ข้อ 12เขียนโมเดลจาก output

เขียนโมเดลเต็มจาก output ของ auto.arima ต่อไปนี้ และบอกว่าทำไมไม่มี intercept

ARIMA(1,0,2)(0,1,1)[12]
          ar1     ma1     ma2     sma1
      -0.7947  0.7786  0.2115  -0.7618
sigma^2 = 0.04883

\((1+0.7947B)(1-B^{12})X_t=(1+0.7786B+0.2115B^2)(1-0.7618B^{12})w_t\), \(\hat\sigma=\sqrt{0.04883}=0.221\)

ไม่มี intercept เพราะ D = 1: ค่าคงที่ในระดับของ X ถูกตัดออกด้วย (1 − B¹²) R จะใส่ค่าคงที่ (drift) ได้ก็ต่อเมื่อ d + D = 1 และ auto.arima ลองแบบ with drift แล้วได้ AICc สูงกว่า

สิ่งที่ควรทำได้หลังจบบทนี้
  • อธิบายว่า auto.arima ทำอะไร (unit root, AICc, MLE) และไม่ทำอะไร (transform, ตรวจ residual)
  • คำนวณ AICc จาก AIC และอธิบาย stepwise, trace, approximation
  • เขียนโมเดลเต็มจาก output ของ auto.arima
  • แปลงพารามิเตอร์ ETS(A,N,N) และ ETS(A,A,N) เป็น ARIMA(0,1,1) และ ARIMA(0,2,2)
  • รู้ว่าห้ามเทียบ AIC ข้ามตระกูล และใช้ tsCV (rolling forecast origin) แทน
  • อ่าน checkresiduals (Q*, df, p-value) และรู้ว่าต้องคิดเรื่อง drift เมื่อใส่ d ใน arima

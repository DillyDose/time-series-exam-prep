1.3 ARIMA(0,1,1) ให้ค่าพยากรณ์เท่ากับ SES

Box-Jenkins กับ exponential smoothing เป็นคนละโมเดลที่มาจากแนวคิดต่างกัน และ MA ของ smoothing ไม่ใช่ MA ของ Box-Jenkins แต่บางค่าของ p, d, q สองฝั่งเทียบกันได้5 เราเห็นความเท่ากันกับ exponential smoothing:

\[\text{ARIMA(0,1,1)}:\ X_t-X_{t-1}=\shk{w_t}+\prm{\theta}\shk{w_{t-1}}\quad\Longleftrightarrow\quad \text{SES}:\ \hat X_{t+1}=\prm{\alpha}X_t+(1-\prm{\alpha})\hat X_t,\quad \alpha=1+\theta\]

ถ้ารู้ θ ของ ARIMA(0,1,1) ก็รู้ α ของ SES ทันที และกลับกัน ข้อสอบเก่าเคยให้โมเดล ARIMA(0,1,1) แล้วให้หา α6

กุญแจของการพิสูจน์คือมอง \(w_{t+1}\) เป็นความคลาดเคลื่อนของการพยากรณ์ เหมือน residual \(e_t=Y_t-\hat Y_t\) ใน regression7 จึงแทน shock ที่มองไม่เห็นด้วยค่าที่คำนวณได้

พิสูจน์ (ข้อสอบเก่า) ว่า ARIMA(0,1,1) ให้ค่าพยากรณ์เท่ากับ SES
  1. โมเดล

    \(X_t-X_{t-1}=w_t+\theta w_{t-1}\) จึงได้ \(X_{t+1}=X_t+w_{t+1}+\theta w_t\)

  2. ใช้ความหมายของ residual

    \(w_{t+1}=X_{t+1}-\hat X_{t+1}\)

  3. แทนแล้วตัด X_{t+1}

    \(X_{t+1}=X_t+X_{t+1}-\hat X_{t+1}+\theta w_t\) ตัด \(X_{t+1}\) ทั้งสองข้าง ได้ \(\hat X_{t+1}=X_t+\theta w_t\)

  4. แทน w_t = X_t − X̂_t

    \(\hat X_{t+1}=X_t+\theta(X_t-\hat X_t)=(1+\theta)X_t-\theta\hat X_t\)

  5. ตั้ง α = 1 + θ

    จะได้ \(-\theta=1-\alpha\) และ \(\hat X_{t+1}=\alpha X_t+(1-\alpha)\hat X_t\) ซึ่งคือ \(F_{t+1}=\alpha X_t+(1-\alpha)F_t\) ของ Lesson 4 ตอน 2 "ถ้าจำไม่ได้ไปเปิดสไลด์ต้น ๆ"

θ = −0.6 ได้ α = 0.4 และ θ = −0.2 ได้ α = 0.8 เพราะ 0 < α < 1 จึงต้องมี −1 < θ < 0

"Optimal Exponential Smoothing in R" คือฟิต ARIMA(0,1,1) แล้วแปลง θ เป็น α8 IMA(1,1) ข้างบนได้ θ̂ = −0.3602 จึงคาดว่า α = 0.6398 และ ets(ima11, model="ANN") ได้ 0.6376 ต่างเล็กน้อยเพราะสองคำสั่ง optimize ต่างกัน

Holt (double exponential smoothing) มีสองน้ำหนักสำหรับ level และ trend จึงเทียบได้กับ ARIMA(0,2,2) ที่ไม่มีค่าคงที่ โดยไม่ลงรายละเอียดการพิสูจน์9 เพราะ Holt มีความชันที่เปลี่ยนได้ จึงต้อง difference สองครั้ง และ MA(2) ที่เหลือคือสองน้ำหนัก α กับ β สูตรแปลงอยู่ใน Lesson 10 ตอน 3

สูตร α = 1 + θ ใช้กับ convention บวกของสไลด์ \(w_t+\theta w_{t-1}\) ถ้าโจทย์เขียน \(w_t-\theta w_{t-1}\) จะได้ α = 1 − θ อีกข้อคือ ถึงสองโมเดลให้ค่าพยากรณ์เท่ากัน ก็ห้ามเอา AIC ของ ets() ไปเทียบกับ AIC ของ arima() เพราะ likelihood คำนวณคนละแบบ (Lesson 10)

ARIMA(0,1,1) ที่ R รายงาน ma1 = −0.75 ตรงกับ SES ที่ α เท่าไร และ α นี้บอกอะไร

α = 1 + (−0.75) = 0.25 น้ำหนักของค่าล่าสุดต่ำ ค่าพยากรณ์จึงปรับตามข้อมูลใหม่ช้า และเรียบมาก

2.2 Box-Cox: ให้ข้อมูลเลือกเองว่าจะแปลงแบบไหน

\[T(X_t)=\begin{cases}\dfrac{X_t^{\prm{\lambda}}-1}{\prm{\lambda}} & \lambda\ne0\\[4pt] \ln X_t & \lambda=0\end{cases}\]

Box-Cox (1964) รวม power transformation ไว้ในสูตรเดียว ค่า λ เป็นปุ่มหมุนตัวเดียวที่เลือกว่าจะบีบข้อมูลแรงแค่ไหน

λได้อะไรใช้เมื่อไร
1x − 1 แทบไม่เปลี่ยนรูปไม่ต้องแปลง
1/2√x (หลังเลื่อนและย่อขนาด)บีบเล็กน้อย
0ln x ไม่ใช่ x⁰ความแกว่งโตเป็นสัดส่วนกับระดับ
1/10, 1/6\(x^{1/10}\), \(x^{1/6}\)เลี่ยงถ้าทำได้ "แปลงกลับยากและความหมายแปลยาก"

ทำไม λ = 0 เป็น ln x14 เมื่อ λ → 0 สูตร \((x^\lambda-1)/\lambda\) เข้าใกล้ ln x เช่น x = 10 และ λ = 0.001 ได้ \((10^{0.001}-1)/0.001=2.3052\) ใกล้ \(\ln10=2.3026\)

log ดีกว่า √ เพราะแปลงกลับด้วย exponential ง่าย และค่าที่แปลงกลับไม่ติดลบ เหมาะกับยอดขาย15 BoxCox.ar() จาก package TSA หาค่า λ ที่ทำให้ likelihood สูงสุดพร้อมช่วงเชื่อมั่น 95% กฎคือถ้าช่วงคลุม 0 ให้ใช้ log ถ้าไม่คลุม 0 ต้องใช้ transformation รูปแบบอื่น16 คำสั่งนี้รันนานเพราะต้องประมาณ MLE ซ้ำหลายครั้ง17

BoxCox.ar ให้ λ̂ = 0.45 และช่วงเชื่อมั่น 0.3 ถึง 0.6 ควรแปลงอย่างไร

ช่วงไม่คลุม 0 จึงไม่ใช้ log ช่วงคลุม 0.5 จึงใช้ √x ซึ่งยังแปลงกลับง่าย (ยกกำลังสอง) และช่วงไม่คลุม 1 จึงต้องแปลง

3.3 AIC: ความฟิตบวกค่าปรับ

ให้คะแนนโมเดลเหมือนตัดเกรดรายงาน ส่วนแรกคือเนื้อหาตรงข้อมูลแค่ไหน ส่วนที่สองคือหักคะแนนที่เขียนยาวเกินจำเป็น โมเดลที่ใส่พารามิเตอร์เพิ่มจะฟิตดีขึ้นเสมอ AIC จึงต้องมีค่าปรับไว้ถ่วง

\[\mathrm{AIC}=-2\ln L+2k\]

ยิ่งน้อยยิ่งดี30 เพราะ −2 ln L น้อยแปลว่า likelihood สูง ส่วน 2k คือค่าปรับที่ไม่ให้โมเดลซับซ้อนเกินจำเป็น ตามหลัก parsimony "ให้มันเท่าที่จำเป็น"

Llikelihood สูงสุดจาก MLE (ตอน 5.5) คือโอกาสที่โมเดลนี้จะเกิด take log เพื่อบีบค่าแต่ทิศทางเหมือนเดิม31
kจำนวนพารามิเตอร์ที่ประมาณ R นับ φ, θ, intercept และ σ² ทั้งหมด

ARMA(1,1) ของ times: log likelihood = −247.66 และ k = 4 (φ, θ, intercept, σ²) จึงได้ AIC = 495.32 + 8 = 503.32 ตรงกับ aic = 503.31 ที่ R รายงาน สูตรนี้ย้อนกลับได้ด้วย ถ้ารู้ AIC และ k ก็หา \(\ln L=(2k-\mathrm{AIC})/2=(8-503.31)/2=-247.66\)

จุดดำคือ −2 ln L เส้นส้มคือค่าปรับของ AIC ARMA(2,1) ไป ARMA(2,2) ความฟิตดีขึ้นแค่ 0.93 แต่ค่าปรับเพิ่ม 2 AIC จึงสูงขึ้นจาก 501.28 เป็น 502.35 การเพิ่มพารามิเตอร์ตัวนี้ไม่คุ้ม

เรื่อง k สไลด์เขียนว่าไม่นับ white noise variance แต่ R นับ σ² ด้วย32 การนับต่างกันไม่เปลี่ยนการเลือกโมเดล เพราะทุกโมเดลถูกบวกค่าคงที่เท่ากัน AIC เทียบกันได้เฉพาะโมเดลที่ใช้ข้อมูลชุดเดียวกัน ข้อมูลที่ log หรือ difference ต่างกัน (d ต่างกัน) คือข้อมูลคนละชุด ซอฟต์แวร์บางตัวอย่าง SAS ใช้ +2 log L ทำให้ยิ่งมากยิ่งดี แต่ใน R ยิ่งน้อยยิ่งดี33

R รายงาน ARMA(2,1) ที่มี intercept ได้ aic = 300 ใช้ข้อมูล 100 ค่า log likelihood เท่าไร

4.1 Parameter redundancy: โมเดลที่ดูใหญ่แต่จริง ๆ เล็ก

เศษส่วน 6/9 กับ 2/3 คือจำนวนเดียวกัน ถ้าตัวเศษและตัวส่วนมีตัวประกอบร่วมก็ตัดได้ ARMA ก็เหมือนกัน ถ้าพหุนามฝั่ง AR กับฝั่ง MA มีตัวประกอบร่วม ตัดทิ้งแล้วจะได้โมเดลอันดับต่ำกว่า

\[\Phi(B)X_t=\theta(B)\shk{w_t}\quad\text{ถ้า }\Phi(z)\text{ กับ }\theta(z)\text{ มีตัวประกอบร่วม ให้ตัดทิ้งก่อน}\]

ต้องตัดก่อนตรวจรากเสมอ ไม่อย่างนั้นจะนับอันดับผิด และตรวจรากของตัวประกอบที่ไม่มีอยู่จริง

วงกลมแดงคือบริเวณที่ไม่ผ่าน รากทุกตัวของโจทย์สี่ข้อในตอน 4.4 อยู่นอกวง ยกเว้นคู่รากเชิงซ้อนของข้อ 3 ฝั่ง MA ซึ่ง modulus 0.913 จึงอยู่ในวง ข้อ 3 จึงไม่ invertible แม้ส่วนจริงจะเล็กเพียง 0.125

ทฤษฎีบทใช้กับพหุนามที่จัดรูป \(\Phi(B)X_t=\theta(B)w_t\) แล้ว ฝั่ง AR ย้าย X ไปซ้ายจึงเปลี่ยนเครื่องหมาย ฝั่ง MA คงเครื่องหมายเดิม ถ้าลืมเปลี่ยนเครื่องหมายฝั่ง AR รากจะผิดทั้งข้อ

4.4 โจทย์สี่ข้อของใบงาน

โจทย์สี่ข้อนี้เป็นรูปแบบที่ออกสอบได้ และเฉลยในห้องทุกข้อ46 ขั้นตอนของทุกข้อเหมือนกัน: จัดรูปเป็น \(\Phi(B)X_t=\theta(B)w_t\) เปลี่ยน B เป็น x ตั้งเท่ากับศูนย์ ระบุ a, b, c ให้ชัด ตรวจ \(b^2-4ac\) ก่อนแทนสูตร และตรวจฝั่งที่ง่ายก่อน

เฉลยโจทย์ 1–4 ของใบงาน ARMA_properties
  1. ข้อ 1: X_t = 0.3X_{t−1} + w_t

    \((1-0.3B)X_t=w_t\) ต้องจัดรูปเพราะพหุนามนี้คือ characteristic function47 \(1-0.3x=0\) ได้ราก 3.33 > 1 จึง causal ไม่มีส่วน MA จึง invertible

  2. ข้อ 2: X_t = w_t − 1.3w_{t−1} + 0.4w_{t−2}

    \(\theta(x)=1-1.3x+0.4x^2\) a = 0.4, b = −1.3, c = 1 \(b^2-4ac=1.69-1.6=0.09>0\) รากจริง \(x=\dfrac{1.3\pm0.3}{0.8}\) ได้ 2 และ 1.25 เกิน 1 ทั้งคู่จึง invertible และเป็น MA จึง causal48

  3. ข้อ 3: X_t = 0.5X_{t−1} + w_t − 0.3w_{t−1} + 1.2w_{t−2}

    \((1-0.5B)X_t=(1-0.3B+1.2B^2)w_t\) ตรวจฝั่งซ้ายก่อนเพราะง่าย ราก 2 > 1 จึง causal ฝั่งขวา a = 1.2, b = −0.3, c = 1 \(D=0.09-4.8=-4.71<0\) รากเชิงซ้อน \(\dfrac{0.3\pm i\sqrt{4.71}}{2.4}=0.125\pm0.904i\) modulus \(\sqrt{0.125^2+0.904^2}=0.913<1\) จึงไม่ invertible49

  4. ข้อ 4: X_t = 0.4X_{t−1} + 0.45X_{t−2} + w_t + w_{t−1} + 0.25w_{t−2}

    ดูคล้าย ARMA(2,2) \((1-0.4B-0.45B^2)X_t=(1+B+0.25B^2)w_t\) แยกตัวประกอบได้ \((1+0.5B)(1-0.9B)X_t=(1+0.5B)^2w_t\) มีตัวประกอบร่วมจึงตัดทิ้ง เหลือ \((1-0.9B)X_t=(1+0.5B)w_t\) ซึ่งจริง ๆ คือ ARMA(1,1) เพราะ redundant50 ราก 1.11 > 1 จึง causal และราก −2 มีค่าสัมบูรณ์ 2 > 1 จึง invertible

ข้อ 3 คือ causal but not invertible51 ในคลิปพูดช่วงนั้นว่า "ไม่ stationary" แต่ความนิ่งของ ARMA ขึ้นกับรากของ Φ เท่านั้น ข้อ 3 จึงยังนิ่ง ข้อ 4 ต้องตัดตัวประกอบร่วมก่อนแล้วค่อยตรวจราก52
\(X_t=0.8X_{t-1}+w_t+1.25w_{t-1}\) causal และ invertible ไหม

\((1-0.8B)X_t=(1+1.25B)w_t\) ราก AR = 1.25 > 1 จึง causal ราก MA = −0.8 มีค่าสัมบูรณ์ 0.8 < 1 จึงไม่ invertible (θ = 1.25 เกิน 1 ก็เห็นได้ทันที)

ฝึกคำสั่ง R ของอาจารย์

หน้านี้รวมคำสั่ง R ที่อาจารย์ใช้ในไฟล์ R_codes ของ Class 2–12 จัดเรียงตามงานที่ต้องทำ ใช้คู่กับหน้าฝึกตามข้อสอบเก่า หน้านั้นฝึกเฉพาะคำสั่งที่ข้อสอบเก่าเคยใช้ หน้านี้เพิ่มคำสั่งที่อาจารย์สอนในห้องแต่ข้อสอบเก่ายังไม่เคยถาม เผื่อปีนี้อาจารย์เปลี่ยนโมเดลหรือเปลี่ยนชุดข้อมูล

แต่ละหัวข้อมี 4 ส่วน:

  1. โค้ดของอาจารย์ คัดมาจากไฟล์ตรงตัว
  2. ตารางอธิบายว่าแต่ละคำสั่งทำอะไร
  3. ผลที่รันได้จริง
  4. โจทย์ให้ลองแก้โค้ดเอง

ทุกตัวเลขรันด้วย R 4.5 กับข้อมูลในโฟลเดอร์ของแต่ละ Class บน myCourseVille ก่อนรันให้ตั้ง working directory ไปที่โฟลเดอร์ที่มีไฟล์ข้อมูล

เตรียม R ก่อนเข้าห้องสอบ ติดตั้งทุก package ล่วงหน้า เพราะในห้องสอบอาจไม่มีอินเทอร์เน็ต

แบบฝึก Lesson 13: Frequency domain และ Prophet

แบบฝึกแบ่งเป็นสี่กลุ่ม คือ periodogram, Prophet, เลือกโมเดล และข้อสอบเก่า ข้อเลือกตอบกดแล้วเห็นผลทันที ส่วนข้อเขียนให้ลองเขียนก่อนแล้วจึงกดดูเฉลย ข้อ 11–13 คือ FINAL 2025 ข้อ 3 และข้อ 5 ทำด้วย R ได้จากไฟล์ rain.txt ในโฟลเดอร์ข้อสอบเก่า

กลุ่ม A: periodogram

ข้อ 1ความถี่เป็นคาบ
ข้อมูลรายเดือน spectrum() ให้ยอดสูงสุดที่ f = 0.0833 ข้อมูลมีรอบเท่าไร
ข้อ 2รูป periodogram
periodogram ของ residual จาก SARIMA แบนเท่ากันทุกความถี่ หมายความว่าอะไร
ข้อ 3ก่อนทำ periodogram
periodogram ของข้อมูลรายวันที่ยังไม่แปลงอะไรเลย มีพลังงานกองสูงมากที่ f ใกล้ 0 แล้วลดลงเรื่อย ๆ ควรทำอะไรก่อน
ข้อ 4periodogram วัดอะไร
ข้อใดถูกเกี่ยวกับ periodogram ตามสไลด์

กลุ่ม C: เลือกโมเดล

ข้อ 9FINAL 2025 ข้อ 3
GDP ไทยและ GDP สหรัฐรายไตรมาส 20 ปี ต้องการวิเคราะห์ว่า GDP ไทยได้รับผลจาก GDP สหรัฐหรือไม่ และตอบสนองร่วมกันหรือไม่ ควรเลือกโมเดลใด
ข้อ 10FINAL 2025 ข้อ 3
ยอดสั่งซื้อสินค้ารายวัน 5 ปี มีแนวโน้มเพิ่มขึ้น ศุกร์–เสาร์ยอดสูง และช่วงปีใหม่กับสงกรานต์ยอดสูง ควรเลือกโมเดลใด
ข้อ 11FINAL 2025 ข้อ 3 ทั้งข้อ (3 คะแนน)
เลือกโมเดล (SARIMA / ARIMAX / VAR / GARCH / FB Prophet) ให้ข้อมูลหกชุดพร้อมเหตุผลหนึ่งบรรทัด: (1) ยอดสั่งซื้อรายวัน ศุกร์–เสาร์สูง ปีใหม่–สงกรานต์สูง (2) ราคาหุ้นเทคโนโลยีรายวัน ผันผวนเป็นช่วง ACF ของ squared return ลดช้า (3) ยอดขายรายสัปดาห์ตอบสนองต่องบ Facebook Ads (4) นักท่องเที่ยวรายเดือน 10 ปี ธ.ค.–ม.ค. สูง trend ขึ้น โควิดตกแรง (5) GDP ไทยและสหรัฐ ผลกระทบและการตอบสนองร่วมกัน (6) ยอดขายกาแฟรายเดือน ปลายปีสูง เม.ย.–พ.ค. ต่ำ

(1) Prophet: รายวัน + weekly + วันหยุดที่ต้องมีหน้าต่าง (2) GARCH: volatility clustering, return² เป็นแบบ AR (3) ARIMAX: Ads เป็น X ที่บริษัทกำหนดเองและรู้ล่วงหน้า (4) Prophet: trend หักแรงช่วงโควิด รองรับด้วย changepoint (SARIMA พร้อม dummy โควิดเป็น xreg ก็ป้องกันได้ถ้าเขียนเหตุผล) (5) VAR: ส่งผลต่อกันสองทาง ใช้ Granger ดูทิศ (6) SARIMA: ฤดูกาลรายเดือนคงที่ ไม่มีข้อมูลอื่นเพิ่ม

อาจารย์ไม่ได้ให้เฉลย ชุด (4) จึงเป็นข้อที่เถียงได้ หลักคือดูว่าโจทย์ให้ข้อมูลอะไร "เพิ่ม" จากอนุกรมเดี่ยวที่มีฤดูกาล

กลุ่ม D: ข้อสอบเก่า (ทำด้วย R)

ข้อ 12FINAL 2025 ข้อ 5a (2 คะแนน)
rain.txt คือปริมาณน้ำฝนรายเดือนที่ อ.นาทวี จ.สงขลา ม.ค. 2022 – พ.ย. 2025 (47 เดือน) สร้าง periodogram เพื่อหาความถี่และ cycle ที่เหมาะสม
rain <- read.table("rain.txt", header = TRUE)
s <- spectrum(rain$rain, log = "no")
s$freq[which.max(s$spec)]          # 0.0833
1 / s$freq[which.max(s$spec)]      # 12

ยอดเด่นที่ f = 0.0833 (power ≈ 920) คาบ T = 1/0.0833 = 12 เดือน คือรอบรายปีของฤดูฝน ยอดรองที่ f = 0.27 (คาบ ~3.7 เดือน) กับ f = 0.021 (คาบ 48 เดือน ≈ ความยาวข้อมูลทั้งหมด คือ trend) สูงไม่ถึงหนึ่งในสิบของยอดหลัก จึงใช้ cycle = 12 และตั้ง ts(rain$rain, start = c(2022,1), frequency = 12) สำหรับข้อต่อไป

ข้อ 13FINAL 2025 ข้อ 5g (9 คะแนน)
ใช้ training ม.ค. 2022 – ธ.ค. 2024 (36 เดือน) และ test ม.ค. – พ.ย. 2025 (11 เดือน) สร้างสี่โมเดล: (1) auto.arima (stepwise = TRUE, approximation = FALSE) (2) แบบเดียวกันที่ใช้ storm เป็น xreg (3) nnetar (4) nnetar ที่ใช้ storm เป็น xreg เติมชื่อโมเดลจาก R และ RMSE ใน test set แล้วอภิปรายผล
ตัวแบบชื่อจาก R (training)RMSE test
1ARIMA(0,0,0)(0,1,0)[12] with drift4.85
2Regression with ARIMA(0,0,0)(0,1,0)[12] errors (drift 1.02, storm 4.58)5.00
3NNAR(1,1,2)[12]≈ 5.6–6.3 (แล้วแต่ seed)
4NNAR(1,1,2)[12] + xreg storm≈ 60–65

อภิปราย: (ก) ARIMA ธรรมดาดีที่สุด เพราะข้อมูลมีแค่ seasonal กับ drift ชัดเจน (ตรงกับ periodogram ข้อ 12) และ training มีแค่ 36 เดือน (ข) storm ช่วยไม่ได้: สัมประสิทธิ์ 4.58 มม. แต่ใน test ผลของพายุไม่สม่ำเสมอ RMSE จึงแย่ลงเล็กน้อย (ค) NNAR ไม่ชนะ ARIMA เพราะข้อมูลน้อย ตรงกับที่อาจารย์เตือนใน Lesson 12 และผลขึ้นกับ seed (ง) NNAR + storm พังหนัก: training มีพายุแค่ไม่กี่เดือน network เรียนผลของ storm = 1 แบบสุดโต่ง พอ test มีพายุ (พ.ค., มิ.ย., ก.ย.–พ.ย.) ค่าพยากรณ์กระโดดไป ~150 มม. และค้างอยู่เพราะพยากรณ์ทีละก้าวใช้ค่าพยากรณ์ก่อนหน้าเป็น input ต่อ

x  <- ts(rain$rain,  start = c(2022,1), frequency = 12)
st <- ts(rain$storm, start = c(2022,1), frequency = 12)
tr <- window(x, end = c(2024,12));  te <- window(x, start = c(2025,1))
s1 <- window(st, end = c(2024,12)); s2 <- window(st, start = c(2025,1))
m1 <- auto.arima(tr, stepwise = TRUE, approximation = FALSE)
m2 <- auto.arima(tr, stepwise = TRUE, approximation = FALSE, xreg = s1)
set.seed(1); m3 <- nnetar(tr)
set.seed(1); m4 <- nnetar(tr, xreg = s1)
accuracy(forecast(m1, h = 11)$mean, te)      # RMSE 4.85
accuracy(forecast(m2, xreg = s2)$mean, te)   # RMSE 5.00
accuracy(forecast(m3, h = 11)$mean, te)
accuracy(forecast(m4, xreg = s2)$mean, te)
สิ่งที่ควรทำได้หลังจบบทนี้
  • อ่านยอดของ periodogram แล้วแปลง T = 1/f และตั้ง frequency ของ ts()
  • บอกความหมายของรูป peak, broad peak, decreasing, flat และรู้ว่าต้อง difference ก่อนถ้ามี trend
  • เขียนสมการ Prophet \(y_t=c_t+s_t+h_t+x_t+\varepsilon_t\) และบอกว่าแต่ละส่วนสร้างอย่างไร
  • เตรียม ds/y, holiday window, add_regressor, make_future_dataframe และอ่าน yhat กับ accuracy
  • เลือก SARIMA / ARIMAX / VAR / GARCH / Prophet จากคำอธิบายข้อมูล พร้อมเหตุผล

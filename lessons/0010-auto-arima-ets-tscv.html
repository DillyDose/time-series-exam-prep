1. auto.arima ทำงานอย่างไร และเจ็ดขั้นของการวิเคราะห์

1.1 auto.arima = Lesson 7 ที่ให้คอมพิวเตอร์ทำ

Lesson 7 สร้างตาราง AIC 4×4 ด้วยมือแล้วเลือกช่องที่ต่ำสุด auto.arima ทำแบบเดียวกัน แต่ค้นได้กว้างกว่า รวม d, D และส่วน seasonal และ "ช่วยชีวิต" จากการลองผิดลองถูก

สไลด์ชุดนี้ทำมานานตั้งแต่ยังไม่มีคำสั่ง auto.arima1 algorithm ของ Hyndman และ Khandakar (2008) รวมสามอย่างที่เรียนมาแล้ว

auto.arima ทำด้วยอะไรทำมือแบบเดิมที่
เลือก d และ Dunit root testACF ลดช้า, ADF (Lesson 7 ตอน 3.1–3.2)
เลือก p, q, P, Qหา AICc ต่ำสุดและใช้ MLE เพื่อได้โมเดล ARIMAตาราง AIC/BIC (Lesson 7 ตอน 3.5)
ประมาณพารามิเตอร์MLELesson 7 ตอน 5.5
\[\mathrm{AICc}=\mathrm{AIC}+\frac{2k(k+1)}{n-k-1}\]

AICc คือ AIC ที่บวกค่าปรับเพิ่มสำหรับข้อมูลน้อย จึงแม่นยำกว่า AIC2 เมื่อ n ใหญ่ ส่วนเพิ่มเข้าใกล้ศูนย์ AICc จึงเท่ากับ AIC เป็นสมาชิกตัวที่สามในครอบครัว AIC/BIC ของ Lesson 7 ทั้งสามใช้ −2 ln L ตัวเดียวกัน ต่างกันแค่ค่าปรับ

german ในตอน 2 มี AIC = −2.77, k = 5 (φ, θ₁, θ₂, Θ₁, σ²) และ n = 118 − 12 = 106 หลัง seasonal difference จึงได้ส่วนเพิ่ม \(2(5)(6)/(106-6)=0.6\) และ AICc = −2.17 ตรงกับ output ค่าเดียวกันนี้คิดกลับเป็น log likelihood ได้: \(\ln L=(2k-\mathrm{AIC})/2=(10+2.77)/2=6.38\) ก็ตรงกับ output เช่นกัน

ค่าเริ่มต้นของ auto.arima ใช้การประมาณเพื่อให้เร็ว การประมาณนี้เลี่ยงได้ด้วย approximation=FALSE เพราะอาจไม่เจอโมเดลที่ AICc ต่ำสุดจริง ทั้งจากการประมาณและจากการค้นแบบ stepwise และ AICc ต่ำสุด "ไม่ได้หมายความว่ามันจะดีที่สุด" ต้องตรวจ residual ต่อเสมอ

RMSE ของ ARIMA คือ √0.077 = 0.278 ใหญ่กว่า σ̂ = 0.221 ที่ได้จากการฟิตข้อมูลทั้งหมด error นอกตัวอย่างจึงใหญ่กว่าในตัวอย่าง ซึ่งเป็นปกติ เพราะ σ̂ วัดจากข้อมูลที่โมเดลเห็นแล้ว

forecastets   <- function(x, h) forecast(ets(x), h = h)
forecastarima <- function(x, h) forecast(auto.arima(x), stepwise = T, approximation = F, h = h)
etserror   <- tsCV(germaninfl, forecastets, h = 1)
arimaerror <- tsCV(germaninfl, forecastarima, h = 1)
mean(etserror^2, na.rm = TRUE); mean(arimaerror^2, na.rm = TRUE)

ในโค้ดของสไลด์ stepwise, approximation ถูกส่งให้ forecast ไม่ใช่ auto.arima จึงไม่มีผล รันซ้ำด้วย forecast เวอร์ชันปัจจุบันได้ ETS 0.0863 และ ARIMA 0.0770 ข้อสรุปเหมือนเดิม

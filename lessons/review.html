1.2 ตัวแปรสุ่ม กฎ E, Var, Cov

ทุกจุดเวลา \(X_t\) คือตัวแปรสุ่มคนละตัว ชุดของมันเรียกว่า stochastic process ความยากคือมีตัวแปรสุ่ม n ตัวแต่ได้ข้อมูลชุดเดียว เหมือนลูกเต๋า n ลูกที่ทอยได้ครั้งเดียว ทางออกคือบรรยายแค่ moment อันดับหนึ่งและสอง

กฎจำว่า
\(E(aX+bY)=aE(X)+bE(Y)\)ดึงค่าคงที่ออกตรง ๆ
\(\mathrm{Var}(aX)=a^2\mathrm{Var}(X)\)ค่าคงที่ที่ดึงออกต้องยกกำลังสอง
\(\mathrm{Var}(X+Y)=\mathrm{Var}X+\mathrm{Var}Y+2\mathrm{Cov}(X,Y)\)อิสระกันเหลือสองพจน์แรก
\(\mathrm{Cov}(X,a)=0\)ค่าคงที่ไม่แกว่ง
\(\mathrm{Cov}(aX,bY)=ab\,\mathrm{Cov}(X,Y)\)ดึงสัมประสิทธิ์ทั้งสองข้าง
\(\mathrm{Cov}(X,X)=\mathrm{Var}(X)\)ตัวเองกับตัวเองคือความแปรปรวน

\(\mathrm{Cov}(2X-3Y,\,2Z+5W)\) สองตัวคูณสองตัวได้ 4 คู่ \(=4\mathrm{Cov}(X,Z)+10\mathrm{Cov}(X,W)-6\mathrm{Cov}(Y,Z)-15\mathrm{Cov}(Y,W)\) เครื่องหมายพาไปด้วยทุกคู่

X, Y อิสระกันได้ cov = 0 แต่ cov = 0 ไม่ได้แปลว่าอิสระ เช่น X = −1, 0, 1 และ Y = X² ได้ cov = 0 ทั้งที่ Y ขึ้นกับ X ทั้งหมด covariance วัดแค่ความสัมพันธ์เชิงเส้น · ตัวกรีกคือ parameter ตัวสวมหมวกคือ statistic ที่คำนวณจากข้อมูล

  • cov = 0 เมื่ออิสระ เคยออกข้อสอบ Class 2 1:17:08

1.3 Autocovariance และ ACF

\[\gamma(h)=\mathrm{cov}(X_{t+h},X_t)\qquad\qquad \rho(h)=\frac{\gamma(h)}{\gamma(0)}\]

auto แปลว่าตัวเอง มีตัวแปรเดียวจึงเทียบตัวเองที่เวลาต่างกัน h คือ lag หมายถึงทุกคู่ที่ห่างกัน h \(\gamma(0)\) คือความแปรปรวน \(\rho(0)=1\) เสมอ ค่าใกล้ ±1 คือสัมพันธ์เชิงเส้นแรง

\(X_t=5+w_t\), Var(w) = 4: mean 5 ทุกเวลา \(\gamma(0)=4\) เพราะบวกค่าคงที่ไม่เปลี่ยนการแกว่ง \(\gamma(h)=0\) เมื่อ h ≠ 0 ได้ ACF เป็น 1 ที่ lag 0 และ 0 ที่อื่น

1.4 White noise: ตัวต่อของทุกโมเดล

\[\mathrm{cov}(\shk{w_i},\shk{w_j})=\begin{cases}\sigma_w^2 & i=j\\ 0 & i\ne j\end{cases}\]

ลูกเต๋าลูกใหม่ทุกวัน ไม่จำเมื่อวาน mean 0 ความแปรปรวนคงที่ ไม่สัมพันธ์กันข้ามเวลา iid เข้มกว่าเพราะห้ามความสัมพันธ์ทุกรูปแบบ Gaussian คือ iid และ normal กฎสองกรณีนี้ใช้ในทุกการพิสูจน์ของวิชา

5.1 MA(q): shock ค้างอยู่ q ช่วง

\[X_t=\shk{w_t}+\prm{\theta_1}\shk{w_{t-1}}+\dots+\prm{\theta_q}\shk{w_{t-q}}=\theta(B)\shk{w_t},\qquad \theta(B)=1+\prm{\theta_1}B+\dots+\prm{\theta_q}B^q\]

ข่าวสงครามเมื่อวานยังมีผลกับราคาน้ำมันวันนี้ พรุ่งนี้เหลืออีกนิดแล้วหมด ค่าวันนี้คือ shock ในหน้าต่างล่าสุด q + 1 ตัว คูณน้ำหนัก θ แต่ละตัว นอกหน้าต่างไม่มีผล θ(B) คือ characteristic function ของ MA

สไลด์บอกว่า MA เขียนโครงสร้างของ noise ที่สัมพันธ์กันได้ ซึ่งเกินกว่าสมมติฐานเดิมที่ให้ error เป็น iid ถ้าอนุกรมไม่ได้แกว่งรอบ 0 เติม μ เป็น \(X_t=\mu+\theta(B)w_t\) R เรียก μ ว่า intercept

R ใช้ \(w_t+\theta w_{t-1}\) หนังสือ Cryer and Chan ใช้ \(w_t-\theta w_{t-1}\) โมเดลเดียวกันจะได้ θ คนละเครื่องหมาย ต้องดูโจทย์ก่อน

7.4 ARIMA(0,1,1) ให้ค่าพยากรณ์เท่ากับ SES

Box-Jenkins กับ exponential smoothing มาจากแนวคิดต่างกัน แต่บางโมเดลให้ค่าพยากรณ์เท่ากันพอดี เราเห็นความเท่ากันกับ exponential smoothing

\[\nabla X_t=\shk{w_t}+\prm{\theta}\shk{w_{t-1}}\quad\Longleftrightarrow\quad \hat X_{t+1}=\prm{\alpha}X_t+(1-\prm{\alpha})\hat X_t,\qquad \alpha=1+\theta\]

รู้ θ ของ ARIMA(0,1,1) ก็รู้ α ของ SES ทันที เพราะ 0 < α < 1 ต้องมี −1 < θ < 0 ส่วน Holt ที่มี level กับ trend เทียบได้กับ ARIMA(0,2,2)

R รายงาน ma1 = −0.75 ได้ α = 1 − 0.75 = 0.25 น้ำหนักค่าล่าสุดต่ำ ค่าพยากรณ์เรียบและตามข้อมูลใหม่ช้า

แนวพิสูจน์: จาก \(X_{t+1}=X_t+w_{t+1}+\theta w_t\) ใช้ \(w_{t+1}=X_{t+1}-\hat X_{t+1}\) ตัด \(X_{t+1}\) ได้ \(\hat X_{t+1}=X_t+\theta w_t\) แทน \(w_t=X_t-\hat X_t\) ได้ \((1+\theta)X_t-\theta\hat X_t\) ตั้ง α = 1 + θ ก็ได้สูตร SES

ถ้าโจทย์เขียน \(w_t-\theta w_{t-1}\) จะได้ α = 1 − θ และถึงค่าพยากรณ์เท่ากัน ก็ห้ามเทียบ AIC ของ ets กับ arima

  • ข้อสอบเก่าเคยออก ให้โมเดล ARIMA(0,1,1) มาแล้วถามว่า α ของ exponential เป็นเท่าไร Class 7-1 0:07:38

7.5 โมเดลที่มีความหมาย: ไม่ซ้ำซ้อน causal invertible

ตรวจอะไรเครื่องมือผ่านเมื่อ
outlierstandardized residual \(\hat w_t/\hat\sigma\)อยู่ใน ±3 หลุดได้ไม่กี่จุด
normalhistogram, QQ plot, shapiro.testจุดเรียงตามเส้น p-value > 0.05

12.1 อาการ: return เงียบ แต่ return² ไม่เงียบ

12.2 ARCH(p)

\[u_t=\shk{\varepsilon_t}\,\sigma_t,\qquad \sigma_t^2=\prm{\alpha_0}+\prm{\alpha_1}u_{t-1}^2+\dots+\prm{\alpha_p}u_{t-p}^2\]

ค่าวันนี้ = เสียงสุ่มมาตรฐาน × ความกว้างของวันนี้ ความกว้างคำนวณจากกำลังสองของค่าในอดีต เหมือนสะพานแขวน ถ้าเมื่อกี้โยกแรง ก้าวต่อไปก็มีโอกาสโยกแรง แต่ไม่รู้ว่าซ้ายหรือขวา ย้ายข้างแล้ว u² เป็น AR(p)

ARCH(1) α₀ = 0.2, α₁ = 0.7: เมื่อวาน u = 2 ได้ σ²ₜ = 0.2 + 0.7(4) = 3.0 σ = 1.73 · เมื่อวาน u = 0 ได้ σ = 0.45 · ระยะยาว 0.2/(1 − 0.7) = 0.67 ต้องมี α₁ < 1 · ARCH(2) 0.1 + 0.5(1)² + 0.4(−2)² = 2.2 เครื่องหมายลบหายเพราะยกกำลังสอง

shock ใหญ่เมื่อวานไม่ได้ทำให้ return วันนี้สูง ที่สูงขึ้นคือ σₜ ค่าวันนี้อาจใหญ่ เล็ก หรือกลางก็ได้

12.3 GARCH(p,q)

\[\sigma_t^2=\prm{\alpha_0}+\sum_{i=1}^{p}\prm{\alpha_i}u_{t-i}^2+\sum_{j=1}^{q}\prm{\beta_j}\sigma_{t-j}^2\]

ARCH จำแค่เมื่อวานโยกแรงแค่ไหน GARCH จำเพิ่มว่าช่วงนี้ทั้งช่วงโยกแรงแค่ไหนผ่าน σ² ของเมื่อวาน ความผันผวนค้างอยู่นานกว่าด้วยพารามิเตอร์น้อยกว่า ARCH เหมือน AR GARCH เหมือน ARMA ในสไลด์ p คือจำนวน α q คือจำนวน β GARCH(p,0) คือ ARCH(p)

13.1 Frequency domain และ periodogram

เพลงเดียวดูได้สองแบบ: เส้นคลื่นเสียงตามเวลา หรือแถบ equalizer ที่บอกว่าเบสกับแหลมดังแค่ไหน frequency domain แสดงข้อมูลชุดเดิมเป็นส่วนประกอบตามความถี่ เปลี่ยนคำถามจาก "เกิดอะไรขึ้นตามเวลา" เป็น "อะไรเกิดบ่อยแค่ไหน"

\[T=\frac{1}{\omega}\qquad\qquad I_n(\omega)=\frac{1}{n}\left|\sum_{t=1}^{n}x_t\,e^{-i2\pi\omega t}\right|^2\]

ความถี่ ω คือจำนวนรอบต่อหนึ่งหน่วยเวลา คาบ T คือความยาวของหนึ่งรอบ เป็นส่วนกลับกัน periodogram เอาข้อมูลไปคูณคลื่น cos/sin ที่แต่ละความถี่ ถ้าข้อมูลแกว่งตรงจังหวะ ผลรวมใหญ่ ไม่ตรงจังหวะก็หักล้างกันจนเล็ก ทุกโจทย์ทำแค่สองขั้น: หายอด แล้วกลับเศษเป็นส่วน

รายวันได้ยอดที่ f = 0.1429 → T = 7 วัน รอบรายสัปดาห์ · รายเดือน f = 0.0833 → 12 เดือน · รายไตรมาส f = 0.25 → 4 ไตรมาส · traffic หลัง diff ได้ f = 0.144 → 6.94 ≈ 7 วัน ไม่ได้ 7 พอดีเพราะ R คำนวณที่ความถี่เป็นขั้น 1/n

13.2 Prophet

Prophet ไม่ถามว่า "ค่าเมื่อวานบอกอะไรเกี่ยวกับวันนี้" แบบ ARIMA แต่ถามว่า "วันนี้คือวันอะไรของปี ของสัปดาห์ ใกล้วันหยุดไหม" แล้วเอาคำตอบมาบวกกัน เหมือนฟิตเส้นโค้งผ่านปฏิทิน เป็น decomposition ขั้นสูง ที่ทำงานดีที่สุด กับอนุกรมที่ฤดูกาลแรงและมีข้อมูลย้อนหลังหลายฤดูกาล

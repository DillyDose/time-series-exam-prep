0. สัญลักษณ์ที่อาจารย์ใช้

สัญลักษณ์ความหมาย
\(X_t\), \(w_t\)ค่าข้อมูลที่เวลา t และ white noise ที่เวลา t
\(B\)backshift operator: \(BX_t=X_{t-1}\), \(B^2X_t=X_{t-2}\) และใช้กับ \(w_t\) ได้เหมือนกัน
\(\Phi(B)\)พหุนามของส่วน AR: \(\Phi(B)=1-\phi_1B-\phi_2B^2-\dots-\phi_pB^p\) เครื่องหมายเป็นลบ
\(\theta(B)\)พหุนามของส่วน MA: \(\theta(B)=1+\theta_1B+\theta_2B^2+\dots+\theta_qB^q\) เครื่องหมายเป็นบวก
รูปย่อของ ARMA\(\Phi(B)X_t=\theta(B)w_t\)
\(\pi(B)\), \(\psi(B)\)พหุนามอนันต์ของรูป AR(∞) และ MA(∞)
root, modulusroot คือค่า x ที่ทำให้พหุนามเท่ากับ 0 ส่วน modulus คือค่าสัมบูรณ์ ถ้ารากเป็น \(a+bi\) modulus คือ \(\sqrt{a^2+b^2}\)

วิธีเปลี่ยนสมการเป็นรูป B: ย้ายพจน์ของ X ไปทางซ้ายทั้งหมด พจน์ของ w ไว้ทางขวา แล้วแทน \(X_{t-k}\) ด้วย \(B^kX_t\) ตัวอย่าง \(X_t=0.5X_{t-1}+w_t-0.3w_{t-1}\) ได้ \(X_t-0.5X_{t-1}=w_t-0.3w_{t-1}\) คือ \((1-0.5B)X_t=(1-0.3B)w_t\)

1. นิยาม (5:30, 18:30, 45:30)

Invertibility — check \(\theta(B)\) (MA part).

\(X_t\) is invertible if it can be written as AR(∞), a meaningful process: MA(q) → AR(∞).

\[w_t=\pi(B)X_t,\qquad \pi(B)=\frac{\Phi(B)}{\theta(B)}\]

Causality — check \(\Phi(B)\) (AR part).

\(X_t\) is causal if it can be written as MA(∞): AR(p) → MA(∞).

\[X_t=\psi(B)w_t,\qquad \psi(B)=\frac{\theta(B)}{\Phi(B)}\]
ตรวจพหุนามเปลี่ยนรูปเขียนได้ว่า
Invertible\(\theta(B)\)MA(q) เป็น AR(∞)\(w_t\) ในรูปของ X ปัจจุบันและอดีต
Causal\(\Phi(B)\)AR(p) เป็น MA(∞)\(X_t\) ในรูปของ w ปัจจุบันและอดีต

2. พิสูจน์ MA(1) invertible (7:00–12:00)

อาจารย์เขียน MA(1) ด้วยเครื่องหมายลบ คือ \(X_t=w_t-\theta w_{t-1}\) ผลที่ได้จึงเป็นบวกทุกพจน์

MA(1) ⇒ \(X_t=w_t-\theta w_{t-1}\)

\[w_t=X_t+\theta w_{t-1}\]

Since \(w_{t-1}=X_{t-1}+\theta w_{t-2}\),

\[w_t=X_t+\theta\,[X_{t-1}+\theta w_{t-2}]\]

Continuing,

\[w_t=X_t+\theta X_{t-1}+\theta^2X_{t-2}+\theta^3X_{t-3}+\dots\qquad\text{AR}(\infty)\]

This is a meaningful process only if the coefficients converge:

\[\sum_{j=1}^{\infty}\theta^j<\infty\ \text{(converge)}\quad\text{if and only if}\quad -1<\theta<1,\ \text{i.e. } |\theta|<1.\]

Therefore MA(1) is invertible if and only if \(|\theta|<1\).

บรรทัดทำอะไรเพราะอะไร
\(w_t=X_t+\theta w_{t-1}\)ย้าย \(-\theta w_{t-1}\) ไปอีกข้างต้องการ \(w_t\) อยู่ทางซ้ายตัวเดียว ลบย้ายข้างเป็นบวก
\(w_{t-1}=X_{t-1}+\theta w_{t-2}\)ใช้บรรทัดก่อนหน้าที่เวลา t−1โมเดลเป็นจริงทุกเวลา
แทนในวงเล็บเหลี่ยมแทน \(w_{t-1}\)กำจัด w ตัวเก่า ได้ X เพิ่มหนึ่งตัว และ w ถอยไปอีกหนึ่งช่วง
AR(∞)แทนซ้ำไปเรื่อย ๆ\(X_{t-j}\) มีสัมประสิทธิ์ \(\theta^j\) รูปนี้คือ \(X_t\) เขียนด้วยค่าในอดีตของตัวเองจำนวนอนันต์
เงื่อนไขลู่เข้าตรวจผลรวมของสัมประสิทธิ์ถ้า \(|\theta|\ge1\) ค่า \(\theta^j\) ไม่ลดลง ค่าในอดีตไกล ๆ จะมีน้ำหนักมากขึ้นเรื่อย ๆ ซึ่งไม่ meaningful
ถ้าโจทย์เขียน MA(1) ด้วยเครื่องหมายบวก (ต่อยอด)

ถ้าโจทย์ให้ \(X_t=w_t+\theta w_{t-1}\) ทำขั้นตอนเดียวกัน เครื่องหมายจะสลับ

\[w_t=X_t-\theta w_{t-1}=X_t-\theta\,[X_{t-1}-\theta w_{t-2}]\] \[w_t=X_t-\theta X_{t-1}+\theta^2X_{t-2}-\theta^3X_{t-3}+\dots=\sum_{j=0}^{\infty}(-\theta)^jX_{t-j}\qquad\text{AR}(\infty)\]

The coefficients converge if and only if \(|\theta|<1\). Therefore MA(1) is invertible if and only if \(|\theta|<1\).

เงื่อนไขเหมือนกันทั้งสองแบบ ให้เขียนตามเครื่องหมายที่โจทย์ให้

3. ทำไมต้องมี invertibility (12:00–15:00)

Consider two MA(1) models:

\[X_t=w_t+\tfrac15w_{t-1}\qquad\text{and}\qquad X_t=w_t+5w_{t-1}\]

Both have the same ACF at lag 1:

\[\rho(1)=\frac{\theta}{1+\theta^2}:\qquad \frac{1/5}{1+1/25}=0.1923,\qquad \frac{5}{1+25}=0.1923\]

The data cannot tell them apart. We choose the invertible one, \(X_t=w_t+\tfrac15w_{t-1}\) (\(|\theta|=0.2<1\)), because it can be written as AR(∞): MA(q) → AR(∞).

โมเดลที่มี \(\theta\) กับ \(1/\theta\) ให้ ACF เดียวกันเสมอ เงื่อนไข invertible จึงใช้เลือกให้เหลือโมเดลเดียว

4. ทฤษฎีบท (15:30–21:00)

Theorem. For an MA(q) to be invertible, we need the roots of

\[\theta(B)=1+\theta_1B+\theta_2B^2+\theta_3B^3+\dots+\theta_qB^q\]

to all exceed 1 in absolute value (or modulus).

Theorem. For an AR(p) to be causal, we need the roots of

\[\Phi(B)=1-\phi_1B-\phi_2B^2-\dots-\phi_pB^p\]

to all exceed 1 in absolute value (or modulus).

ขั้นตอนใช้ทฤษฎีบท

  1. เขียนโมเดลในรูป \(\Phi(B)X_t=\theta(B)w_t\)
  2. เปลี่ยน B เป็น x แล้วตั้งพหุนามเท่ากับ 0
  3. หาราก: พหุนามกำลังหนึ่งแก้ตรง ๆ พหุนามกำลังสองใช้ \(x=\dfrac{-b\pm\sqrt{b^2-4ac}}{2a}\) โดย \(a\) คือสัมประสิทธิ์ของ \(x^2\), \(b\) ของ \(x\), \(c\) คือค่าคงที่
  4. ถ้า \(b^2-4ac<0\) รากเป็น \(a'\pm b'i\) ให้หา modulus \(\sqrt{a'^2+b'^2}\)
  5. ทุกรากมากกว่า 1: ผ่าน ถ้ามีรากใดไม่เกิน 1: ไม่ผ่าน

5. AR(1) causal หรือไม่ (21:15–24:00)

1) \(X_t=0.3X_{t-1}+w_t\) (AR(1) with \(\phi=0.3\))

\[(1-0.3B)X_t=w_t,\qquad \Phi(B)=1-0.3B\] \[\Phi(x)=1-0.3x=0\ \Rightarrow\ |x|=\left|\frac{1}{0.3}\right|=3.33>1\]

Causal.

AR(1) กรณีทั่วไป (ต่อยอดจากตัวอย่างของอาจารย์)

AR(1): \(X_t=\phi X_{t-1}+w_t\)

\[(1-\phi B)X_t=w_t,\qquad \Phi(B)=1-\phi B\] \[\Phi(x)=1-\phi x=0\ \Rightarrow\ x=\frac{1}{\phi}\] \[|x|=\left|\frac1\phi\right|>1\iff|\phi|<1\]

Therefore AR(1) is causal if and only if \(|\phi|<1\).

MA(∞) form. \(\psi(B)=\dfrac{\theta(B)}{\Phi(B)}=(1-\phi B)^{-1}=1+\phi B+\phi^2B^2+\phi^3B^3+\dots\) (power series), so

\[X_t=\psi(B)w_t=w_t+\phi w_{t-1}+\phi^2w_{t-2}+\dots=\sum_{j=0}^{\infty}\phi^jw_{t-j}\qquad\text{MA}(\infty)\]

Invertibility. AR(1) has \(\theta(B)=1\), which has no roots. \(w_t=X_t-\phi X_{t-1}\) is already an AR form, so AR(1) is always invertible.

AR(1) เขียนเป็น MA(∞) ด้วยการแทนค่าซ้ำ (ต่อยอด: วิธีเดียวกับที่อาจารย์ใช้กับ MA(1) ในหัวข้อ 2)

AR(1) ⇒ \(X_t=\phi X_{t-1}+w_t\)

Since \(X_{t-1}=\phi X_{t-2}+w_{t-1}\),

\[X_t=\phi\,[\phi X_{t-2}+w_{t-1}]+w_t=\phi^2X_{t-2}+\phi w_{t-1}+w_t\]

Continuing,

\[X_t=w_t+\phi w_{t-1}+\phi^2w_{t-2}+\phi^3w_{t-3}+\dots\qquad\text{MA}(\infty)\] \[\sum_{j=1}^{\infty}\phi^j<\infty\ \text{(converge)}\quad\text{if and only if}\quad -1<\phi<1.\]

Therefore AR(1) is causal if and only if \(|\phi|<1\).

ถ้าโจทย์เขียนว่า show by the theorem หรือ check the roots ให้ใช้กล่องบน ถ้าโจทย์ให้ write as MA(∞) หรือ show directly ให้ใช้กล่องนี้

MA(1) ด้วยทฤษฎีบท (ต่อยอด)

MA(1): \(X_t=w_t+\theta w_{t-1}=(1+\theta B)w_t\), \(\theta(B)=1+\theta B\)

\[\theta(x)=1+\theta x=0\ \Rightarrow\ x=-\frac1\theta,\qquad |x|=\left|\frac1\theta\right|>1\iff|\theta|<1\]

Therefore MA(1) is invertible if and only if \(|\theta|<1\). MA(1) has \(\Phi(B)=1\), so it is always causal.

6. MA(2) invertible หรือไม่ (25:00–28:30)

2) \(X_t=w_t-1.3w_{t-1}+0.4w_{t-2}\)

\[X_t=(1-1.3B+0.4B^2)\,w_t,\qquad \theta(B)=1-1.3B+0.4B^2\] \[\theta(x)=1-1.3x+0.4x^2\qquad(ax^2+bx+c:\ a=0.4,\ b=-1.3,\ c=1)\] \[b^2-4ac=(-1.3)^2-4(0.4)(1)=1.69-1.6=0.09>0\] \[x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}=\frac{1.3\pm0.3}{0.8}=2,\ 1.25\quad(>1)\]

Both roots exceed 1, so the process is invertible.

จุดที่ต้องระวังคือการจับคู่ a, b, c พหุนามเขียนเรียงจากค่าคงที่ไปกำลังสอง ค่า a จึงเป็นตัวท้าย คือ 0.4 และ c เป็นตัวแรก คือ 1

7. ARMA(1,2) ที่รากเป็นจำนวนเชิงซ้อน (29:00–37:30)

3) ARMA(1,2): \(X_t=0.5X_{t-1}+w_t-0.3w_{t-1}+1.2w_{t-2}\)

\[(1-0.5B)X_t=(1-0.3B+1.2B^2)\,w_t\]

• \(\Phi(x)=1-0.5x=0\ \Rightarrow\ x=2>1\). Causal.

• \(\theta(x)=1-0.3x+1.2x^2\qquad(a=1.2,\ b=-0.3,\ c=1)\)

\[D=b^2-4ac=(-0.3)^2-4(1.2)(1)=0.09-4.8=-4.71<0\]

The roots are complex, \(a'\pm b'i\):

\[x=\frac{-b}{2a}\pm\frac{i\sqrt{|D|}}{2a}=\frac{-(-0.3)}{2(1.2)}\pm\frac{i\sqrt{|-4.71|}}{2(1.2)}\approx0.125\pm0.904\,i\] \[\text{modulus}=\sqrt{0.125^2+0.904^2}=0.913<1\]

The roots do not exceed 1 in modulus, so the process is not invertible.

Conclusion: causal but not invertible.

บรรทัดสรุป “not invertible” ผมเติมจากผล 0.913 น้อยกว่า 1 ตามทฤษฎีบท ในเฟรมที่อ่านได้อาจารย์เขียนถึงค่า 0.913

8. ARMA(2,2) ที่มี parameter redundancy: Ex 3.7 (37:50–44:00)

4) Ex 3.7 ARMA(2,2)?

\[X_t=0.4X_{t-1}+0.45X_{t-2}+w_t+w_{t-1}+0.25w_{t-2}\] \[(1-0.4B-0.45B^2)\,X_t=(1+B+0.25B^2)\,w_t\]

Factor both sides:

\[(1+0.5B)(1-0.9B)\,X_t=(1+0.5B)(1+0.5B)\,w_t\]

The common factor \((1+0.5B)\) cancels (parameter redundancy):

\[(1-0.9B)\,X_t=(1+0.5B)\,w_t\]

The model is ARMA(1,1), not ARMA(2,2): \(X_t=0.9X_{t-1}+w_t+0.5w_{t-1}\).

• \(\Phi(x)=1-0.9x=0\ \Rightarrow\ x=1/0.9=1.11>1\). Causal.

• \(\theta(x)=1+0.5x=0\ \Rightarrow\ x=-2,\ |x|=2>1\). Invertible.

ขั้นวิธีทำ
แยกตัวประกอบฝั่ง ARตรวจโดยคูณกลับ: \((1+0.5B)(1-0.9B)=1-0.9B+0.5B-0.45B^2=1-0.4B-0.45B^2\)
แยกตัวประกอบฝั่ง MA\((1+0.5B)^2=1+B+0.25B^2\)
หาตัวประกอบเมื่อมองไม่ออกหารากของพหุนามด้วยสูตรกำลังสอง ถ้ารากคือ \(r_1,r_2\) ตัวประกอบคือ \((1-B/r_1)(1-B/r_2)\) ฝั่ง AR มีราก −2 และ 1.11 จึงได้ \((1+0.5B)(1-0.9B)\)
ตัดตัวประกอบร่วมตัวประกอบที่เหมือนกันทั้งสองฝั่งตัดออกได้ โมเดลจึงเล็กลง ต้องตัดก่อนตรวจ causal และ invertible

9. เขียน ARMA(1,1) เป็น MA(∞): หา ψ (48:30–57:40)

ใช้โมเดลจากหัวข้อ 8 คือ \((1-0.9B)X_t=(1+0.5B)w_t\) อาจารย์เปลี่ยน B เป็น z ขณะกระจายพหุนาม

\[\Phi(z)=1-0.9z,\qquad \theta(z)=1+0.5z\] \[\psi(z)=\frac{\theta(z)}{\Phi(z)}=\frac{1+0.5z}{1-0.9z}=(1+0.5z)(1-0.9z)^{-1}\]

Power series: \((1+\theta z)^{-1}=1+(-\theta)z+(-\theta)^2z^2+(-\theta)^3z^3+\dots\)

With \(\theta=-0.9\): \((1-0.9z)^{-1}=1+0.9z+0.9^2z^2+0.9^3z^3+\dots\)

\[\psi(z)=(1+0.5z)(1+0.9z+0.9^2z^2+\dots)\] \[=1+1.4z+(1.4)(0.9)z^2+(1.4)(0.9)^2z^3+(1.4)(0.9)^3z^4+\dots\] \[X_t=\psi(B)w_t=\big(1+1.4B+(1.4)(0.9)B^2+(1.4)(0.9)^2B^3+\dots\big)\,w_t\qquad\text{MA}(\infty)\] \[X_t=w_t+\sum_{j=1}^{\infty}1.4\,(0.9)^{j-1}\,w_{t-j}\]
สัมประสิทธิ์ของมาจากผล
\(z^0\)\(1\times1\)1
\(z^1\)\(1\times0.9+0.5\times1\)1.4
\(z^2\)\(1\times0.9^2+0.5\times0.9=0.9(0.9+0.5)\)\(1.4(0.9)=1.26\)
\(z^3\)\(1\times0.9^3+0.5\times0.9^2=0.9^2(0.9+0.5)\)\(1.4(0.9)^2=1.134\)
\(z^j\)\(0.9^{j-1}(0.9+0.5)\)\(1.4(0.9)^{j-1}\)

วิธีคูณคือนำ 1 และ 0.5z ในวงเล็บแรกคูณกระจายเข้าไปในอนุกรม แล้วรวมพจน์ที่มีกำลังของ z เท่ากัน ค่า 1.4 มาจาก 0.9 + 0.5 ซึ่งคือ \(\phi+\theta\)

10. เขียน ARMA(1,1) เป็น AR(∞): หา π (57:40–60:30)

Invertibility:

\[\pi(z)=\frac{\Phi(z)}{\theta(z)}=(1-0.9z)(1+0.5z)^{-1}\]

Power series with \(\theta=0.5\): \((1+0.5z)^{-1}=1-0.5z+0.5^2z^2-0.5^3z^3+\dots\)

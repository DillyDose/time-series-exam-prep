ใบที่ 1 — นิยาม

Define invertibility and causality.

Invertibility: \(X_t\) is invertible if it can be written as AR(∞), a meaningful process (MA(q) → AR(∞)):

\[w_t=\pi(B)X_t,\qquad \pi(B)=\frac{\Phi(B)}{\theta(B)}\]

For an MA(q) to be invertible, we need the roots of \(\theta(B)=1+\theta_1B+\theta_2B^2+\dots+\theta_qB^q\) to all exceed 1 in absolute value (or modulus).

Causality: \(X_t\) is causal if it can be written as MA(∞) (AR(p) → MA(∞)):

\[X_t=\psi(B)w_t,\qquad \psi(B)=\frac{\theta(B)}{\Phi(B)}\]

For an AR(p) to be causal, we need the roots of \(\Phi(B)=1-\phi_1B-\phi_2B^2-\dots-\phi_pB^p\) to all exceed 1 in absolute value (or modulus).

ใบที่ 2 — พิสูจน์ MA(1) invertible (โจทย์เขียน \(-\theta\))

Show that the MA(1) process \(X_t=w_t-\theta w_{t-1}\) is invertible when \(|\theta|<1\).

MA(1): \(X_t=w_t-\theta w_{t-1}\)

\[w_t=X_t+\theta w_{t-1}\]

Since \(w_{t-1}=X_{t-1}+\theta w_{t-2}\),

\[w_t=X_t+\theta\,[X_{t-1}+\theta w_{t-2}]=X_t+\theta X_{t-1}+\theta^2w_{t-2}\]

Since \(w_{t-2}=X_{t-2}+\theta w_{t-3}\),

\[w_t=X_t+\theta X_{t-1}+\theta^2X_{t-2}+\theta^3w_{t-3}\]

Continuing,

\[w_t=X_t+\theta X_{t-1}+\theta^2X_{t-2}+\theta^3X_{t-3}+\dots=\sum_{j=0}^{\infty}\theta^jX_{t-j}\qquad\text{AR}(\infty)\] \[\sum_{j=1}^{\infty}\theta^j<\infty\ \text{(converge) if and only if } -1<\theta<1.\]

Therefore MA(1) can be written as AR(∞), so it is invertible, if and only if \(|\theta|<1\).

ใบที่ 3 — พิสูจน์ MA(1) invertible (โจทย์เขียน \(+\theta\))

Show that the MA(1) process \(X_t=w_t+\theta w_{t-1}\) is invertible when \(|\theta|<1\).

MA(1): \(X_t=w_t+\theta w_{t-1}\)

\[w_t=X_t-\theta w_{t-1}\]

Since \(w_{t-1}=X_{t-1}-\theta w_{t-2}\),

\[w_t=X_t-\theta\,[X_{t-1}-\theta w_{t-2}]=X_t-\theta X_{t-1}+\theta^2w_{t-2}\]

Since \(w_{t-2}=X_{t-2}-\theta w_{t-3}\),

\[w_t=X_t-\theta X_{t-1}+\theta^2X_{t-2}-\theta^3w_{t-3}\]

Continuing,

\[w_t=X_t-\theta X_{t-1}+\theta^2X_{t-2}-\theta^3X_{t-3}+\dots=\sum_{j=0}^{\infty}(-\theta)^jX_{t-j}\qquad\text{AR}(\infty)\] \[\sum_{j=1}^{\infty}(-\theta)^j<\infty\ \text{(converge) if and only if } -1<\theta<1.\]

Therefore MA(1) can be written as AR(∞), so it is invertible, if and only if \(|\theta|<1\).

ใบที่ 4 — พิสูจน์ AR(1) causal ด้วยทฤษฎีบท

Show that the AR(1) process \(X_t=\phi X_{t-1}+w_t\) is causal when \(|\phi|<1\).

AR(1): \(X_t=\phi X_{t-1}+w_t\)

\[X_t-\phi X_{t-1}=w_t\ \Rightarrow\ (1-\phi B)X_t=w_t,\qquad \Phi(B)=1-\phi B\]

For an AR(p) to be causal, we need the roots of \(\Phi(B)\) to all exceed 1 in absolute value.

\[\Phi(x)=1-\phi x=0\ \Rightarrow\ x=\frac1\phi\] \[|x|=\left|\frac1\phi\right|>1\quad\text{if and only if}\quad|\phi|<1\]

Therefore AR(1) is causal if and only if \(|\phi|<1\).

โจทย์ให้ write as MA(∞) หรือ show directly ด้วยใช้ใบที่ 5 แทน หรือลอกต่อท้าย

ใบที่ 5 — พิสูจน์ AR(1) causal ด้วยการแทนค่าซ้ำ (เขียนเป็น MA(∞))

Show that AR(1) \(X_t=\phi X_{t-1}+w_t\) can be written as MA(∞) when \(|\phi|<1\).

AR(1): \(X_t=\phi X_{t-1}+w_t\)

Since \(X_{t-1}=\phi X_{t-2}+w_{t-1}\),

\[X_t=\phi\,[\phi X_{t-2}+w_{t-1}]+w_t=\phi^2X_{t-2}+\phi w_{t-1}+w_t\]

Since \(X_{t-2}=\phi X_{t-3}+w_{t-2}\),

\[X_t=\phi^3X_{t-3}+\phi^2w_{t-2}+\phi w_{t-1}+w_t\]

Continuing,

\[X_t=w_t+\phi w_{t-1}+\phi^2w_{t-2}+\phi^3w_{t-3}+\dots=\sum_{j=0}^{\infty}\phi^jw_{t-j}\qquad\text{MA}(\infty)\] \[\sum_{j=1}^{\infty}\phi^j<\infty\ \text{(converge) if and only if } -1<\phi<1.\]

Therefore AR(1) can be written as MA(∞), so it is causal, if and only if \(|\phi|<1\).

ใบที่ 6 — AR(1) invertible ไหม / MA(1) causal ไหม

Is AR(1) invertible? Is MA(1) causal?

AR(1) is always invertible. \(X_t=\phi X_{t-1}+w_t\) gives \(w_t=X_t-\phi X_{t-1}\), which is already an AR form (\(\theta(B)=1\), no MA part to check). No condition on \(\phi\) is needed.

MA(1) is always causal. \(X_t=w_t+\theta w_{t-1}\) is already an MA form (\(\Phi(B)=1\), no AR part to check). No condition on \(\theta\) is needed.

ใบที่ 9 — อันดับ 2 รากเป็นจำนวนจริง

Is \(X_t=w_t\textcolor{#1558d6}{-1.3}w_{t-1}\textcolor{#1558d6}{+0.4}w_{t-2}\) invertible?
\[X_t=(1\textcolor{#1558d6}{-1.3}B\textcolor{#1558d6}{+0.4}B^2)\,w_t,\qquad \theta(B)=1\textcolor{#1558d6}{-1.3}B\textcolor{#1558d6}{+0.4}B^2\] \[\theta(x)=1\textcolor{#1558d6}{-1.3}x\textcolor{#1558d6}{+0.4}x^2\qquad(a=\textcolor{#1558d6}{0.4},\ b=\textcolor{#1558d6}{-1.3},\ c=1)\] \[b^2-4ac=(\textcolor{#1558d6}{-1.3})^2-4(\textcolor{#1558d6}{0.4})(1)=\textcolor{#1558d6}{0.09}>0\] \[x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}=\frac{\textcolor{#1558d6}{1.3}\pm\textcolor{#1558d6}{0.3}}{\textcolor{#1558d6}{0.8}}=\textcolor{#1558d6}{2},\ \textcolor{#1558d6}{1.25}\]

ใบที่ 12 — Parameter redundancy (Ex 3.7)

\(X_t=0.4X_{t-1}+0.45X_{t-2}+w_t+w_{t-1}+0.25w_{t-2}\). Is it ARMA(2,2)? Is it causal and invertible?
\[(1-0.4B-0.45B^2)\,X_t=(1+B+0.25B^2)\,w_t\]

Factor both sides:

\[(1+0.5B)(1-0.9B)\,X_t=(1+0.5B)(1+0.5B)\,w_t\]

The common factor \((1+0.5B)\) cancels (parameter redundancy):

\[(1-0.9B)\,X_t=(1+0.5B)\,w_t\]

So the model is ARMA(1,1), not ARMA(2,2): \(X_t=0.9X_{t-1}+w_t+0.5w_{t-1}\).

• \(\Phi(x)=1-0.9x=0\ \Rightarrow\ x=1/0.9=1.11>1\). Causal.

• \(\theta(x)=1+0.5x=0\ \Rightarrow\ x=-2,\ |x|=2>1\). Invertible.

ใบที่ 15 — ทำไมต้องมี invertibility

\(X_t=w_t+\textcolor{#1558d6}{\tfrac15}w_{t-1}\) and \(X_t=w_t+\textcolor{#1558d6}{5}w_{t-1}\). Compare their ACF. Which one do we choose and why?

For MA(1), \(\rho(1)=\dfrac{\theta}{1+\theta^2}\).

\[\theta=\textcolor{#1558d6}{\tfrac15}:\ \rho(1)=\frac{\textcolor{#1558d6}{0.2}}{1+\textcolor{#1558d6}{0.04}}=\textcolor{#1558d6}{0.1923}\qquad\qquad \theta=\textcolor{#1558d6}{5}:\ \rho(1)=\frac{\textcolor{#1558d6}{5}}{1+\textcolor{#1558d6}{25}}=\textcolor{#1558d6}{0.1923}\]

Both models have the same ACF, so the data cannot tell them apart.

We choose \(X_t=w_t+\textcolor{#1558d6}{\tfrac15}w_{t-1}\) because \(|\theta|=\textcolor{#1558d6}{0.2}<1\): it is invertible, i.e. it can be written as AR(∞) (MA(q) → AR(∞)). The model with \(\theta=\textcolor{#1558d6}{5}\) is not invertible.
